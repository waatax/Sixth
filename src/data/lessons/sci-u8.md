## 🔑 核心觀念 1：生態系的俄羅斯娃娃——五大組成層次

![生態系能量流動、食物鏈食物網與能量金字塔 (Ecosystem Food Web)](./images/sci_u8_concept1.svg)


生態系統的結構如同俄羅斯套娃，由微觀到宏觀層層包容：

```text
  【1. 個體 (Organism)】 ──► 單一隻生命體 (例如：一隻臺灣黑熊 🐻)
          │
          ▼
  【2. 族群 (Population)】 ──► 同時、同地、同種生物的集合 (例如：玉山國家公園內所有的臺灣黑熊)
          │
          ▼
  【3. 群落/群集 (Community)】 ──► 同一地區所有不同生物族群的總和 (例如：玉山上的黑熊、山羌、紅檜、鳥類)
          │
          ▼
  【4. 生態系 (Ecosystem)】 ──► 生物群落 ＋ 無生命環境 (陽光、空氣、水、土壤、溫度)
          │
          ▼
  【5. 生物圈 (Biosphere)】 ──► 地球上所有生物及其生存環境的總和 (海平面上下約各 10 公里範圍)
```

## 🔑 核心觀念 2：自然界的職業分工與物質循環

![生物與環境保育 (Ecosystems & Energy) - 圖解 2](./images/sci_u8_concept2.svg)

在生態系這個完美的綠色工廠中，三大生命角色緊密協作，實現了「物質無限循環」：

```text
                          ☀️ 太陽光源源不絕注入能量
                                      │
                                      ▼
                        ┌───────────────────────────┐
                        │   【 🌿 生產者 (植物) 】   │ ◄────┐
                        └─────────────┬─────────────┘      │
                                      │                    │
                             攝食 (能量與有機物)            │
                                      │                    │
                                      ▼                    │ 無機養分釋回
                        ┌───────────────────────────┐      │ (礦物質/氮磷鉀)
                        │   【 🦁 消費者 (動物) 】   │      │
                        └─────────────┬─────────────┘      │
                                      │                    │
                               遺體與排泄物                │
                                      │                    │
                                      ▼                    │
                        ┌───────────────────────────┐      │
                        │   【 🍄 分解者 (菌類) 】   │ ─────┘
```

- $\textcolor{#4caf50}{\textbf{物質可以循環}}$：碳、氫、氧、氮、磷等元素在生物與非生物環境間不斷循環流轉，永不消滅。
- $\textcolor{#e91e63}{\textbf{能量單向流動}}$：太陽能量一旦被生物以「熱能」形式散失到太空中，就**無法再回收利用**，因此生態系必須持續依賴太陽能的注入維持運作！

## 🔑 核心觀念 3：誰吃誰的能量傳遞——食物網、10% 定律與生物放大

![生物與環境保育 (Ecosystems & Energy) - 圖解 3](./images/sci_u8_concept3.svg)

### 🕸️ 食物鏈 (Food Chain) 與食物網 (Food Web)
- **食物鏈**：以單線箭頭表示「吃與被吃」的關係。**箭頭方向 $\rightarrow$ 永遠指向「捕食者（能量流入的方向）」！**
- **食物網**：多條相互交錯的食物鏈交織成的網狀結構。**食物網越複雜，當某種生物數量變動時，其他物種越容易替代，生態系統就越穩定健康！**

```text
                  【 森林生態系複雜食物網範例 】
                         [ 🦅 頂級掠食者：老鷹 ]
                           ▲               ▲
                          /                 \
                  [ 🐍 蛇類 ]             [ 🦉 貓頭鷹 ]
                    ▲     ▲                 ▲
                   /       \               /
            [ 🐸 青蛙 ]   [ 🐀 田鼠 ] ────┘
                ▲             ▲
                │             │
            [ 🦗 蝗蟲 ]       │
                ▲             │
                 \           /
                  [ 🌾 綠色稻麥與植物草本 (生產者) ]
```

### 📉 能量金字塔與 10% 能量傳遞定律

$$\textcolor{#e91e63}{\textbf{能量傳遞 10\% 定律：}} \text{各營養階層僅有約 } \textcolor{#e91e63}{\textbf{10\% 的能量}} \text{ 能傳遞至上一階層，其餘 } \textcolor{#2196f3}{\textbf{90\%}} \text{ 皆以熱能散失或生命呼吸消耗！}$$

```text
                          ┌─────────────┐
                          │ 🦅 頂級掠食者│  (僅獲得 10 J)
                          ├─────────────┤
                          │  🐍 次級消費者 │  (獲得 100 J)
                          ├─────────────┤
                          │  🦗 初級消費者 │  (獲得 1,000 J)
                          ├─────────────┤
                          │  🌾 綠色生產者 │  (擁有 10,000 J 太陽轉換化學能)
                          └─────────────┘
                             【 能量金字塔 (越往頂端能量越少) 】
```

### ⚠️ 生物放大作用 (Biomagnification)
與能量向上遞減相反！環境中難以被生物分解與排出的重金屬（如汞、鉛）或脂溶性毒物（如塑膠微粒、戴奧辛、DDT），會隨著食物鏈「**層層累積濃縮**」。位居食物鏈最頂端的生物（如大型魚類、猛禽、人類），體內累積的毒素濃度高達環境底層的數十萬倍！

## 🔑 核心觀念 5：生物多樣性危機（HIPPO）與永續保育

當前地球生物多樣性正面臨空前威脅，生態學家將五大殺手統稱為 $\textcolor{#e91e63}{\textbf{HIPPO}}$：

```text
       【 H: Habitat Loss 】 ─────► 棲地破壞 (砍伐森林、開闢道路阻斷動物遷徙，排名第一大殺手！)
       【 I: Invasive Species 】 ─► 外來種入侵 (搶奪本土物種食物與棲地，缺乏天敵破壞平衡)
       【 P: Pollution 】 ────────► 環境污染 (農藥、工業廢水、海洋塑膠垃圾)
       【 P: Population 】 ───────► 人口過度膨脹 (過度消耗自然資源、超載開發)
       【 O: Overharvesting 】 ───► 過度捕撈與獵殺 (鯨豚、鯊魚魚翅、穿山甲濫捕)
```

### 👾 臺灣常見強勢外來入侵種警報
1. $\textcolor{#e91e63}{\textbf{綠鬣蜥}}$：寵物棄養，於南臺灣農田劇烈繁殖，挖洞破壞堤防農作。
2. $\textcolor{#ff9800}{\textbf{福壽螺}}$：引進食用後遭棄養，啃食水稻幼苗造成農業浩劫。
3. $\textcolor{#4caf50}{\textbf{小花蔓澤蘭}}$：被稱為「綠色殺手/植物吸血鬼」，迅速攀爬纏繞樹木阻擋陽光導致母樹枯死。
4. **埃及聖䴉**：逃出動物園後在野外大量繁殖，排擠本土鷺鷥築巢棲地。

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【生態系角色與食物鏈能量流動】
- 📌 **題目情境**：在森林生態系中有一條食物鏈：「橡樹葉 ➔ 毛毛蟲 ➔ 小鳥 ➔ 鷹」。請問：
  (1) 誰是生產者？誰是初級消費者？
  (2) 能量在食物鏈中傳遞時，能量會增加還是逐級遞減？
- 💡 **思考關鍵**：綠色植物製造養分 ➔ 生產者；吃植物者 ➔ 初級消費者。能量每向上一階約僅傳遞 10%（能量金字塔遞減）。
- 📐 **詳盡步驟**：
  1. 橡樹葉行光合作用為「生產者」；毛毛蟲吃樹葉為「初級消費者」；小鳥為次級消費者；鷹為頂級消費者。
  2. 能量在傳遞過程中因為生物呼吸、運動發熱而散失，能量會「逐級遞減」（約 90% 散失）。

### 📝 範例 2：【生物累積與放大作用】
- 📌 **題目情境**：如果農夫在田間噴灑了無法被生物分解的重金屬農藥，沿著食物鏈（草 ➔ 蝗蟲 ➔ 青蛙 ➔ 蛇 ➔ 鷹），哪一種生物體內的毒素累積濃度會最高？
- 💡 **思考關鍵**：脂溶性重金屬與農藥無法代謝排出，食物鏈階層越高，累積濃度越高（生物放大效應）。
- 📐 **詳盡步驟**：
  1. 最高階掠食者「鷹」體內的重金屬農藥累積濃度最高。
  2. 這種現象稱為「生物放大作用 (Biological Magnification)」，會造成高階鳥類產軟殼蛋或神經中毒。

## 🧠 迷思大破解

❌ **迷思 1**：在食物鏈中畫箭頭時，老鷹吃蛇，所以箭頭要指向被吃的一方：老鷹 $\rightarrow$ 蛇。
✅ **正確觀念**：大錯特錯！食物鏈的箭頭方向嚴格代表「$\textcolor{#e91e63}{\textbf{能量流動的方向}}$」。因為蛇被老鷹吃掉後，蛇身上的有機養分與能量流向了老鷹，所以箭頭必須指向捕食者：**蛇 $\longrightarrow$ 老鷹**！

❌ **迷思 2**：分解者（細菌、黴菌、蕈菇）只會讓食物壞掉長蟲，對大自然沒有任何正面價值。
✅ **正確觀念**：分解者是大自然不可或缺的「$\textcolor{#4caf50}{\textbf{超級清潔隊與循環大師}}$」！若沒有分解者，地表數億年來的所有枯木落葉與動物屍體將堆積如山，土壤中的氮、磷、鉀礦物質也將全部耗盡，整個生態系的物質循環將徹底癱瘓中斷！

❌ **迷思 3**：我們買外國進口的寵物（如巴西龜、綠鬣蜥）在寺廟放生是積德做善事。
✅ **正確觀念**：隨意放生等於「$\textcolor{#e91e63}{\textbf{殘害本土生態}}$」！強勢外來種進入野外後會瘋狂掠食本土物種、搶奪巢穴並散播外來病原體，甚至導致臺灣本土特有物種走向滅絕，屬於違法且破壞生態的嚴重行為。

## ✏️ 隨堂自我小練習

1. **(選擇題)** 在「水稻 $\rightarrow$ 稻螟蟲 $\rightarrow$ 青蛙 $\rightarrow$ 鎖鏈蛇 $\rightarrow$ 大冠鷲」這條食物鏈中，哪一個營養階層所擁有的總能量最少？
   (A) 水稻  (B) 稻螟蟲  (C) 鎖鏈蛇  (D) 大冠鷲
   **解答**：$\textcolor{#4caf50}{\textbf{(D)}}$。根據能量金字塔 10% 傳遞定律，能量每上升一個階層就損失約 90%，因此位於最高階捕食者的大冠鷲所能獲得的總能量最少。

2. **(選擇題)** 小明在陽明山國家公園進行生態調查，記錄到「擎天崗草原上所有的野化水牛」。請問在生態學層次中，這群水牛屬於下列哪一個層次？
   (A) 個體  (B) 族群  (C) 群落  (D) 生態系
   **解答**：$\textcolor{#4caf50}{\textbf{(B)}}$。在同一時間、同一特定地理區域內生活的所有「同一種」生物個體集合，稱為「族群」。

3. **(選擇題)** 近年來臺灣中南部許多樹木被俗稱「植物綠癌」的藤本植物覆蓋纏繞，導致樹木無法進行光合作用而枯死。請問這種惡名昭彰的外來入侵種是下列何者？
   (A) 水筆仔  (B) 紅檜  (C) 小花蔓澤蘭  (D) 臺灣一葉蘭
   **解答**：$\textcolor{#4caf50}{\textbf{(C)}}$。小花蔓澤蘭繁殖與生長速度極快，為臺灣嚴防清除的有害外來入侵植物。

4. **(簡答題)** 為什麼湖泊遭受微量重金屬汞（水銀）污染後，水中的微小浮游生物體內汞含量極低，但生活在湖泊頂層的大型肉食性魚類體內汞濃度卻超標數萬倍？
   **解答**：這是因為「生物放大作用 (Biomagnification)」。重金屬汞等物質難以被生物代謝排出，會在脂肪組織中累積。當高階消費者大量捕食低階生物時，毒素沿著食物鏈被層層累積濃縮，使得頂級掠食者體內的毒素濃度達到驚人的倍數。

5. **(填空題)** 臺灣國寶魚「臺灣櫻花鉤吻鮭」屬於冰河時期的孑遺生物，牠們僅能在水溫低於 $17^\circ\text{C}$、水質清澈且高溶氧的環境中生存，目前主要棲息於臺中雪霸國家公園的 $\underline{\hspace{2.5cm}}$ 上游。
   **解答**：$\textcolor{#2196f3}{\textbf{七家灣溪}}$（或大甲溪上游）。

## 🌍 你知道嗎？

**🐺 美國黃石國家公園「重引入灰狼」引發的驚天生態奇蹟！**
1926 年，美國黃石公園內的灰狼因人為獵殺而全數滅絕。失去頂級天敵後，馬鹿族群暴增，牠們肆無忌憚地啃光了河岸邊所有的柳樹與白楊樹苗，導致河岸土壤嚴重流失、水質混濁，海狸因為沒有樹枝造壩而消失，魚類與鳥類相繼滅絕，整個生態系統瀕臨崩潰。
1995 年，科學家重新將 14 隻灰狼野放回黃石公園。奇蹟發生了：
狼群不僅抑制了鹿的數量，更迫使鹿群不敢長時間滯留在開闊的河谷。僅僅幾年內，河岸樹林迅速重新茂密成林，海狸回來修築了數十座濕地水壩，水鳥、鳴禽、水獺與各類魚群全面復甦。樹木根系更牢牢抓住了河岸土壤，連**河流的蜿蜒流向都穩定了下來**！這項生物學奇蹟證明了：頂級掠食者在維持生態平衡中扮演著不可替代的關鍵力量！

#### ⚠️ 段考高頻失分防雷提醒

1．誤以為分解者不重要或屬於消費者：分解者（細菌、真菌）若消失，地球將被屍體堆滿，物質循環完全中斷。

2．生物累積毒素濃度誰最高搞反：以為食物鏈底部的生物吃最多毒素最高，正確是【位居食物鏈頂端的掠食者體內濃度最高】。

3．能量循環流動觀念錯誤：物質在生態系中可「循環再生」，但能量是「單向流動、逐級散失為熱能」，無法循環。

4．外來種等於入侵種：外來種經評估飼育不一定都會危害生態，只有「在野外大量繁殖且危害本土生態平衡」的才稱為入侵種。

### 1. 食物鏈的箭頭方向

- 🧠 **一句話記住**：箭頭：被吃者 → 吃者；第一個一定是生產者（植物）。
- 🌱 **生活例子**：稻子 → 蝗蟲 → 青蛙 → 蛇：蝗蟲吃稻子，所以箭頭從稻子指向蝗蟲。

**先想想看**：遮住下面的說明，用自己的話說說「食物鏈的箭頭方向」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

食物鏈的箭頭表示「養分和能量從誰流到誰」，所以箭頭要從「被吃的」指向「吃它的」。綠色植物會行光合作用自己製造養分，叫生產者，排在食物鏈的「最開頭」。

💡 **解題心法與重要規則**：箭頭：被吃者 → 吃者；第一個一定是生產者（植物）。

⚠️ **小心別犯錯**：箭頭不是「誰吃誰」的方向，畫反是最常見的錯誤。

</details>

### 2. 能量越往上傳越少

- 🧠 **一句話記住**：能量：越往上越少；累積的毒物：越往上越多。
- 🌱 **生活例子**：要養活一隻老鷹，需要很多隻蛇、更多的青蛙和非常多的昆蟲與植物。

**先想想看**：遮住下面的說明，用自己的話說說「能量越往上傳越少」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

生物把吃進去的能量大部分用來活動和維持體溫，只有一小部分（約十分之一）能傳到下一層。所以食物鏈越往上，生物的數量通常越少。不過，難以排出的有毒物質卻會越往上累積越多。

💡 **解題心法與重要規則**：能量：越往上越少；累積的毒物：越往上越多。

⚠️ **小心別犯錯**：最上層的掠食者體內，毒物濃度通常最高。

</details>

### 3. 生物多樣性與外來種

- 🧠 **一句話記住**：生物多樣性三層次：遺傳、物種、生態系。
- 🌱 **生活例子**：綠鬣蜥、福壽螺都是臺灣常見的外來入侵種，會破壞農作物和生態。

**先想想看**：遮住下面的說明，用自己的話說說「生物多樣性與外來種」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

生物多樣性包含：同種生物的差異（遺傳多樣性）、生物種類多不多（物種多樣性）、環境種類多不多（生態系多樣性）。外來入侵種沒有天敵，會大量繁殖、搶走本土生物的生存空間。

💡 **解題心法與重要規則**：生物多樣性三層次：遺傳、物種、生態系。

⚠️ **小心別犯錯**：不要隨意放生寵物或外來生物，可能造成生態災難。

</details>

### 4. 生產者、消費者、分解者（延伸應用）

- 🧠 **一句話記住**：生產者：自己造養分；消費者：吃別的生物；分解者：把死去的生物變回養分。
- 🌱 **生活例子**：草（生產者）→ 兔子（消費者）→ 老鷹（消費者）。落葉和動物屍體被香菇、細菌（分解者）分解，養分回到土裡，讓草再長出來。
- 🎯 **段考命題常考方式**：【什麼時候用】判斷角色時問：它是自己造養分、吃別人，還是分解死去的生物？

**先想想看**：遮住下面的說明，用自己的話說說「生產者、消費者、分解者」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

生態系裡的生物有三種角色：生產者（植物，利用陽光自己製造養分）、消費者（動物，要吃別的生物）、分解者（細菌、真菌，把死掉的生物和排泄物分解，養分回到土壤）。三種角色缺一不可。

💡 **解題心法與重要規則**：生產者：自己造養分；消費者：吃別的生物；分解者：把死去的生物變回養分。

⚠️ **小心別犯錯**：香菇等蕈類不是植物，不會行光合作用，它是分解者。

</details>

## 🧩 段考回推補強：考卷會考、容易漏掉的觀念

### 生物之間的五種互動

| 關係 | 例子 | 誰得益 |
| :--- | :--- | :--- |
| 掠食 | 黑冠麻鷺吃蚯蚓 | 掠食者得益，獵物受害 |
| 競爭 | 珊瑚和海綿搶空間 | 雙方都可能受影響 |
| 互利共生 | 小丑魚和海葵 | 雙方都得益 |
| 片利共生 | 鮣魚吸附在鯊魚身上 | 一方得益，另一方無明顯影響 |
| 寄生 | 跳蚤和狗 | 一方得益，另一方受害 |

食物、空間、伴侶不足時，都可能出現競爭。

### 族群、群集、生態系

- **族群**：同一區域、同一種生物的集合。
- **群集**：同一區域、所有不同種生物的集合。
- **生態系**：群集加上環境（陽光、水、土壤、空氣）。

調查池塘時要水面和水底都看，不能只看一處。一份族群紀錄只能說明該區域，不能推論整個校園。

### 能量金字塔和生物累積

能量沿食物鏈傳遞時，每一層大多以熱的形式散失，只有一小部分傳到下一層，**不會 100% 傳遞**。所以最底層生產者能量最多。

難分解的毒素則相反，會沿食物鏈越積越多，這叫**生物累積**。例如蛙類中毒，以牠為食的猛禽也可能受害。

### 社會性昆蟲的分工

螞蟻、蜜蜂是群體生活，會分工合作尋找食物、搬運食物和建築巢穴。蟻巢裡不只一隻螞蟻，通常有蟻后、工蟻等不同分工。這種行為增加了整個族群生存機會。

### 寄生和共生的差別

寄生是一方得利、另一方受害，例如跳蚤吸狗的血。共生中雙方或一方得利，且另一方不會明顯受害。判斷時問：雙方是變好、沒影響，還是變差？

📐 **解題步驟**：

**第 17 題**【選擇・課綱】　外來種為什麼可能造成生態問題？

**A.** 它們都比較大

**C.** 寄生  
**D.** 競爭

📐 **解題步驟**：

⚠️ **易錯提醒**：寄生和掠食都是一方受害，但寄生通常不立刻致死。
