## 📌 單元標題與學習目標
**單元 1：臺灣的民主之路與政府組織**
（108課綱核心素養：社-E-A2、社-E-B1、社-E-C2）
**學習目標：** 了解臺灣從戒嚴到民主化的艱辛歷程，認識政府五院的運作方式，並明白身為公民的基本權利與義務。

## 🎯 學習導引：為什麼要學這個？
想像一下，如果有一天班長不是大家投票選出來的，而是老師直接指派，而且規定大家不能提出反對意見，也不能隨便和同學聚在一起聊天，你會有什麼感覺呢？這聽起來很不可思議，但在過去的臺灣，真的是這樣喔！了解民主的發展，能幫助我們珍惜現在自由表達意見的權利，並知道如何透過正確的管道來參與社會。

## 🔑 核心觀念 1：臺灣民主化歷程
臺灣的民主不是天上掉下來的，而是經過許多人的努力。
- **五大里程碑**：戒嚴時期 $\rightarrow$ 解嚴 $\rightarrow$ 國會全面改選 $\rightarrow$ 總統直選 $\rightarrow$ 政黨輪替。
- **二二八事件與白色恐怖**：在民主化之前，臺灣經歷了一段缺乏人權保障的時期。二二八事件及隨後的白色恐怖，讓許多知識份子和無辜民眾受害。

🏠 **生活案例**：
1. **班級幹部選舉**：現在我們可以自由參選和投票選出班長，這就像是「總統直選」，每個人都有平等的投票權。
2. **社團活動自由**：以前的人不能隨便組社團（黨禁），現在你可以自由參加魔術社、籃球社，這是因為「解嚴」後保障了集會結社的自由。

## 🔑 核心觀念 2：政府五院組織與職權
為了避免權力過度集中，我國政府採取「五權分立」的制度，彼此分工合作又互相制衡。

📊 **五院職權完整對比表**

| 院別 | 具體功能 | 產生方式 | 簡單來說就像... |
| :--- | :--- | :--- | :--- |
| **行政院** | 負責推動國家各項政策與施政 | 由總統任命院長 | 負責做事的「執行團隊」 |
| **立法院** | 負責審查法案、預算，監督行政 | 人民選舉產生立法委員 | 制定規則的「規則委員會」 |
| **司法院** | 負責審判民事、刑事與行政訴訟 | 總統提名，立法院同意 | 解決糾紛的「裁判」 |
| **考試院** | 負責國家考試、公務員銓敘 | 總統提名，立法院同意 | 選拔人才的「考試委員」 |
| **監察院** | 負責調查公務員違法失職、彈劾 | 總統提名，立法院同意 | 糾正錯誤的「糾察隊」 |

## 🔑 核心觀念 3：憲法四大基本權利與四大義務
憲法是國家的根本大法，保障了我們最重要的權利，同時也規定了我們的義務。

📊 **權利與義務整理表**

| 類別 | 項目 | 內容說明與生活例子 |
| :--- | :--- | :--- |
| **權利** | **平等權** | 男女平權，各種族群都享有相同待遇。 |
| **權利** | **自由權** | 言論自由、信仰自由（可以自由決定信什麼宗教）。 |
| **權利** | **受益權** | 生病時可以使用健保，遇到困難可請政府協助。 |
| **權利** | **參政權** | 滿一定年齡可以投票選舉市長或總統。 |
| **義務** | **納稅** | 父母賺錢需要繳稅，讓政府有錢造橋鋪路。 |
| **義務** | **服兵役** | 依法服兵役，保衛國家安全。 |
| **義務** | **受教育** | 國民基本教育是義務，所以你現在要上學！ |
| **義務** | **守法** | 遵守交通規則等各項法律。 |

🏠 **生活案例**：
- **行使權利**：在班會上舉手表決決定畢業旅行的地點，這是行使類似「參政權」的表現。

## 🔑 核心觀念 4：地方政府組織
除了中央政府，我們還有負責管理地方事務的地方政府。
- **縣市長與縣市議會**：市長負責市政（如鋪路、辦活動），議會負責監督市長。
- **里長**：是最基層的地方公職人員，處理社區的大小事，如清水溝、廣播通知。

## 🧠 迷思大破解
❌ **錯誤迷思 1**：自由就是想做什麼就做什麼，沒有人可以管我。
✅ **正確觀念**：自由是以「不侵犯他人的自由與權利」為前提。例如你有言論自由，但不能隨便在網路上辱罵同學。

❌ **錯誤迷思 2**：政府官員是長官，我們只能聽他們的命令。
✅ **正確觀念**：在民主社會，政府的權力來自人民，人民可以透過選舉、罷免等參政權來監督政府。

❌ **錯誤迷思 3**：憲法規定的權利和義務，那是大人的事，跟小學生無關。
✅ **正確觀念**：受教育就是你正在履行的義務，同時你享有國家提供教育資源的受益權，這都跟憲法有關！

## 📊 本單元重點速查整理表格
**臺灣民主化重大事件時間軸表格 (1947-2000)**

| 年代 | 重大事件 | 事件意義與影響 |
| :--- | :--- | :--- |
| 1947 | 二二八事件 | 爆發嚴重官民衝突，隨後進入長期威權統治。 |
| 1949 | 宣布戒嚴 | 限制人民多項自由權利（黨禁、報禁等）。 |
| 1987 | 宣布解嚴 | 恢復憲法保障的人民權利，臺灣邁向民主化。 |
| 1991-92| 國會全面改選 | 終止「萬年國會」，民意代表真正由臺灣人民選出。 |
| 1996 | 總統首次直選 | 人民親自投票選出國家元首，民主一大步。 |
| 2000 | 首次政黨輪替 | 政權和平轉移，象徵臺灣民主制度日趨成熟。 |

## 🌍 你知道嗎？
💡 臺灣的「健保制度」在全世界非常有名！這是國家為了保障人民的「生存與健康權利」（屬於受益權）而設立的。很多外國人來臺灣，都對我們能用相對便宜的費用獲得高品質的醫療服務感到驚訝呢！

## 🚀 +10% 現代素養前瞻新知
隨著科技發展，現在有所謂的「**數位民主（e-Democracy）**」。例如臺灣的「公共政策網路參與平臺」，只要有一定數量的人在網路上對某個議題連署（例如：延後上學時間），政府就必須正式回應。這讓公民參與變得更快速、更即時！我們不需要等到選舉，也能在日常中表達對政策的意見。
