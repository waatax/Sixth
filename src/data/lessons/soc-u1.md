# 單元 1：臺灣的民主之路與政府組織

臺灣從戒嚴威權走向自由民主，這段歷程凝聚了無數前人的努力，是全球民主發展的亮眼典範！

---

## 🏛️ 核心觀念一：臺灣民主化歷程

### 關鍵里程碑
1.  **戒嚴時期（1949~1987）**：實施戒嚴令，限制人民集會、結社、言論與出版自由。
2.  **解除戒嚴（1987年）**：蔣經國總統宣告解嚴，開放黨禁與報禁，人民重獲憲法保障之基本權利。
3.  **國會全面改選（1991~1992年）**：萬年國代與立委退職，由全體臺灣人民直選中央民意代表。
4.  **總統直接民選（1996年）**：臺灣首次由全體公民一人一票直選國家元首。
5.  **政黨輪替與和平轉型（2000年起）**：政權和平交接，奠定成熟的民主政治體制。

## ⚖️ 核心觀念二：中央政府組織與五權分立

中華民國憲法設計為「五院架構」，各司其職並相互制衡：

| 機關名稱 | 核心職權 | 院長產生方式 / 主要功能 |
| :--- | :--- | :--- |
| **行政院** | 國家最高行政機關，推動各項政務 | 閣揆由總統直接任命，負責施政 |
| **立法院** | 國家最高立法機關，制定法律、審查預算 | 由全國人民直接選舉立法委員組成 |
| **司法院** | 國家最高司法機關，掌理解釋憲法、審判 | 大法官與法官獨立審判，守護正義 |
| **考試院** | 掌管公務人員考選、任用、銓敘與保障 | 確保公務體系公平選拔人才 |
| **監察院** | 掌管彈劾、糾舉及糾正權，行使審計權 | 監督政府官員與機關是否違法失職 |

## 🗳️ 核心觀念三：公民的權利與義務

*   **人民的基本權利**：
    *   **平等權**：法律之前人人平等，無分男女、宗教、種族、階級。
    *   **自由權**：人身、居住、遷徙、言論、講學、著作、出版自由。
    *   **受益權**：生存權、工作權、財產權、受國民教育權。
    *   **參政權**：選舉、罷免、創制、複決權及應考試服公職之權。
*   **人民的四大義務**：納稅、服兵役、受國民教育、遵守憲法與法律。
