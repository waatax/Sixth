# 📌 單元標題與學習目標：單元 4：社會服務與公民實踐——用愛與行動溫暖世界 (108課綱 綜-E-B3, 綜-E-C3)

**學習目標**：
理解服務學習的真正意涵與四部曲，能規劃並參與校園或社區的志工服務行動，從實踐與反思中培養關懷社會的少年公民素養，體會施比受更有福的生命價值。

## 🎯 學習導引：為什麼要學這個？

你有沒有看過便利商店裡的零錢箱？或者是看過穿著背心在街頭指揮交通的導護志工？你可能會想：「他們為什麼要花自己的休息時間去幫忙別人，又沒有錢拿？」其實，「服務他人」有一種神奇的魔法。當我們把關注的眼光從「自己」身上，移到「別人」或「社會」的需求上時，你會發現自己的力量比想像中還要大！這堂課，我們不只要當個乖學生，更要化身為「少年公民」，學習如何用實際行動，把溫暖和愛心散播到世界角落，並且在服務中，收穫最珍貴的自我成長！

## 🔑 核心觀念 1：服務學習四部曲 (PARE)

「服務學習」(Service-Learning) 不只是單純的做義工（勞動），而是「服務」加上「學習」。為了讓服務更有意義，我們必須遵循國際通用的四部曲：

📊 **服務學習四部曲完整表格**

| 階段 (英文簡稱) | 中文名稱 | 階段重點與任務 | 具體活動範例 (以去淨灘為例) |
| :---: | :--- | :--- | :--- |
| **P** | **準備 (Preparation)** | 發現問題、蒐集資料、規劃方案。 | 認識海洋廢棄物種類、準備夾子手套、規劃交通與分工。 |
| **A** | **行動 (Action)** | 實地參與、團隊合作、執行計畫。 | 在海灘上實際撿拾垃圾、分類並記錄垃圾種類。 |
| **R** | **反思 (Reflection)** | **最重要的一步！** 檢討過程、思考意義。 | 大家坐下來討論：「為什麼會有這麼多吸管？我們生活能怎麼改變？」 |
| **C** | **慶賀 (Celebration)** | 分享成果、肯定彼此、感謝團隊。 | 在朝會上向全校發表淨灘成果、頒發感謝狀、大家一起吃點心慶祝。 |

## 🔑 核心觀念 2：少年公民三大參與面向與具體方案

六年級的我們，能為社會做什麼呢？可以從身邊最親近的三個面向開始：

📊 **校園、社區、環境服務行動方案比較表**

| 參與面向 | 核心目標 | 適合小學生的具體志工服務方案 |
| :--- | :--- | :--- |
| 🏫 **校園服務** | 讓學校成為更好的學習環境 | - 圖書館圖書志工 (幫忙上架書籍、整理書報)<br>- 資源回收小尖兵 (協助分類宣導)<br>- 低年級課業輔導小老師 |
| 🏘️ **社區關懷** | 關心社區弱勢與公共空間 | - 安養院探訪 (陪爺爺奶奶唱歌、讀報、聊天)<br>- 社區公園打掃維護<br>- 募集發票或物資捐贈給家扶中心 |
| 🌳 **環境倡議** | 保護地球與生態永續 | - 參與淨灘或淨山活動<br>- 製作海報在社區宣導「減塑生活」<br>- 復育社區綠地、種植本土原生植物 |

🏠 **生活案例一：社區清潔**
週末時，班上同學自發性地組成「打擊髒亂小隊」，帶著夾子和垃圾袋，把學校附近的社區公園打掃得乾乾淨淨。不僅讓社區居民有更好的運動空間，路過的阿姨還稱讚他們是小英雄！

🏠 **生活案例二：替獨居長輩讀報**
小華參加了社區中心的志工隊，每個禮拜六早上都會去陪獨居的李爺爺。因為李爺爺老花眼看不清楚，小華就會讀報紙上的趣事給他聽。爺爺每次都笑得很開心，小華也從爺爺那裡聽到了很多以前的歷史故事。

## 🔑 核心觀念 3：反思學習與生命價值的成長

做完服務後，一定要寫「反思學習單」。透過反思，服務才不會只是「勞動」，而是轉化為「生命經驗」。常用的反思法是 **4F引導思考法**：

📊 **反思學習單範本表格 (4F法)**

| 4F 項目 | 意義 | 引導問題 | 填寫範例 (以安養院探訪為例) |
| :--- | :--- | :--- | :--- |
| **Fact (事實)** | 客觀描述發生了什麼事 | 我做了什麼？看到了什麼？ | 今天我們去安養院表演直笛，並陪爺爺奶奶聊天。 |
| **Feeling (感受)** | 當下的情緒與感覺 | 我覺得開心/挫折嗎？為什麼？ | 一開始有點害怕不知道說什麼，但看到奶奶笑著鼓掌，我覺得很溫暖感動。 |
| **Finding (發現)** | 從中學到了什麼新知識或觀點 | 我對這件事或對自己有什麼新發現？ | 我發現長輩其實很怕孤單，他們需要的不是物質，而是陪伴。 |
| **Future (未來)** | 未來可以怎麼做 | 下次我可以怎麼改進？生活中如何應用？ | 我決定以後每天放學回家，也要多陪自己的阿公阿嬤聊天！ |

## 🔑 核心觀念 4：如何寫一份簡單的服務企劃書

想要發起一個服務行動，我們需要一份好的企劃書（對應到四部曲的「準備」階段）。

📝 **簡易服務企劃書範本**
1. **行動名稱**：「愛心發票大募集——救救流浪貓」
2. **服務對象**：XX市流浪動物保護協會
3. **行動動機**：冬天到了，看到新聞說流浪動物收容所缺乏購買飼料的資金。
4. **具體作法**：全班分五組，利用下課時間在各年級走廊宣導，設置發票收集箱，為期一週。
5. **所需資源**：自製海報3張、紙箱改裝的發票箱5個、膠帶。
6. **預期效益**：預計募得 500 張發票，並喚起全校愛護動物的意識。

## 🧠 迷思大破解

1. ❌ **迷思一：我是小孩沒有錢，等我長大賺大錢再來做公益就好。**
   ✅ **正確觀念**：錯！服務社會不一定要捐錢。你的時間、你的微笑、你的專長（例如唱歌、畫海報、講故事），都是極具價值的貢獻。愛心沒有年齡限制！
2. ❌ **迷思二：去做志工只是為了拿「服務時數」來升學加分用？**
   ✅ **正確觀念**：錯！如果只為了時數去敷衍了事，那是浪費生命。真正的服務學習強調「用心參與」與「反思成長」。你會發現，過程中獲得的快樂和成就感，遠比那張證書珍貴。
3. ❌ **迷思三：去服務別人，是我在「施捨」他們，我比較優越。**
   ✅ **正確觀念**：錯！服務是平等的互相學習。我們常說「教學相長」，在服務中我們也是「施受同體」。我們付出了時間，但從對方身上學到了生命故事、堅韌的態度，其實我們「得到」的往往比「付出」的更多。

## 🌍 你知道嗎？

💡 **「微型圖書館」(Little Free Library)**
在世界各地，有一種由社區居民發起的可愛行動叫做「微型圖書館」。人們會在自己家門口或社區公園，設立一個像鳥舍一樣的小木箱，裡面放滿書。規則是：「拿走一本書，就放回一本書」。這不需要花大錢，卻成功在社區裡散播了閱讀的樂趣，這也是一種非常棒的社區服務與分享行動喔！

## 🚀 +10% 現代素養前瞻新知

**聯合國 SDGs 與數位公益倡議 (Digital Activism)**
我們做的環境保護或社區關懷，其實都呼應了聯合國提出的「2030永續發展目標 (SDGs)」(例如：消除飢餓、優質教育、氣候行動)。在現代，做公益不一定要走出門，你還可以透過「數位倡議」！例如，你可以利用 Canva 製作精美的 SDGs 倡議海報發布在班級網頁，或者拍攝一部呼籲大家節約用水的短影音。利用網路的力量，你的聲音可以傳達到全世界，這就是現代數位少年公民的超能力！
