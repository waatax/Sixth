# 單元 4：修辭的魔法與成語百寶箱

善用修辭能讓文章生動活潑，掌握成語能讓表達精煉精確！

---

## ✨ 核心觀念一：國小高年級必學修辭法

### 1. 譬喻 (Metaphor & Simile)
將甲事物比作具有相似特徵的乙事物。
*   **明喻**（有「像、如、好比」）：他的笑容像陽光一樣燦爛。
*   **隱喻/暗喻**（用「是、成了」）：母親是避風的港灣。
*   **借喻**（不出現本體和比喻詞，直接用喻體代替）：別讓心中的雜草遮蔽了陽光。

### 2. 擬人 (Personification)
將物賦予人的情感、動作或語言。
*   *例句*：春風輕輕撫摸著大地，小草悄悄探出頭來打招呼。

### 3. 排比 (Parallelism)
三個或以上結構相同或相似、語氣一致的詞組或句子排列。
*   *例句*：讀書使人充實，討論使人機智，作文使人準確。

### 4. 誇飾 (Hyperbole)
故意言過其實，加強語氣與渲染效果。
*   *例句*：教室裡安靜得連一根針掉在地上都聽得見。

### 5. 設問 (Rhetorical Questions)
*   **提問**（自問自答）：什麼是真正的勇氣？那就是面對困難永不放棄。
*   **反問/激問**（問而不答，答案在問題反面）：難道我們能眼睜睜看著環境被破壞嗎？
*   **懸問**（心中存疑，無確定答案）：那片森林深處，到底藏著什麼秘密呢？

## 📚 核心觀念二：常見高頻成語分類與活用

| 類別 | 精選成語 | 意義與用法 |
| :--- | :--- | :--- |
| **學習與智慧** | **舉一反三** | 能從一件事情類推理解其他事情 |
| | **融會貫通** | 將各方面的知識融合為完整系統 |
| **恆心與毅力** | **水滴石穿** | 只要堅持不懈，微小力量也能成就大事 |
| | **鍥而不捨** | 不斷雕刻不放棄，比喻堅持到底 |
| **品德與待人** | **虛懷若谷** | 心胸謙虛寬廣得像山谷一樣 |
| | **推己及人** | 設身處地為他人著想，發揮同理心 |
