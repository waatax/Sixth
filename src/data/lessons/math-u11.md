## 🎯 學習導引：為什麼要學這個？

在國小一到五年級，當我們遇到問題時，常常習慣用「逆向算術」或「倒推法」來思考：
- 🍦 **生活情境 A（傳統算術思維）**：小明去超商買了 3 瓶鮮奶和一個 35 元的麵包，總共付了 140 元。請問 1 瓶鮮奶多少錢？
  - 過去的解法（倒推算術）：$(140 - 35) \div 3 = 105 \div 3 = 35$ 元。

但是，當問題變得更加複雜時：
- 🎢 **生活情境 B（複雜數量關係）**：哥哥的零用錢比弟弟的 2 倍多 50 元，如果兩人的零用錢合起來剛好是 650 元，請問弟弟有多少零用錢？
  - 這時候如果直接用倒推算術，腦袋很容易打結甚至算錯！

| 思考模式 | 算術思維（小學低中年級） | 代數思維（小六至國中） | 核心優勢 |
| :--- | :--- | :--- | :--- |
| **思維起點** | 從「已知結果」倒推回去找「起點」 | 將「未知數」設為 $x$，直接順著題意說故事 | 邏輯直接、順暢，絕不混亂 |

| **解題能力** | 僅能解決單純的四則運算題 | 能解決雞兔同籠、年齡問題、比例問題等各類難題 | 國中會考與高中數學必備核心工具 |

## 🔑 核心觀念 1：等式的本質與天平平衡原理

![等量公理與未知數方程求解模型 (Axiom of Equality)](./images/math_u11_concept1.svg)

### 1. 什麼是等式？
任何含有「等號 $=$」且左右兩邊數值相等的算式，就叫做 $\textcolor{#2196f3}{\textbf{等式}}$。
例如：
$$5 + 8 = 13 \quad \text{或} \quad x + 15 = 42$$

### 2. 天平的平衡哲學
想像一架靈敏的雙盤天平，當左盤與右盤重量一樣時，天平維持完美水平：
```text
           [ 天平平衡示意圖 ]
                ▲ 指針朝正中
           ┌────┴────┐
        ┌──┴──┐   ┌──┴──┐
        │ 左盤 │   │ 右盤 │
        │ A物 │   │ B物 │
        └─────┘   └─────┘
           A     =    B
```
- **核心規律**：如果天平目前處於平衡狀態，只要我們在**兩邊同時進行一模一樣的操作**，天平就**永遠保持平衡**！
  - 兩邊同時放入 5 克 $\rightarrow$ 依然平衡！
  - 兩邊同時拿走 3 克 $\rightarrow$ 依然平衡！
  - 兩邊物體重量同時翻倍 $\rightarrow$ 依然平衡！
  - 兩邊物體重量同時平分成一半 $\rightarrow$ 依然平衡！

## 🔑 核心觀念 2：四大等量公理解密

![等量公理與未知數 (Axiom of Equality) - 圖解 2](./images/math_u11_concept2.svg)

為了求出未知數 $x$ 的真正數值，我們的唯一目標就是：**讓等號的左邊只剩下孤零零的 $x$**（即 $x = \text{數字}$）！

```text
               ┌───────────────────────────────┐
               │    四大等量公理（天平平衡術）   │
               └───────────────┬───────────────┘
            ┌──────────────────┼──────────────────┐
            ▼                  ▼                  ▼
     【等量加法公理】   【等量減法公理】   【等量乘法與除法】
     若 A = B           若 A = B           若 A = B
     則 A + C = B + C   則 A - C = B - C   則 A × C = B × C
                                           則 A ÷ C = B ÷ C (C ≠ 0)
```

### 1. 等量減法公理（消滅加數）
- 形式：$x + 12 = 30$
- 思考：$x$ 身邊多加了 $12$，怎樣才能讓 $x$ 變回一個人？
- 技巧：**等號兩邊同時減去 $12$**！
  $$x + 12 - 12 = 30 - 12 \implies x = 18$$

### 2. 等量加法公理（消滅減數）
- 形式：$x - 25 = 40$
- 思考：$x$ 被扣掉了 $25$，怎樣還原？
- 技巧：**等號兩邊同時加上 $25$**！
  $$x - 25 + 25 = 40 + 25 \implies x = 65$$

### 3. 等量除法公理（消滅乘數倍數）
- 形式：$4x = 52$（注意：$4x$ 代表 $4 \times x$）
- 思考：$x$ 被放大了 $4$ 倍，如何還原成 $1$ 個 $x$？
- 技巧：**等號兩邊同時除以 $4$**！
  $$(4x) \div 4 = 52 \div 4 \implies x = 13$$

### 4. 等量乘法公理（消滅除數分數）
- 形式：$\frac{x}{5} = 9$（即 $x \div 5 = 9$）
- 思考：$x$ 被分成了 $5$ 等份，如何還原完整數值？
- 技巧：**等號兩邊同時乘以 $5$**！
  $$\frac{x}{5} \times 5 = 9 \times 5 \implies x = 45$$

## 📊 本單元核心考點與重點公式速查表

![等量公理與未知數 (Axiom of Equality) - 圖解 4](./images/math_u11_concept4.svg)

| 核心知識點 / 考點主題 | 📐 核心公式 / 定理 / 規則架構 | 💡 黃金記憶口訣 / 速記法 | ⚠️ 常考易錯陷阱 / 必勝解題秘訣 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{等量加減公理}}$ | 若 $A = B$，則 $A \pm C = B \pm C$ | **「多加就要減，被減就要加；兩邊同操作，天平不歪斜」** | ❌ 容易只在左邊減去數字，忘記右邊也要同時減去相同數字！ |
| $\textcolor{#e91e63}{\textbf{等量乘除公理}}$ | 若 $A = B$，則 $A \times C = B \times C$<br>$A \div C = B \div C$ ($C \ne 0$) | **「乘倍同除回歸一，分母同乘化整數；除數絕對不可零」** | ⚠️ 等量除法中，兩邊同除的數值 $C$ 絕對不能是 $0$（因為除數不可為 0）。 |
| $\textcolor{#9c27b0}{\textbf{複合兩步方程求解}}$ | 先移常數加減，再移係數乘除：<br>$ax + b = c \implies ax = c - b \implies x = \frac{c - b}{a}$ | **「先拆加減外圍牆，再除乘號核心樑」** | ❌ 解 $2x + 6 = 20$ 時，切勿先除以 2 卻忘記 6 也要除以 2；最穩妥是先減 6 得到 $2x = 14$，再除以 2！ |
| $\textcolor{#2e7d32}{\textbf{含有括號的等式}}$ | $a(x + b) = c$：可先將兩邊同除以 $a$，或利用分配律展開 $ax + ab = c$ | **「遇括號先看倍數，能整除直接除，不能除用分配律」** | 💡 當右邊數字是外圍括號倍數的倍數時（如 $3(x+4)=24$），兩邊直接除以 3 最快！ |

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【複合運算基礎題】
- 📌 **題目情境**：解方程式 $4x + 18 = 50$，求 $x$ 的值。
- 💡 **思考關鍵**：$x$ 的身邊有「乘 4」和「加 18」，按照解題原則，先消去加號（外圍），再消去乘號（內圍）。
- 📐 **詳盡步驟**：
  1. 兩邊同時減去 $18$（等量減法公理）：
     $$4x + 18 - 18 = 50 - 18$$
     $$4x = 32$$
  2. 兩邊同時除以 $4$（等量除法公理）：
     $$4x \div 4 = 32 \div 4$$
     $$\mathbf{x = 8}$$
  3. **驗算**：把 $x = 8$ 代入原式：$4 \times 8 + 18 = 32 + 18 = 50$（完全正確！）。

### 📝 範例 2：【生活年齡應用題】
- 📌 **題目情境**：爸爸今年的年齡是小華年齡的 $3$ 倍少 $2$ 歲。已知爸爸今年 $40$ 歲，請問小華今年幾歲？
- 💡 **思考關鍵**：題目要求小華年齡，將小華年齡設為 $x$，再根據「3倍少2歲等於40歲」列式。
- 📐 **詳盡步驟**：
  1. **假設**：設小華今年 $x$ 歲。
  2. **列式**：小華的 3 倍是 $3x$，少 2 歲是 $3x - 2$。
     $$3x - 2 = 40$$
  3. **求解**：
     - 兩邊同加 $2$：$3x = 42$
     - 兩邊同除以 $3$：$x = 14$
  4. **作答**：小華今年 $\mathbf{14}$ 歲。

## 🧠 迷思大破解

❌ **迷思 1**：解方程式只要「把數字移到等號另一邊隨便變號」就好了，不用管什麼等量公理。
✅ **正確觀念**：所謂的「移項法則」本質就是「等量公理的快速簡寫」！如果不知道背後是因為「天平兩邊同時減去該數」，在遇到負數或乘除法時（例如 $-2x = 8$ 或 $x \div 3 = 6$），學生就會頻繁出現符號錯亂。理解天平平衡，才是永不出錯的正道！

❌ **迷思 2**：在方程式 $3x = 12$ 中，$x = 12 - 3 = 9$。
✅ **正確觀念**：$3x$ 代表的是「$3 \times x$」，乘號省略了，不是加號！要消去乘數 3，必須使用「等量除法公理」兩邊同除以 3：$x = 12 \div 3 = 4$。

❌ **迷思 3**：等量除法公理中，兩邊可以同時除以任何數字，包括 0。
✅ **正確觀念**：數學世界中，**絕對不能除以 0**！因為任何數除以 0 在數學上是「無意義（Undefined）」的。因此等量除法公理必須嚴格限制除數 $C \ne 0$。

❌ **迷思 4**：列式解應用題時，可以直接把算術答案算出來再倒貼一個 $x$。
✅ **正確觀念**：列式的精髓是「重現題目情境的等量關係」！例如「小明原有 $x$ 元，買文具花了 30 元後剩 70 元」，必須寫成 $x - 30 = 70$，而不是直接寫 $x = 70 + 30$。學會寫出平衡方程，到了國中遇到雙未知數時才能迎刃而解！

## ✏️ 隨堂自我小練習

1. **(計算題)** 解方程式：$5x - 15 = 45$，求 $x$。
   - **詳細解析**：
     - 第一步：兩邊同時加上 15（等量加法）：$5x = 45 + 15 = 60$
     - 第二步：兩邊同時除以 5（等量除法）：$x = 60 \div 5 = 12$
   - **答案**：$x = 12$。

2. **(計算題)** 解方程式：$\frac{x + 8}{3} = 10$，求 $x$。
   - **詳細解析**：
     - 第一步：分母為 3，兩邊同時乘以 3（等量乘法）：$x + 8 = 10 \times 3 = 30$
     - 第二步：兩邊同時減去 8（等量減法）：$x = 30 - 8 = 22$
   - **答案**：$x = 22$。

3. **(應用題)** 班級舉辦同樂會，老師買了每包 25 元的餅乾若干包和一桶 120 元的果汁，總計花費 320 元。如果老師買了 $x$ 包餅乾，請問老師買了幾包餅乾？
   - **詳細解析**：
     - 設餅乾買了 $x$ 包，總價為 $25x$ 元。
     - 依題意列出平衡方程式：$25x + 120 = 320$
     - 兩邊同減 120：$25x = 200$
     - 兩邊同除以 25：$x = 8$
   - **答案**：老師買了 $8$ 包餅乾。

4. **(選擇題)** 下列哪一個運算步驟符合「等量公理」且運算完全正確？
   - (A) 若 $x + 7 = 15$，則 $x = 15 + 7$
   - (B) 若 $3x = 18$，則 $x = 18 \div 3 = 6$
   - (C) 若 $x - 5 = 20$，則 $x = 20 - 5 = 15$
   - (D) 若 $x \div 4 = 8$，則 $x = 8 \div 4 = 2$
   - **詳細解析**：
     - (A) 兩邊應同減 7，得 $x = 8$
     - (B) 兩邊同除以 3，得 $x = 6$，完全正確！
     - (C) 兩邊應同加 5，得 $x = 25$
     - (D) 兩邊應同乘 4，得 $x = 32$
   - **答案**：$\textcolor{#2e7d32}{\textbf{(B)}}$。

5. **(進階情境題)** 姊姊現有的存款比妹妹的 $3$ 倍多 $100$ 元。如果兩人把存款合在一起，剛好可以買一台價值 $1700$ 元的拍立得相機且剛好花完。請問妹妹現有存款是多少元？
   - **詳細解析**：
     - 設妹妹存款為 $x$ 元，則姊姊存款為 $(3x + 100)$ 元。
     - 兩人存款相加：$x + (3x + 100) = 1700$
     - 合併同類項：$4x + 100 = 1700$
     - 兩邊同減 100：$4x = 1600$
