## 🔑 核心觀念 1：物質的變臉秀——物理變化 vs 化學變化

世界上的物質隨時都在發生改變，我們可以把這些改變分成兩大類：

1. **物理變化**：只是外表、形狀或狀態（固、液、氣）改變了，但物質的**本質沒有變**，也沒有產生新物質。通常比較容易恢復原狀。
   - 🏠 實例：冰塊融化成水、撕碎紙張、把黏土捏成小狗、打破玻璃。
2. **化學變化**：物質的本質改變了，**產生了跟原本完全不一樣的新物質**。通常伴隨著發光、發熱、變色、產生氣體或沉澱，且很難恢復原狀。
   - 🏠 實例：紙張燃燒變成灰燼、鐵生鏽、蘋果切開變黃、食物發霉腐敗。

## 🔑 核心觀念 2：鐵生鏽的秘密與防鏽大作戰

鐵生鏽是一種**化學變化**。鐵金屬變成了脆弱、鬆散的氧化鐵（鐵鏽）。鐵鏽無法保護內部的鐵，如果不處理，鐵器會一直生鏽直到完全損壞。

**鐵生鏽的三大條件**（缺一不可）：
1. **鐵**（主角本身）
2. **氧氣**（空氣中就有）
3. **水分**（潮濕的環境）
*(⚠️ 催化劑：鹽分或酸性物質會讓生鏽速度大幅加快！所以海邊的腳踏車特別容易生鏽。)*

**四大防鏽法**（原理：隔絕水分與氧氣）：
1. **塗漆**：在鐵橋、大門上刷油漆。
2. **塗油**：在腳踏車鏈條、齒輪上塗潤滑油。
3. **電鍍/鍍鋅**：在鐵罐外面鍍上一層不易生鏽的金屬（如馬口鐵、白鐵）。
4. **製成合金**：加入鉻、鎳製成「不鏽鋼」（如家裡的不鏽鋼鍋、餐具）。

## 🔑 核心觀念 3：食物的隱形殺手——微生物生長條件

食物為什麼會腐敗？罪魁禍首是空氣中看不見的**微生物**（包括細菌、真菌如黴菌、酵母菌等）。當微生物在食物上大量繁殖並分解食物時，就會產生毒素和異味，這就是食物腐敗（化學變化）。

**微生物生長的四大條件**：
1. **養分**（食物本身）
2. **水分**（潮濕環境）
3. **溫暖的溫度**（大約 $20^\circ\text{C} \sim 40^\circ\text{C}$ 最活躍）
4. **空氣/氧氣**（大多數微生物需要）

---

## 🔑 核心觀念 4：食品保存法——與時間賽跑的魔法

要讓食物保存久一點，原理很簡單：就是**破壞微生物生長的條件**，讓它們無法繁殖！

### 📊 五大食品保存法完整比較表

| 保存方法 | 科學原理 | 🏠 食品實例 | 優缺點分析 |
| :--- | :--- | :--- | :--- |
| **冷凍/冷藏** | **降低溫度**，讓微生物休眠或減緩活動 | 鮮肉、鮮奶、冰淇淋 | 優點：保留原味；缺點：退冰後容易壞 |
| **脫水/乾燥** | **去除水分**，讓微生物渴死無法生長 | 芒果乾、香菇、肉乾、奶粉 | 優點：變輕易攜帶；缺點：口感會改變 |
| **糖漬/鹽醃** | 利用高濃度的糖/鹽，使微生物**脫水死亡** | 蜜餞、鹹魚、泡菜、果醬 | 優點：風味獨特；缺點：吃多不健康 |
| **真空包裝** | 抽走空氣，**隔絕氧氣**，讓好氧菌無法生存 | 米、茶葉、調理包 | 優點：防氧化防潮；缺點：有些厭氧菌仍可存活 |
| **高溫殺菌** | 利用超高溫直接**殺死微生物**後密封 | 罐頭、保久乳 | 優點：可常溫保存很久；缺點：營養可能流失 |

## 🧠 迷思大破解

❌ **迷思 1**：冰箱是萬能的！食物只要放進冰箱，就永遠不會壞。
✅ **正確觀念**：冰箱只能「減緩」微生物的生長速度，不能殺死它們！食物放冰箱太久，還是會發霉或腐壞的。

❌ **迷思 2**：鐵生鏽是因為被水「融化」了，這是一種物理變化。
✅ **正確觀念**：鐵生鏽是鐵和氧氣、水分發生反應，產生了全新的物質「氧化鐵」，所以這是百分之百的**化學變化**！

❌ **迷思 3**：只要是微生物讓食物發生的變化，就是「腐敗」，都不能吃。
✅ **正確觀念**：這要看是哪種微生物！如果是我們刻意控制特定有益微生物（如乳酸菌、酵母菌）來分解食物，這稱為「**發酵**」。例如：牛奶變成優格、黃豆變成醬油、麵團變成麵包，這些發酵食品不但美味，對身體也有益處！

| 比較項目 | 物理變化 | 化學變化 |
| :--- | :--- | :--- |
| **定義** | 物質形態改變，本質未變 | 物質發生反應，產生新物質 |

| **可否輕易恢復原狀？**| ✅ 多數可以（如冰變水可再結冰） | ❌ 多數不行（如紙燒成灰無法還原） |
| **生活實例** | 切碎青菜、水結冰、打破碗、折紙 | 炒熟青菜、鐵生鏽、放煙火、消化食物 |

## ✏️ 隨堂自我小練習

1. **(選擇題)** 下列哪一種現象屬於「物理變化」？
   (A) 媽媽把一塊生豬肉煮成熟的紅燒肉
   (B) 哥哥把喝完的鋁箔包踩扁
   (C) 蘋果切開放在桌上變成了咖啡色
   (D) 腳踏車籃子生鏽了
   **解答**：(B)。踩扁鋁箔包只是形狀改變，沒有產生新物質。其他都是化學變化。

2. **(選擇題)** 小明想保護他的腳踏車鏈條不要生鏽，他應該怎麼做最合適？
   (A) 塗上一層厚厚的水  (B) 灑上一層鹽巴  (C) 塗抹潤滑油  (D) 用吹風機加熱
   **解答**：(C)。潤滑油可以隔絕空氣和水分。水和鹽分反而會加速生鏽。

3. **(選擇題)** 古時候的人沒有冰箱，他們常把捕到的魚抹上厚厚的鹽巴做成鹹魚。請問鹽醃法可以防腐的主要原理是什麼？
   (A) 鹽巴會散發冷氣降低溫度
   (B) 高鹽分會讓微生物脫水死亡無法繁殖
   (C) 鹽巴可以隔絕氧氣
   (D) 鹽巴本身含有抗生素
   **解答**：(B)。

4. **(簡答題)** 請列舉鐵生鏽必備的三個條件。
   **解答**：鐵、水分、氧氣（空氣）。

美國紐約著名的自由女神像，其實是由「銅」打造的！剛建造好時，她是閃亮的紅銅色。但幾十年來，銅金屬暴露在空氣中，和氧氣、水分、二氧化碳發生了化學變化，產生了「銅鏽」。不過特別的是，綠色的銅鏽和脆弱的鐵鏽不同，銅鏽非常緻密，反而形成了一層保護膜，保護內部的銅不再繼續損壞喔！

## 🚀 +10% 現代素養前瞻新知

**♻️ 從太空科技到生活：真空冷凍乾燥技術！**
你知道太空人在太空中吃的草莓是長怎樣的嗎？為了解決食物保存和重量的問題，科學家發明了「真空冷凍乾燥技術 (Freeze-Drying)」。
先把食物冷凍在零下幾十度，然後在真空環境中加熱，讓食物中的冰直接「昇華」成水蒸氣抽走。這樣做出來的草莓乾，不但能保存好幾年不會壞，重量變得很輕，而且只要加水，就能幾乎恢復原本的味道和營養！現在這項技術已經普及到我們生活中的蔬菜包、即溶咖啡裡囉！
