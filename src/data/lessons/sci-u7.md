## 🔑 核心觀念 1：物質的變臉秀——物理變化 vs 化學變化

![物質變化——防鏽與防腐 (Rust & Preservation) - 圖解 1](./images/sci_u7_concept1.svg)

在自然界與日常生活中，物質發生的所有變化皆可歸納為兩大類別：

```text
       【物理變化：分子間距改變，分子本質不變】        【化學變化：原子重組，產生全新物質】
         [ 🧊 冰塊 ] ──加熱融化──► [ 💧 水滴 ]       [ 🪵 木材 ] ──燃燒反應──► [ 💨 CO₂ + 灰燼 ]
       (水分子 H₂O 依然是 H₂O，只是排列鬆散)           (纖維素與氧氣反應，轉化為二氧化碳與灰)
```

## 🔑 核心觀念 2：鐵生鏽的秘密與防鏽大作戰

![物質變化——防鏽與防腐 (Rust & Preservation) - 圖解 2](./images/sci_u7_concept2.svg)

$\textcolor{#ff9800}{\textbf{鐵生鏽}}$ 是一種緩慢進行的$\textcolor{#2196f3}{\textbf{氧化化學反應}}$。堅硬銀灰色的鐵元素，與空氣中的氧氣和水分長期接觸，轉變為鬆散、多孔、無金屬光澤且容易脫落的紅褐色$\textcolor{#e91e63}{\textbf{水合氧化鐵（鐵鏽，}\text{Fe}_2\text{O}_3\cdot x\text{H}_2\text{O}\textbf{）}}$。

$$\textcolor{#2196f3}{\textbf{鐵生鏽化學反應式：}} \textcolor{#e91e63}{\textbf{鐵 (Fe)}} + \textcolor{#2196f3}{\textbf{氧氣 (}\text{O}_2\textbf{)}} + \textcolor{#00bcd4}{\textbf{水 (}\text{H}_2\text{O}\textbf{)}} \longrightarrow \textcolor{#ff9800}{\textbf{紅褐色鐵鏽 (氧化鐵)}}$$

```text
                  【 鐵生鏽條件四組實驗對比示意圖 】
  ┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
  │ [ A. 乾燥空氣組 ]│ [ B. 基準對照組 ]│ [ C. 隔絕空氣組 ]│ [ D. 鹽水加速組 ]│
  │   (只有氧氣)    │  (有氧氣＋有水) │   (只有水無氧)  │ (氧＋水＋鹽分)  │
  │   ───────────   │   ───────────   │   ───────────   │   ───────────   │
  │   [ 試管加塞 ]  │   [ 敞開試管 ]  │   [ 水面覆蓋油層]│   [ 敞開試管 ]  │
  │   [ 乾燥劑無水] │   [ 浸泡純水 ]  │   [ 煮沸水去氧氣]│   [ 浸泡濃鹽水 ]│
  │   結果：❌ 不鏽 │   結果：✅ 慢生鏽 │   結果：❌ 不鏽 │   結果：💥 狂生鏽│
  └─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

### 🛡️ 四大工程防鏽技術——隔絕氧氣與水分

```text
                               【 防鏽核心原理：隔絕水與氧氣 】
                                            │
         ┌──────────────────┬───────────────┴──────────────┬──────────────────┐
         ▼                  ▼                              ▼                  ▼
    【1. 塗漆隔絕】    【2. 塗油潤滑】               【3. 電鍍防護】    【4. 冶煉不鏽鋼合金】
    (鐵門、大橋刷漆)   (腳踏車鏈條、機械)            (馬口鐵罐頭鍍錫、  (鐵加入鉻、鎳金屬，
                                                    螺絲鍍鋅)          表面形成緻密氧化膜)
```

1. $\textcolor{#e91e63}{\textbf{表面塗漆}}$：在鋼鐵大橋、車身、鐵捲門表面塗刷油漆，形成一層緻密的物理阻隔膜。
2. $\textcolor{#ff9800}{\textbf{塗抹潤滑油/黃油}}$：在運轉的腳踏車鏈條、機械齒輪上塗油，既能潤滑減少磨損，又能阻隔空氣與水滴。
3. $\textcolor{#00bcd4}{\textbf{金屬電鍍 / 鍍鋅 / 鍍錫}}$：在鐵器外表鍍上一層不易生鏽的金屬（例如食品罐頭內壁鍍錫稱為「馬口鐵」，戶外鐵皮屋頂鍍鋅稱為「白鐵皮」）。
4. $\textcolor{#9c27b0}{\textbf{製造不鏽鋼合金 (Stainless Steel)}}$：在煉鋼時加入 $\textcolor{#9c27b0}{12\%\text{ 以上的鉻 (Cr)}}$ 與鎳 (Ni)。鉻會在金屬表面自發形成一層極薄且自我修復的緻密氧化鉻保護鈍化膜，徹底隔絕內部鐵原子氧化。

## 🔑 核心觀念 3：食物腐敗的罪魁禍首——微生物生長條件

![物質變化——防鏽與防腐 (Rust & Preservation) - 圖解 3](./images/sci_u7_concept3.svg)

新鮮食物放久變酸發臭、長出毛茸茸的菌絲，是空氣中肉眼看不見的$\textcolor{#e91e63}{\textbf{微生物（細菌、黴菌、酵母菌）}}$在食物上附著、大量繁殖，並分泌酵素分解食物營養所導致的$\textcolor{#2196f3}{\textbf{化學腐敗}}$。

```text
                  【 微生物大量繁殖的四大必備溫床 】
         ┌────────────────────────────────────────────────────────┐
         │ 1. 充足養分 (Nutrients)：食物中的蛋白質、醣類、脂肪   │
         │ 2. 充沛水分 (Moisture)：潮濕環境提供代謝介質          │
         │ 3. 適宜溫度 (Temperature)：20℃ ~ 40℃ 繁殖最為旺盛    │
         │ 4. 氧氣存在 (Oxygen)：絕大多數好氧菌生存必備          │
         └────────────────────────────────────────────────────────┘
```

> 🌟 **腐敗 vs 發酵——微生物的雙面角色**：
> - **腐敗 (Spoilage)**：有害微生物不受控地分解食物，產生腐胺、毒素與惡臭，食用會引發食物中毒。
> - $\textcolor{#4caf50}{\textbf{發酵 (Fermentation)}}$：人類刻意營造特定條件，利用「益菌」（如乳酸菌、酵母菌、麴菌）將食材轉化為美味營養的食品（例如：牛奶發酵成$\textcolor{#4caf50}{\textbf{優酪乳}}$、黃豆發酵成$\textcolor{#4caf50}{\textbf{醬油/味噌}}$、麵粉發酵成$\textcolor{#4caf50}{\textbf{麵包}}$）。

食品保存的本質就是：$\textcolor{#e91e63}{\textbf{精準破壞微生物繁殖的四大條件}}$！

### 📊 五大經典食品保存技術全景對比表

| 保存技術方法 | 核心科學物理/化學機制 | 🏠 經典食品範例 | 現代優勢與技術特性 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{低溫冷藏 / 冷凍}}$ | 降溫使微生物體內的酵素活性急劇下降，進入「休眠狀態」，$\textcolor{#2196f3}{\textbf{大幅減緩繁殖速度}}$ | 鮮肉、鮮奶、海鮮、蔬菜 | 保留新鮮原味與口感，但退冰後微生物會迅速甦醒復合 |
| $\textcolor{#ff9800}{\textbf{乾燥 / 脫水法}}$ | 透過日曬、烘乾或熱風移除食物中的水分，$\textcolor{#ff9800}{\textbf{讓微生物缺乏水分無法代謝}}$ | 香菇乾、芒果乾、牛肉乾、奶粉 | 大幅減輕重量便於攜帶與長期存放 |
| $\textcolor{#9c27b0}{\textbf{高濃度糖漬 / 鹽醃}}$| 利用高濃度糖水或鹽水造成高滲透壓，$\textcolor{#9c27b0}{\textbf{將微生物細胞內的水分抽乾脫水死亡}}$| 蜜餞果醬、鹹魚、培根、豆腐乳 | 賦予食材獨特風味，但高鈉高糖不宜過量攝取 |
| $\textcolor{#00bcd4}{\textbf{真空包裝 / 充氮氣}}$| 抽出空氣或填入惰性氮氣，$\textcolor{#00bcd4}{\textbf{隔絕氧氣使好氧菌窒息，並防止油脂氧化}}$| 真空包裝米、洋芋片充氮包、茶葉 | 防受潮、防氧化變質，保持香氣脆度 |
| $\textcolor{#e91e63}{\textbf{高溫高壓滅菌密封}}$| 利用 $121^\circ\text{C}$ 高溫蒸氣直接$\textcolor{#e91e63}{\textbf{徹底殺死所有細菌與微生物芽孢}}$後真空密封| 馬口鐵肉醬罐頭、玻璃水果罐頭、保久乳 | 不需添加防腐劑即可在室溫下存放 $1\sim 3\text{ 年}$ 之久 |

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【鐵生鏽條件控制變因實驗】
- 📌 **題目情境**：小華設計了四支試管進行鐵釘防鏽實驗：
  - 甲試管：鐵釘放在乾燥空氣中（加乾燥劑並密封）
  - 乙試管：鐵釘完全浸泡在煮沸過且上方封油的蒸餾水中（隔絕空氣）
  - 丙試管：鐵釘一半浸在水中、一半接觸空氣
  - 丁試管：鐵釘一半浸在食鹽水中、一半接觸空氣
  請問哪幾支試管的鐵釘會生鏽？哪一支生鏽最嚴重？
- 💡 **思考關鍵**：生鏽必須「水＋氧氣」同時存在；電解質（鹽水）會加速生鏽。
- 📐 **詳盡步驟**：
  1. 甲試管（無水）與乙試管（無氧氣）均「不會生鏽」。
  2. 丙與丁試管皆具備水與氧氣，均會生鏽。
  3. 丁試管因為食鹽水為電解質溶液，生鏽反應最劇烈、生鏽速度最快。

### 📝 範例 2：【食品防腐與保存原理】
- 📌 **題目情境**：市售肉乾能存放數月不發霉，而新鮮生肉放在室溫下一天就會腐敗。請問肉乾的核心保存原理是什麼？
- 💡 **思考關鍵**：微生物繁殖需要水分、養分、溫度與空氣。
- 📐 **詳盡步驟**：
  1. 肉乾經過烘烤脫水與高鹽高糖醃漬，大幅降低了肉質中的「水分活度」。
  2. 微生物細胞處於高滲透壓與乾燥環境中會脫水死亡或停止繁殖，達到長效保存效果。

## 🧠 迷思大破解

❌ **迷思 1**：把吃不完的剩菜放進冰箱冷凍庫，裡面的細菌就全部被凍死了，食物永遠不會壞。
✅ **正確觀念**：低溫冷凍只能「抑制」微生物的生長與繁殖速度，絕大多數細菌在低溫下只是處於「冬眠」狀態，並未被殺死！一旦解凍退冰回到室溫，細菌會立即恢復活力並爆發性繁殖。

❌ **迷思 2**：鐵生鏽只是外表脫皮變形，這是一種物理變化。
✅ **正確觀念**：鐵生鏽是鐵原子與空氣中的氧氣、水分子發生化學反應，生成了性質截然不同的新物質「水合氧化鐵」，顏色、硬度、導電度全部改變，因此是標準的「$\textcolor{#2196f3}{\textbf{化學變化}}$」！

❌ **迷思 3**：食品罐頭可以在常溫下保存三年不壞，一定是因為加了大量可怕的化學防腐劑。
✅ **正確觀念**：依據臺灣食品法規，**絕大多數商業罐頭是嚴格禁止添加防腐劑的！** 罐頭之所以能長年不壞，靠的是先進的「高溫高壓商業滅菌」技術徹底消滅微生物，並透過完全密封阻絕外界空氣與細菌進入。

❌ **迷思 4**：只要食物發生了微生物變化，就代表食物壞掉了，絕對不能吃。
✅ **正確觀念**：在人類控制下由益生菌進行的微生物轉化稱為「$\textcolor{#4caf50}{\textbf{發酵}}$」！例如優格、起司、納豆、泡菜、醬油，都是發酵產生的健康美味食品。

## ✏️ 隨堂自我小練習

1. **(選擇題)** 下列日常生活中的各種現象，哪一項屬於「物理變化」？
   (A) 廚房瓦斯爐燃燒產生藍色火焰
   (B) 喝完的鋁罐被腳踩扁壓成扁平片狀
   (C) 鐵欄杆淋雨後表面長出紅褐色鐵鏽
   (D) 削皮後的蘋果放置於空氣中表面逐漸變深褐色
   **解答**：$\textcolor{#4caf50}{\textbf{(B)}}$。踩扁鋁罐只是金屬外觀形狀改變，鋁的化學本質未變，無新物質生成，為物理變化。

2. **(選擇題)** 小明設計了四支試管研究鐵釘生鏽條件。哪一支試管內的鐵釘會生鏽得最快、最嚴重？
   (A) 試管內放乾燥劑，塞緊橡皮塞
   (B) 試管內注入煮沸去除空氣的水，並在水面滴上一層礦物油密封
   (C) 敞開試管，鐵釘半浸泡在一般自來水中
   (D) 敞開試管，鐵釘半浸泡在濃食鹽水中
   **解答**：$\textcolor{#4caf50}{\textbf{(D)}}$。食鹽水含有電解質離子，在同時具備水分與空氣的條件下會劇烈加速鐵的電化學氧化生鏽。

3. **(選擇題)** 傳統市場常將新鮮水果加入高濃度的砂糖製作成甜蜜的蜜餞，這種食品保存法能長期保存不壞的主要原理為何？
   (A) 砂糖會釋放低溫凍死細菌
   (B) 高濃度糖水產生高滲透壓，使微生物細胞脫水而無法生長
   (C) 砂糖會完全吸收光線，阻擋光合作用
   (D) 砂糖會與氧氣劇烈化學反應耗盡所有空氣
   **解答**：$\textcolor{#4caf50}{\textbf{(B)}}$。高糖與高鹽環境利用滲透壓原理抽取微生物細胞內水分，達到防腐效果。

4. **(簡答題)** 為什麼不鏽鋼鍋具在正常使用下不容易像一般生鐵鍋一樣生鏽？
   **解答**：因為不鏽鋼在鋼鐵中添加了鉻（Cr）與鎳（Ni）等合金金屬。當鉻接觸空氣中的氧氣時，會在金屬最表層形成一層極為緻密、肉眼不可見的「氧化鉻保護鈍化膜」，能有效阻隔內部鐵原子與水分、氧氣接觸，達到優異的防鏽耐腐蝕效果。

### 3. 食物保存的方法
