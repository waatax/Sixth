# 單元 7：物質的變化——防鏽與防腐

鐵製品生鏽與食物腐敗是日常生活中最常見的氧化與微生物作用。學會科學原理，就能延長物品壽命與守護健康！

---

## 🔩 核心觀念一：鐵生鏽的成因與防鏽

### 鐵生鏽的三大必備條件
1.  **鐵金屬**
2.  **水（水分/濕氣）**
3.  **氧氣（空氣）**
*   *加劇生鏽的催化劑*：酸性物質（如酸雨）、鹽分（如海邊鹽霧）。

### 防鏽科學方法
阻隔「水」與「氧氣」接觸鐵表面：
*   **塗層隔絕**：塗油漆、抹潤滑油（如腳踏車鏈條）、包覆塑膠。
*   **金屬鍍層**：
    *   **鍍錫**（馬口鐵，用於罐頭食品）。
    *   **鍍鋅**（白鐵，用於戶外鐵皮屋、水管）。
*   **製成合金**：在鐵中加入鉻、鎳製成**不鏽鋼**（餐具、廚具）。
*   **保持乾燥**：存放於防潮箱或加入乾燥劑。

---

## 🍞 核心觀念二：食物的腐敗與保存

食物腐敗主要是由**微生物（細菌、黴菌、酵母菌）**大量繁殖與酵素作用引起的。

### 微生物生長條件
微生物生長需要：**適當溫度、水分、氧氣、養分**。

### 食品保存的科學原理

| 保存方法 | 科學原理 | 日常實例 |
| :--- | :--- | :--- |
| **低溫冷凍/冷藏** | 抑制微生物酵素活性與繁殖速度 | 冰箱冷藏肉品、蔬菜 |
| **脫水與乾燥** | 降低水分含量，使微生物無法生存 | 果乾、奶粉、牛肉乾、香菇乾 |
| **醃漬（高鹽/高糖）** | 利用高滲透壓使微生物脫水死亡 | 醬瓜、蜜餞、鹹魚 |
| **真空包裝** | 抽除空氣，隔絕氧氣抑制好氧菌 | 真空米、香腸包裝 |
| **高溫滅菌與密封** | 殺死微生物並完全密封隔絕外界 | 罐頭食品、保久乳 |
| **添加天然/合格防腐劑** | 抑制微生物生長 | 依法規限量添加之食品 |

## 🧠 迷思大破解

*   ❌ **錯誤觀念**：「食物放在冷凍庫就永遠不會壞。」
*   ⭕ **正確觀念**：低溫只能『抑制』微生物生長，無法完全殺死微生物，退冰後微生物依然會恢復活力並迅速繁殖！
