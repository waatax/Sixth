## 🔑 核心觀念 1：岩石的三大家族與岩石循環

岩石是由一種或多種礦物組成的固體集合體。根據岩石的「$\textcolor{#e91e63}{\textbf{生成成因}}$」，地質學家將它們劃分為三大經典家族：

```text
                           ┌───◄─── 高溫熔融 ───◄───┐
                           │                        │
                           ▼                        │
                      [ 🔥 地底岩漿 ]               │
                           │                        │
                     冷卻凝固 (冷卻快慢)            │
                           │                        │
                           ▼                        │
                    【 🌋 火成岩 】                 │
                    (花崗岩/玄武岩/安山岩)          │
                           │                        │
                     風化、侵蝕、搬運               │
                           │                        │
                           ▼                        │
                      [ 🏖️ 沉積物 ]                 │
                           │                        │
                     壓密、膠結作用                 │
                           │                        │
                           ▼                        │
                    【 🧱 沉積岩 】                 │
                    (砂岩/頁岩/石灰岩/礫岩)         │
                           │                        │
                     地底高溫、高壓變質             │
                           │                        │
                           ▼                        │

                    (大理岩/板岩/片麻岩)
```

## 🔑 核心觀念 2：礦物的身分證——辨識四大指標

岩石是由「$\textcolor{#00bcd4}{\textbf{礦物 (Minerals)}}$」所組成的天然均質固體無機物。要辨識不同的礦物，地質學家會使用以下四種科學檢驗方法：

```text
       【1. 條痕 (Streak)】                      【2. 摩氏硬度 (Hardness)】
   在白色瓷板上刻劃出粉末顏色                  用標準礦物相互刻劃比硬度
   (例如: 赤鐵礦黑外表，條痕紅棕色！)            (滑石 1 最軟 ◄──► 鑽石 10 最硬)
             ┌──────────┐                                 ┌──────────┐
             │ 瓷板刻痕 │                                 │ 指甲≈2.5 │ 鋼刀≈5.5
             └──────────┘                                 └──────────┘
       【3. 光澤 (Luster)】                      【4. 晶形與解理 (Cleavage)】
   金屬光澤 (像黃鐵礦)、玻璃光澤 (像石英)        方解石菱形受力平整破裂
```

### 💎 摩氏硬度表 (Mohs Hardness Scale, 1~10)

$$\textcolor{#4caf50}{\textbf{滑石 (1)}} \rightarrow \textcolor{#4caf50}{\textbf{石膏 (2)}} \rightarrow \textcolor{#2196f3}{\textbf{方解石 (3)}} \rightarrow \textcolor{#2196f3}{\textbf{螢石 (4)}} \rightarrow \textcolor{#00bcd4}{\textbf{磷灰石 (5)}} \rightarrow \textcolor{#00bcd4}{\textbf{正長石 (6)}} \rightarrow \textcolor{#ff9800}{\textbf{石英 (7)}} \rightarrow \textcolor{#ff9800}{\textbf{黃玉 (8)}} \rightarrow \textcolor{#e91e63}{\textbf{剛玉 (9)}} \rightarrow \textcolor{#e91e63}{\textbf{金剛石/鑽石 (10)}}$$

- **生活簡易硬度參考對照**：
  - 人類指甲硬度約 $\approx 2.5$（能刮傷滑石與石膏，但刮不動方解石）。
  - 銅幣硬度約 $\approx 3.5$。
  - 鋼製小刀/鐵釘硬度約 $\approx 5.5$。
  - 石英（水晶）硬度為 $7$，能輕易在普通玻璃（硬度約 $5.5$）上刻出深刻劃痕。

## 🔑 核心觀念 3：地貌的雕刻師——風化、侵蝕、搬運與堆積

地表的岩石並非恆久不變，在大自然外營力的持續作用下，經歷了四大循環階段：

```text
   【1. 風化作用】 ──────► 【2. 侵蝕作用】 ──────► 【3. 搬運作用】 ──────► 【4. 堆積作用】
   原地崩解碎裂            外力剝蝕切割            隨流水/風力移動         流速減慢沉澱
   (熱脹冷縮、結冰膨脹)    (雨水沖刷、海浪拍打)    (急流滾動碎石)          (河口三角洲、沙灘)
```

## 🔑 核心觀念 4：板塊運動與地震能量釋放

地球的最外層是由地殼與上部地函頂部組成的岩石圈，破裂拼接成十幾個巨大的$\textcolor{#e91e63}{\textbf{板塊 (Tectonic Plates)}}$。

```text
       \                /                                      │      (震源正上方地面)
        \  花東縱谷    /                                       │
         \  隱沒帶   /                                         │ 地震波傳播
          \         /                                          │
```

### 🇹🇼 臺灣為什麼地震頻繁？
臺灣正好座落於$\textcolor{#2196f3}{\textbf{歐亞板塊}}$與$\textcolor{#e91e63}{\textbf{菲律賓海板塊}}$的聚合碰撞邊界（花東縱谷即為交界斷層線）。兩大板塊每年以約 $7\sim 8\text{ 公分}$ 的速度持續擠壓碰撞，在地底累積龐大的應力。當岩層無法承受巨大的擠壓力量時，岩層瞬間斷裂錯動，將能量以$\textcolor{#ff9800}{\textbf{地震波 (Seismic Waves)}}$形式向四面八方釋放，引發劇烈地面晃動。

### 📊 地震規模 vs 地震震度深度比較

| 比較項目 | $\textcolor{#e91e63}{\textbf{芮氏地震規模 (Magnitude, } M_L\textbf{)}}$ | $\textcolor{#2196f3}{\textbf{地震震度 (Intensity)}}$ |
| :--- | :--- | :--- |
| **定義** | 地震「$\textcolor{#e91e63}{\textbf{震源釋放能量的總大小}}$」 | 某特定地區地面感受到的「$\textcolor{#2196f3}{\textbf{搖晃程度與破壞力}}$」 |
| **數值與單位** | 只有**一個固定數值**（如規模 $6.5$），**不加「級」字** | 分為 $0\sim 7$ 級（其中 5 級與 6 級再細分強弱，共 10 個等級） |
| **分佈特徵** | 一場地震永遠只有一個規模值！ | 離震央越近通常震度越大，隨距離與地質條件各地震度皆不相同 |

## 🔑 核心觀念 5：地震防災保命黃金三步驟

地震發生時，劇烈搖晃通常只持續數十秒至一分鐘。在第一時間內，切勿慌亂逃跑，必須立刻執行國際標準避難動作：

```text
       【步驟 1：趴下 (Drop)】     ➔    【步驟 2：掩護 (Cover)】    ➔    【步驟 3：穩住 (Hold On)】
        迅速壓低身體重心                躲入堅固桌下，雙手護住頭頸            緊抓桌腳，隨桌子移動
            🧎‍♂️                           🛡️ 🪵                           🤝 🪵
```

### 🛡️ 地震應變關鍵原則
1. **室內應變**：
   - 遠離大片玻璃窗、吊燈與未固定的高大書櫃。
   - **絕對不可搭乘電梯！**（若人在電梯內，應立刻按下所有樓層按鈕並在停靠時迅速走出）。
2. **戶外應變**：
   - 迅速移動至開闊空曠處，遠離高樓大廈、廣告招牌、高壓電線桿與磚牆。
   - 若在山區或海邊，需嚴防落石塌方與海嘯突襲，迅速往高處避難。

## 🧠 迷思大破解

❌ **迷思 1**：地震發生時，要趕快打開大門衝到馬路上逃生！
✅ **正確觀念**：大錯特錯！強烈地震時地面劇烈晃動，奔跑極易跌倒摔傷，更會被頭頂掉落的招牌、碎玻璃或磁磚砸中喪命。正確做法是「$\textcolor{#4caf50}{\textbf{就地趴下、尋找掩護、緊握桌腳}}$」，待搖晃停止後再冷靜疏散。

❌ **迷思 2**：高山上絕對不可能發現古代貝殼或魚類的化石。
✅ **正確觀念**：臺灣的中央山脈與阿里山高山地層中，發現了大量古代貝類與海洋生物化石！這不是因為古代海水淹到山頂，而是因為這些地層原本沉積在遠古海底，後來透過強烈的「$\textcolor{#e91e63}{\textbf{板塊擠壓造山運動}}$」被硬生生推升到數千公尺的高山之上！

❌ **迷思 3**：一場地震如果規模很大，那麼全臺灣各地感受到的震度一定都一樣大。
✅ **正確觀念**：地震「規模」全場只有一個固定數值；但「震度」代表各地的搖晃強度，震央附近的縣市震度最大，距離震央越遠的地區震度越小，而且鬆軟沉積層（盆地效應）搖晃會顯著放大。

❌ **迷思 4**：顏色金光閃閃的礦物一定就是珍貴的黃金。
✅ **正確觀念**：黃鐵礦的外表同樣呈現燦爛的金色，常被誤認為黃金，因此被稱為「愚人金」。但只要在白色瓷板上劃出「$\textcolor{#00bcd4}{\textbf{條痕}}$」，黃金的條痕是金黃色，而愚人金（黃鐵礦）的條痕卻是**綠黑色**！

## ✏️ 隨堂自我小練習

1. **(選擇題)** 小明在野外地質考察時採集到一塊岩石，表面具有明顯一層一層的紋理，用放大鏡觀察還在岩石中發現了古代三葉蟲的化石印痕。請問這塊岩石最可能屬於哪一類？
   (A) 火成岩  (B) 沉積岩  (C) 變質岩  (D) 隕石
   **解答**：$\textcolor{#4caf50}{\textbf{(B)}}$。具有層理且含有古生物化石是「沉積岩」的最典型特徵。

2. **(選擇題)** 小華拿指甲（硬度約 2.5）去刮某未知礦物，發現刮不出痕跡；改拿銅幣（硬度約 3.5）去刮，能輕易刮出刮痕。請問該未知礦物的摩氏硬度最可能介於何者之間？
   (A) 小於 2.5  (B) 介於 2.5 到 3.5 之間  (C) 介於 3.5 到 5.5 之間  (D) 大於 7
   **解答**：$\textcolor{#4caf50}{\textbf{(B)}}$。礦物能被硬度較大的物體刻劃出痕跡，因此硬度介於 2.5 與 3.5 之間。

3. **(選擇題)** 關於「地震規模」與「地震震度」的比較，下列敘述何者**正確**？
   (A) 震度只有一個數值，代表震源釋放的能量
   (B) 規模是指各地感受到的搖晃程度，距離震央越遠規模越小
   (C) 每次地震全臺灣只會有一個地震規模數值，但各縣市測得的震度可能不同
   (D) 臺灣氣象署震度分級最高為 12 級
   **解答**：$\textcolor{#4caf50}{\textbf{(C)}}$。一場地震釋放的能量大小（規模）只有一個值，但各地的破壞與晃動程度（震度）隨距離與地質而不同。

4. **(簡答題)** 為什麼澎湖群島擁有舉世聞名壯觀的「柱狀玄武岩」景觀？
   **解答**：因為澎湖在遠古地質年代有海底火山噴發，基性玄武岩岩漿湧出地表後迅速冷卻。在均勻冷卻收縮的過程中，岩石內部產生六角形或五角形的垂直節理裂隙，形成了壯觀的柱狀玄武岩石柱群。

5. **(填空題)** 當強烈地震發生時，室內避難的黃金口訣三步驟為：(1) $\underline{\hspace{2cm}}$、(2) $\underline{\hspace{2cm}}$、(3) $\underline{\hspace{2cm}}$。
   **解答**：$\textcolor{#4caf50}{\textbf{趴下 (Drop)}}$、$\textcolor{#4caf50}{\textbf{掩護 (Cover)}}$、$\textcolor{#4caf50}{\textbf{穩住 (Hold On)}}$。

## 🌍 你知道嗎？

**🪨 滴水穿石的石灰岩奇蹟：鐘乳石與石筍的萬年賽跑！**
在墾丁森林遊樂區或許多石灰岩溶洞中，常可看見從洞頂垂下的「鐘乳石」與從地面長起的「石筍」。這些奇觀是如何形成的呢？
當含有二氧化碳的雨水（弱酸性碳酸）滲入地底時，會緩慢溶解石灰岩中的碳酸鈣形成碳酸氫鈣水溶液。當水滴滴落溶洞頂端時，水分蒸發、二氧化碳逸出，碳酸鈣重新沉澱析出。這個過程極其緩慢，每長高或垂下 $1\text{ 公分}$，就需要耗費上百年的漫長時間！當上下兩端的鐘乳石與石筍經過數萬年終於相遇連接時，就形成了頂天立地的「石柱」！

## 🚀 +10% 現代素養前瞻新知

**📲 與時間賽跑：臺灣國家級「地震即時預警 (P-Wave Alert)」系統！**
每次大地震來臨前數秒，你的智慧型手機是否曾響起尖銳的「國家級警報」？這套傲視全球的預警系統是如何搶先通知大家的呢？
秘密就在於地震波的傳播速度差！地震發生時會同時產生兩種主要波形：速度較快但破壞力極小、上下振動的$\textcolor{#2196f3}{\textbf{P 波（每秒約 6 公里）}}$，以及速度較慢但破壞力毀滅性、左右劇烈搖晃的$\textcolor{#e91e63}{\textbf{S 波與表面波（每秒約 3.5 公里）}}$。
氣象署密集佈建的地震儀在偵測到第一波微弱的 P 波後，中央超級電腦在 3 秒內算出震央與規模，利用光速傳播的無線電訊號搶在毀滅性的 S 波抵達你家前的數秒到數十秒發出警報，為捷運煞車、高鐵減速與民眾避難爭取最寶貴的黃金逃生時間！
