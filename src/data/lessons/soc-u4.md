4. 建立「$\textcolor{#4caf50}{\textbf{世界公民 (Global Citizen)}}$」意識，實踐公平貿易與跨文化關懷。

## 🔑 核心觀念 1：全球化的多面向與雙面刃效應

全球化是指商品、資金、資訊、文化與人才，跨越國界自由且快速流動的過程。

```text
               【 全球化的三大主要推動力與面向 】

   ┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐
   │    經濟全球化    │ │    文化全球化    │ │    科技全球化    │
   ├──────────────────┤ ├──────────────────┤ ├──────────────────┤
   │ 跨國企業國際分工 │ │ 各國飲食電影交融 │ │ 網際網路與AI串聯 │
   │ 全球供應鏈無國界 │ │ 在地文化面臨挑戰 │ │ 資訊秒達零時差   │
   └──────────────────┘ └──────────────────┘ └──────────────────┘
```

### 📊 全球化的「機會」與「風險」全方位對比

| 面向 | $\textcolor{#4caf50}{\textbf{正面機會 (帶來的優勢)}}$ | $\textcolor{#d32f2f}{\textbf{負面風險 (面臨的挑戰)}}$ |
| :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{經濟貿易}}$ | 消費者可享用更多元、便宜的全球商品；企業擁有全世界大市場。 | 跨國大財團可能剝削落後國家廉價勞工（童工、血汗工廠）；本土小農與傳統老店受衝擊倒閉。 |
| $\textcolor{#9c27b0}{\textbf{文化生活}}$ | 輕鬆體驗各國美食、節慶與藝術（如珍奶風靡歐美、萬聖節在亞洲流行）。 | 強勢西方與流行文化可能導致弱勢族群語言與傳統文化「同質化」逐漸消失。 |
| $\textcolor{#ff9800}{\textbf{公共衛生}}$ | 國際醫療專家迅速交流疫苗技術、共享抗疫數據。 | 跨國人員流動極快，新興傳染病（如 COVID-19）數天內即可擴散至全球。 |
| $\textcolor{#4caf50}{\textbf{環境生態}}$ | 各國簽訂氣候協議（如巴黎協定），共同開發綠色新能源。 | 跨國空運海運造成大量碳排放；部分高污染工廠轉移到法規寬鬆的開發中國家。 |

## 🔑 核心觀念 2：重要國際組織——世界協作的大舞臺

為了解決跨國性難題，世界成立了兩大類型的國際組織：

```text
                        ┌───────────────────────────────┐
                        │        國際組織兩大體系       │
                        └──────┬─────────────────┬──────┘
                               ▼                 ▼
          ┌───────────────────────────┐   ┌───────────────────────────┐
          │ 政府間國際組織 (IGO)      │   │ 非政府國際組織 (NGO)      │
          │ (由主權國家政府代表組成)  │   │ (由民間公民團體自發組成)  │
          └───────────────────────────┘   └───────────────────────────┘
```

### 📋 重要國際組織核心職能與臺灣參與清單

| 組織性質 | 組織名稱與英文簡稱 | 核心宗旨與主要任務 | 臺灣參與模式與現況 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{IGO}}$<br>(政府間) | $\textcolor{#2196f3}{\textbf{聯合國 (UN)}}$ | 維護世界和平與安全、促進國際合作與人權發展。 | 1971年失去聯合國代表權，目前積極透過友邦發聲爭取有意義參與。 |
| $\textcolor{#2196f3}{\textbf{IGO}}$<br>(政府間) | $\textcolor{#2196f3}{\textbf{世界衛生組織 (WHO)}}$ | 指導全球公共衛生、監測傳染病、制訂國際醫療標準。 | 積極爭取以觀察員身分受邀出席世界衛生大會 (WHA)。 |
| $\textcolor{#2196f3}{\textbf{IGO}}$<br>(政府間) | $\textcolor{#2196f3}{\textbf{世界貿易組織 (WTO)}}$ | 降低各國關稅貿易障礙、建立公平貿易規則、調解貿易紛爭。 | **正式會員**，於2002年以「$\textcolor{#ff9800}{\textbf{臺灣、澎湖、金門及馬祖個別關稅領域}}$」名義加入。 |
| $\textcolor{#2196f3}{\textbf{IGO}}$<br>(政府間) | $\textcolor{#2196f3}{\textbf{亞太經濟合作 (APEC)}}$ | 推動亞太環太平洋地區貿易自由化與經濟技術合作。 | **正式會員**，於1991年以「$\textcolor{#ff9800}{\textbf{中華台北 (Chinese Taipei)}}$」名義加入。 |
| $\textcolor{#9c27b0}{\textbf{NGO}}$<br>(非政府) | $\textcolor{#9c27b0}{\textbf{無國界醫生 (MSF)}}$ | 為受武裝衝突、傳染病流行或天災影響的地區提供中立緊急醫療救援。 | 民間人道組織，臺灣有多位優秀醫師志願前往前線服務。 |
| $\textcolor{#9c27b0}{\textbf{NGO}}$<br>(非政府) | $\textcolor{#9c27b0}{\textbf{國際紅十字會 (ICRC)}}$ | 在戰亂中保護戰俘與平民、提供戰地人道救護與尋親服務。 | 臺灣設有中華民國紅十字會，積極參與國內外急難救助。 |
| $\textcolor{#9c27b0}{\textbf{NGO}}$<br>(非政府) | $\textcolor{#9c27b0}{\textbf{綠色和平 (Greenpeace)}}$ | 倡議保護全球森林、守護海洋、對抗氣候變遷與反核武。 | 在臺灣設有辦公室，推動減塑與綠能倡議。 |

## 🔑 核心觀念 4：培育素養滿分的「世界公民」

```text
                    【 世界公民的三大修練 】

               ① 具備同理心 ──► 尊重各國不同文化、信仰與生活習慣
               ② 關注全球事 ──► 每天花時間閱讀國際新聞，不與世界脫節
               ③ 採取好行動 ──► 實踐永續減碳、支持公平貿易商品
```

- **什麼是世界公民？** 世界公民不僅認同自己的國家，更明白所有人生活在同一個地球生態系中，命運休戚與共。
- **生活實踐**：在日常生活中關心氣候暖化難民、反對種族歧視、拒買雇用童工剝削的血汗商品。

## 🧠 迷思大破解

❌ **迷思 1**：臺灣不是聯合國正式會員，所以國際上發生的事跟我們小學生一點關係都沒有？
✅ **正確觀念**：病毒蔓延不需要護照，氣候變遷與溫室氣體沒有國界！世界的經濟波動、糧食價格都直接影響臺灣的生活。身為地球村的一分子，我們必須持續關心國際局勢！

❌ **迷思 2**：全球化只有好處，東西越便宜越好，產地在哪裡根本沒差？
✅ **正確觀念**：如果某些進口商品價格異常低廉，背後很可能是以破壞當地熱帶雨林、壓榨貧窮國家童工或超長工時為代價！身為負責任的消費者，我們應該關注商品的生產過程是否合乎道德與人道。

❌ **迷思 3**：非政府組織（NGO）只是民間慈善團體，沒有能力對國際產生影響力？
✅ **正確觀念**：NGO 具備高度的「獨立性」與「跨國機動性」，不受外交政治角力牽絆。無國界醫生 (MSF) 甚至曾榮獲諾貝爾和平獎！NGO 是推動全球人權、環保條約最關鍵的推手！

## ✏️ 隨堂自我小練習

1. **(選擇題)** 臺灣目前是下列哪一個「政府間國際組織 (IGO)」的正式會員國？
   (A) 聯合國 (UN)  
   (B) 世界衛生組織 (WHO)  
   (C) 世界貿易組織 (WTO)  
   (D) 聯合國教科文組織 (UNESCO)  
   **💡 解析**：選 $\textcolor{#2196f3}{\textbf{(C)}}$。臺灣於 2002 年以「臺澎金馬個別關稅領域」正式加入世界貿易組織 (WTO)。

2. **(選擇題)** 當某個中東國家爆發戰亂衝突，導致大量平民受傷且當地醫院全毀時，下列哪一個民間發起的非政府組織 (NGO) 會冒著危險提供中立的緊急醫療救援？
   (A) 亞太經濟合作會議 (APEC)  
   (B) 無國界醫生 (MSF)  
   (C) 世界貿易組織 (WTO)  
   (D) 國際奧林匹克委員會 (IOC)  
   **💡 解析**：選 $\textcolor{#2196f3}{\textbf{(B)}}$。無國界醫生 (Médecins Sans Frontières) 是專門在戰亂與災區提供緊急醫療的 NGO。

3. **(選擇題)** 在全球化浪潮下，下列何者屬於全球化可能帶來的「負面衝擊」？
   (A) 能夠在臺灣吃到世界各國的新鮮水果與美食  
   (B) 透過網際網路可以與不同國家的學伴即時視訊交流  
   (C) 新興傳染病在短短幾天內透過國際航班擴散至全球  
   (D) 臺灣的高科技晶片可以銷售至全世界各大科技大廠  
   **💡 解析**：選 $\textcolor{#2196f3}{\textbf{(C)}}$。傳染病因跨國交通便捷而迅速擴散，是全球化公共衛生面臨的重大挑戰。

4. **(情境思考題)** 走進超市時，小萱在兩包可可粉前猶豫：一包非常便宜，但產地不明；另一包包裝上印有「$\textcolor{#ff9800}{\textbf{公平貿易認證 (Fairtrade)}}$」標章，價格稍微高了一點點。請問這個標章代表什麼意義？如果是你，你會如何選擇？
   **💡 參考答案**：
   - 公平貿易標章代表這包可可在生產過程中「**保障了農民獲得合理的工資與利潤**」，且「**嚴格禁止雇用童工、採用友善環境的永續種植方式**」。
   - 選擇購買公平貿易商品，能用實際消費支持落後國家小農改善生活與受教育，是實踐世界公民責任的最佳表現！

## 🚀 +10% 現代素養前瞻新知

**☕ 公平貿易（Fairtrade）與負責任的「道德消費」！**
你知道嗎？全世界每喝一杯咖啡或吃一塊巧克力，背後可能藏著我們看不見的童工辛酸。
- 過去跨國中間商層層剝削，非洲西部的可可小農每天工作超過 12 小時，得到的收入卻不到 1 美元，許多兒童甚至因此被迫輟學在農場砍可可豆。
- **公平貿易運動**：保證以「公平收購底價」直接向農民合作社採購，並提撥「社區發展金」協助當地興建小學、乾淨水井與診所！
- 現代消費者的力量很大！只要我們在買文具、衣服、零食時，主動指名選購具有「**公平貿易標章**」或「**永續森林認證 (FSC)**」的產品，就是在用手中的錢包為世界投下美好的一票！
