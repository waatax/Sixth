# 單元 4：全球化浪潮與國際組織參與

我們生活在一個緊密相連的地球村，世界的一舉一動都深深影響著我們的生活！

---

## 🌐 核心觀念一：什麼是全球化 (Globalization)？

全球化是指各國在**經濟、文化、科技、資訊、環境**等方面互相依賴、頻繁交流的現象。

### 1. 全球化的好處
*   **商品多樣化**：在臺灣就能買到世界各國的水果、電子產品與服飾。
*   **文化交流**：各國音樂、電影、動漫、飲食文化互相融合傳播。
*   **知識與科技共享**：網際網路讓全球研究者能即時合作解決全球問題。

### 2. 全球化的挑戰
*   **傳染病全球擴散**：如 COVID-19 快速蔓延全球。
*   **經濟連鎖反應**：一國金融風暴或供應鏈斷裂引發全球物價震盪。
*   **在地文化衝擊**：強勢文化流行可能削弱本土傳統文化。

---

## 🇺🇳 核心觀念二：國際組織與全球治理

為了協調國際事務，各國共同建立了各類國際組織：

| 組織名稱 | 英文簡稱 | 主要宗旨與功能 |
| :--- | :--- | :--- |
| **聯合國** | **UN** | 維護世界和平與安全，促進國際人權與合作 |
| **世界衛生組織** | **WHO** | 指導全球公共衛生政策，防堵重大傳染病 |
| **世界貿易組織** | **WTO** | 促進全球自由貿易，解決各國貿易爭端 |
| **亞太經合會** | **APEC** | 促進亞太地區經濟成長與貿易合作（臺灣為正式成員） |
| **綠色和平組織** | **Greenpeace** | 非政府組織(NGO)，致力於全球環境保護與氣候議題 |

---

## 🇹🇼 核心觀念三：臺灣在世界的貢獻 (Taiwan Can Help)

臺灣雖然面臨外交挑戰，但依然積極參與國際事務：
1.  **醫療與人道救援**：派遣醫療團至友邦、在國際天災時第一時間提供物資與搜救隊。
2.  **科技農業技術援助**：農技團常駐非洲、中南美洲協助提升糧食產量。
3.  **全球民主防線**：捍衛言論自由與人權價值。
