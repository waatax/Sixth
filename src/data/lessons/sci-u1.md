## 🔑 核心觀念 1：大氣中的水循環——水的百變分身

![大氣中的水循環](./images/sci_u1_concept1.svg)

地球上的水在太陽照射下，透過$\textcolor{#e91e63}{\textbf{蒸發}}$、$\textcolor{#2196f3}{\textbf{凝結}}$、$\textcolor{#9c27b0}{\textbf{凝華}}$、$\textcolor{#4caf50}{\textbf{降水}}$不斷循環。大氣中的水氣遇冷時，會依據「$\textcolor{#ff9800}{\textbf{形成的高度}}$」與「$\textcolor{#ff9800}{\textbf{環境溫度}}$」變身成不同的形態：

| 發生位置 | 氣溫條件 | 水氣變化狀態 | 形成結果 |
| :--- | :--- | :--- | :--- |
| **高空中** | 氣溫 > 0℃ | 水氣凝結成小水滴 | ☁️ 雲 `Cloud` |
| **高空中** | 氣溫 ≤ 0℃ | 水氣凝華成小冰晶 | ❄️ 雪 `Snow` |
| **高空中降落** | - | 小水滴碰撞變大受重力落下 | 🌧️ 雨 `Rain` |
| **貼近地表** | - | 懸浮於貼近地表大氣 | 🌫️ 霧 `Fog` |
| **地表物體表面** | 氣溫 > 0℃ | 凝結於草葉或車窗上 | 💧 露 `Dew` |
| **地表物體表面** | 氣溫 ≤ 0℃ | 凝華於草葉或車窗上 | ❄️ 霜 `Frost` |

## 🔑 核心觀念 2：氣壓與風——大氣的推手

![高低氣壓與天氣](./images/sci_u1_concept2.svg)

空氣具有質量與重量！地球表面單位面積所承受的空氣柱重量稱為$\textcolor{#e91e63}{\textbf{大氣壓力 (Atmospheric Pressure)}}$，常用單位為$\textcolor{#2196f3}{\textbf{百帕 (hPa)}}$。

1. $\textcolor{#2196f3}{\textbf{高氣壓 (H, High Pressure)}}$：
   - 中心空氣受冷下沉，地表空氣向外順時針（北半球）輻散。
   - **天氣特徵**：空氣下沉增溫，水氣不易凝結，天氣通常$\textcolor{#4caf50}{\textbf{晴朗乾燥、少雲}}$。
2. $\textcolor{#e91e63}{\textbf{低氣壓 (L, Low Pressure)}}$：
   - 地表空氣受熱膨脹上升，周圍空氣逆時針（北半球）向中心輻合。
   - **天氣特徵**：上升空氣膨脹冷卻，水氣容易凝結成雲致雨，天氣通常$\textcolor{#e91e63}{\textbf{陰雨多雲、對流旺盛}}$。
3. $\textcolor{#ff9800}{\textbf{風的成因與流向}}$：
   - 空氣永遠從「$\textcolor{#2196f3}{\textbf{高氣壓區}}$」流向「$\textcolor{#e91e63}{\textbf{低氣壓區}}$」，空氣的水平流動就形成了「$\textcolor{#ff9800}{\textbf{風}}$」。

```text
       【高氣壓系統 (H)】                          【低氣壓系統 (L)】
    空氣冷卻下沉 ➔ 地表向外擴散                地面受熱上升 ➔ 膨脹凝結致雨
          ↓↓↓↓↓↓                                       ↑↑↑↑↑↑
        [ 高氣壓 H ] ────── (氣壓梯度力 ➔ 產生風) ──────➔ [ 低氣壓 L ]
      【晴朗乾燥・少雲】                           【多雲陰雨・對流旺盛】
```

### 🌊 局地風向實例：海陸風日常循環

```text
   【白天：吹海風 (Sea Breeze)】              【夜晚：吹陸風 (Land Breeze)】
   陸地吸熱快 (溫度高 ➔ 低壓 L)              陸地散熱快 (溫度低 ➔ 高壓 H)
   海洋吸熱慢 (溫度低 ➔ 高壓 H)              海洋散熱慢 (溫度高 ➔ 低壓 L)
         陸地 (L) ◄── 海風 ── 海洋 (H)             陸地 (H) ── 陸風 ──► 海洋 (L)
```

## 🔑 核心觀念 3：鋒面系統——冷暖氣團的交鋒戰場

![鋒面系統：冷鋒與暖鋒](./images/sci_u1_concept3.svg)

當大範圍性質（溫度、濕度）均勻的空氣塊（稱為$\textcolor{#2196f3}{\textbf{氣團}}$）相遇時，交界處形成的過渡帶稱為$\textcolor{#e91e63}{\textbf{鋒面 (Front)}}$。臺灣位於亞熱帶交界，氣候深受冷暖氣團交替影響：

```text
   【冷鋒剖面圖 (Cold Front)】                 【暖鋒剖面圖 (Warm Front)】
    冷空氣強勢插入，暖空氣陡升                  暖空氣主動爬升於冷空氣上方
       暖空氣 (被強烈抬升)                         暖空氣 (平緩爬升)
           ▲ 雲雨區 (厚積雨雲)                        ▲ 雲雨區 (大範圍層雲)
           │  🌧️ 🌧️ 🌧️                               │  🌧️ 🌧️ 🌧️
     冷空氣 ──► 暖空氣                          暖空氣 ──► 冷空氣
   【符號】：藍色尖角 ▼▼▼ 移動方向             【符號】：紅色半圓 ●●● 移動方向
```

### 📊 三大鋒面系統特徵與天氣對比表

| 鋒面種類 | 地面天氣圖符號 | 氣團勢力與運動特徵 | 伴隨的天氣劇烈變化 | 臺灣常見出現季節與影響 |
| :--- | :--- | :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{冷鋒}}$ | 藍色三角形尖端朝向移動方向 $\textcolor{#2196f3}{\blacktriangle\blacktriangle\blacktriangle}$ | $\textcolor{#2196f3}{\textbf{冷氣團勢力強}}$，強行插入暖氣團下方將暖空氣強烈抬升 | 氣溫陡降、颳起強烈陣風、伴隨短暫強陣雨或雷雨，鋒面過後轉乾冷 | 秋冬季節（大陸冷氣團、寒流南下時） |
| $\textcolor{#e91e63}{\textbf{暖鋒}}$ | 紅色半圓形朝向移動方向 $\textcolor{#e91e63}{\blacksquare\blacksquare\blacksquare}$ | $\textcolor{#e91e63}{\textbf{暖氣團勢力強}}$，緩慢爬升到冷氣團上方並向前推進 | 氣溫逐漸回升、出現大範圍連續性陰雨或綿綿細雨 | 春季（較少直接完全通過臺灣本島） |

## 🔑 核心觀念 4：颱風的結構與防災智慧

![颱風結構與防災](./images/sci_u1_concept4.svg)

$\textcolor{#e91e63}{\textbf{颱風 (Typhoon)}}$ 是生成於熱帶溫暖洋面（水溫 $\ge 26.5^\circ\text{C}$）上的強烈熱帶低氣壓系統。北半球颱風以$\textcolor{#2196f3}{\textbf{逆時針方向}}$向中心旋轉匯聚。

### 🌀 颱風剖面結構深入解析

```text
                           ↑↑ 頂部氣流向外強烈輻散 ↑↑
         ┌─────────────────────────┬─────────────────────────┐
         │  猛烈螺旋雨帶 (眼牆)     │  猛烈螺旋雨帶 (眼牆)     │
         │      ████████████       │       ████████████      │
         │      ████████████       │       ████████████      │
         │      🌧️🌧️ 狂風暴雨 🌧️🌧️   │       🌧️🌧️ 狂風暴雨 🌧️🌧️   │
         └────────────┬────────────┴────────────┬────────────┘
                      │    【颱風眼 (Eye)】     │
                      │  風平浪靜・無風無雨     │
                      │  中心為極低氣壓下沉氣流 │
                      │  甚至能看見藍天或星星   │
                      └─────────────────────────┘
         ────────────────── 溫暖海洋表面 ───────────────────
```

- $\textcolor{#00bcd4}{\textbf{颱風眼 (Eye)}}$：颱風最中心，空氣微弱下沉。中心氣壓全系統$\textcolor{#e91e63}{\textbf{最低}}$，但天氣$\textcolor{#4caf50}{\textbf{風平浪靜、無風無雨}}$。
- $\textcolor{#e91e63}{\textbf{眼牆/雲牆 (Eye Wall)}}$：環繞颱風眼外圍的垂直高聳厚重積雨雲，是整個颱風$\textcolor{#e91e63}{\textbf{風速最快、雨勢最猛烈、破壞力最強}}$的區域！
- $\textcolor{#ff9800}{\textbf{螺旋雨帶 (Spiral Rainbands)}}$：從外圍向中心旋轉匯入的雲帶，帶來陣發性的強風與間歇性豪大雨。

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【地面天氣圖與高低氣壓判讀】
- 📌 **題目情境**：閱讀地面天氣圖時，發現臺灣北方有一個標示「H」的系統正逐漸南下，而臺灣東方海面上有一標示「L」的系統。請問這分別代表什麼天氣系統？當「H」籠罩臺灣時，天氣通常如何？
- 💡 **思考關鍵**：H (High Pressure) 代表高氣壓；L (Low Pressure) 代表低氣壓。高氣壓中心空氣下沉，不利於水氣凝結，天氣晴朗乾燥。
- 📐 **詳盡步驟**：
  1. 「H」代表高氣壓系統；「L」代表低氣壓系統。
  2. 當高氣壓籠罩臺灣時，由於中心下沉氣流壓抑對流，天空雲量稀少，天氣多為「晴朗乾燥」。
  3. 風向規律：風永遠由「高氣壓 (H)」吹向「低氣壓 (L)」。

### 📝 範例 2：【鋒面符號與梅雨季成因】
- 📌 **題目情境**：氣象局發布預報指出一條「滯留鋒」正在臺灣上空徘徊。請問在天氣圖上滯留鋒的符號長什麼樣子？它通常在幾月造成臺灣連日陰雨？
- 💡 **思考關鍵**：冷暖氣團勢力相當形成的鋒面為滯留鋒。符號為紅色半圓形與藍色尖三角形在同一線上「反向交替排列」。
- 📐 **詳盡步驟**：
  1. 符號特徵：藍色尖三角形與紅色半圓形交替排列於線兩側。
  2. 發生季節：每年 5 ~ 6 月初夏時節，形成臺灣俗稱的「梅雨季」，帶來豐沛雨量但也需防範局部豪大雨。

## 🧠 迷思大破解

❌ **迷思 1**：颱風天狂風暴雨時，如果突然看見陽光、風雨完全停止，代表颱風已經離開，可以出去玩了。
✅ **正確觀念**：這極可能是進入了「$\textcolor{#00bcd4}{\textbf{颱風眼}}$」！颱風眼無風無雨，但一旦眼區移出，緊接而來的另一側眼牆會帶來方向完全相反的毀滅性強風暴雨，千萬不可外出！

❌ **迷思 2**：高氣壓代表氣壓數值很高，所以一定會颳大風、下暴雨。
✅ **正確觀念**：恰恰相反！高氣壓中心空氣下沉增溫，不利於水氣凝結成雲，因此高氣壓籠罩下天氣通常是「$\textcolor{#4caf50}{\textbf{晴朗乾燥、陽光充足}}$」的好天氣。

❌ **迷思 3**：霜是天上飄下來的細小雪花。
✅ **正確觀念**：霜不是從天上掉下來的！霜是地表附近的空氣中的水氣，在寒冷且無風的晴朗夜晚，直接在地表物體表面「$\textcolor{#9c27b0}{\textbf{凝華}}$」結成的固態白色冰晶。

❌ **迷思 4**：風向標的箭頭指向哪裡，就代表風吹向哪裡。
✅ **正確觀念**：風向標的箭頭指向的是「$\textcolor{#e91e63}{\textbf{風吹來的來源方向}}$」！如果箭頭指著東方，代表現在吹的是「東風」（風由東方吹向西方）。

### 2. 冷鋒與暖鋒的符號

- 🧠 **一句話記住**：冷鋒：三角形；暖鋒：半圓形；滯留鋒：三角形和半圓形交錯。
- 🌱 **生活例子**：冬天冷鋒過境後，氣溫會明顯下降，要多穿衣服。

**先想想看**：遮住下面的說明，用自己的話說說「冷鋒與暖鋒的符號」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

冷空氣和暖空氣相遇的交界叫鋒面。冷鋒的符號是一排三角形，通過時常下短暫大雨、之後氣溫下降；暖鋒的符號是一排半圓形，通常帶來時間較長的綿綿細雨。

⚠️ **小心別犯錯**：三角形和半圓形「指向」的方向就是鋒面前進的方向。

</details>

- 🌱 **生活例子**：梅雨季常連續下好幾天雨；颱風來時要注意強風豪雨，做好防颱準備。

**先想想看**：遮住下面的說明，用自己的話說說「梅雨與颱風」是什麼意思，再想一個你身邊的例子。

<summary>對照白話說明與易錯提醒</summary>

### 4. 看懂「降雨機率」（延伸應用）

- 🧠 **一句話記住**：降雨機率越高 → 下雨的可能越大；它說的是「可能性」，雨下得多大要看「雨量」預報。
- 🌱 **生活例子**：明天降雨機率 80%，出門最好帶傘；降雨機率 10%，下雨的可能很低，但不是完全不會下。

**先想想看**：遮住下面的說明，用自己的話說說「看懂「降雨機率」」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

降雨機率是「在預報的時間和地區裡，會下雨的可能性有多大」。降雨機率 70% 表示：在類似的天氣情況下，10 次大約有 7 次會下雨。它不是說會下 70% 的時間，也不是 70% 的地方下雨，更不是雨量大小。

⚠️ **小心別犯錯**：降雨機率 90% 不代表雨很大，可能只是毛毛雨；降雨機率 0% 以外，都還是有可能下雨。

</details>
