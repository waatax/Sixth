由美國康乃爾大學教授華特·波克（Walter Pauk）研發，是公認最高效的**結構化筆記與自我測驗系統**！

```text
                  【康乃爾筆記本三欄黃金比例】
  ┌─────────────────────────────────────────────────────────────┐
  │ 標題：單元 3 自主學習策略                 日期：2026/08/18   │
  ├──────────────────────┬──────────────────────────────────────┤
  │ ❓【提示 / 提問欄】   │ 📝【筆記記錄欄 (Notes)】              │
  │    (左側 1/3)        │    (右側 2/3)                        │
  │                      │                                      │
  │ ★ 課後複習時填寫      │ ★ 課堂聽講時記錄                    │
  │                      │                                      │
  │ Q1: 什麼是多元智能？ │ - 迦納提出，打破單一 IQ 迷思         │
  │ Q2: 康乃爾分哪三欄？ │ - 包含：語文、數學、空間等 8 種      │
  │ Q3: 費曼法四步驟？   │ - 筆記欄、提示欄、總結欄             │
  │                      │ - 符號簡寫：$\rightarrow$ (導致), ★ (重點)      │
  ├──────────────────────┴──────────────────────────────────────┤
  │ 💡【總結欄 (Summary)】(下方 1/5)                            │
  │ ★ 課後用 1~2 句話提煉全頁精華：                             │
  │   「發掘多元智能天賦，善用康乃爾三欄筆記與費曼教學法，打造高效自主學習力！」│
  └─────────────────────────────────────────────────────────────┘
```

- 🌟 **康乃爾筆記的 5R 流程**：
  1. **Record (記錄)**：上課在右側筆記欄快速記下重點與圖表。
  2. **Reduce (簡化/提煉)**：課後在左側提示欄寫下「關鍵字」與「考題」。
  3. **Recite (複述/測驗)**：**用手遮住右邊**，看著左邊問題考自己！
  4. **Reflect (反思)**：思考這份筆記與生活的連結，寫下底部總結。
  5. **Review (複習)**：每週花 10 分鐘快速重溫提示欄。

## 🔑 核心觀念 4：全腦思維整理——心智圖 (Mind Mapping)

由英國「大腦之父」東尼·博贊（Tony Buzan）發明，利用**放射狀樹枝結構**模擬大腦神經元突觸，結合色彩與圖像，將整本書的重點濃縮於一張圖中！

```text
                 【心智圖四大繪製黃金原則】
                       🎨【中心主題】
                    (紙張橫放、中央畫彩色大圖)
                         ／           ＼
                 【主幹粗樹枝】       【主幹粗樹枝】
                 (主要章節分類)       (主要章節分類)
                   ／       ＼           ／       ＼
              【次幹細分枝】 【次幹】  【次幹】   【次幹細分枝】
               (關鍵詞/單詞) (關鍵詞)   (關鍵詞)   (關鍵詞/單詞)
```
- 💡 **心智圖四大準則**：
  1. **紙張橫放**：視野最寬廣。
  2. **只寫關鍵詞**：一個分枝只寫一個詞（不要抄寫整段長句子）。
  3. **善用色彩**：每個主幹使用不同顏色，刺激右腦記憶。
  4. **圖文並茂**：多畫小塗鴉與箭頭符號，記憶力暴增 3 倍！

## 🧠 迷思大破解

❌ **迷思 1：我數學常不及格，代表我的智商很低、一輩子沒前途？**
✅ **正確觀念**：絕對不是！數理只是八大智能中的一種。許多世界級的頂尖大導演、暢銷作家、設計大師或運動金牌國手，在學校時數學也不好。發掘並擦亮你的「優勢智能」，每個人都能在自己的專屬賽道上發光發熱！

❌ **迷思 2：上課抄筆記就是要像打字機一樣，把老師黑板上的字一字不漏全抄下來？**
✅ **正確觀念**：機械式抄寫只是「手的勞動」，大腦根本沒有思考！好的筆記必須經過**「提煉與消化」**。使用康乃爾筆記法，將重點濃縮在左側提示欄並自我提問，才能將短期記憶真正固化為長期記憶！

❌ **迷思 3：自己讀書都沒時間了，花時間去教同學是在浪費時間當冤大頭？**
✅ **正確觀念**：大錯特錯！神經科學研究證實：**「教導他人」是人類所有學習方式中，知識留存率最高的方法（高達 $\textcolor{#e91e63}{\textbf{90\%}}$）**！當你在教同學時，你的大腦正在進行高強度的知識重組與盲點檢測，最大的受益者永遠是你自己！
