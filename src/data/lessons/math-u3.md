# 單元 3：小數除法

> 🎯 學完這個單元，你會發現小數除法其實跟整數除法一樣簡單！

---

## 什麼是小數除法？

小數除法就是被除數或除數（或兩者）含有小數點的除法。

生活中常會用到：
- 7.2 公升的果汁平分成 3 瓶，每瓶多少公升？👉 7.2 ÷ 3
- 4.56 公尺的布，每段要 1.2 公尺，可以剪幾段？👉 4.56 ÷ 1.2

別怕小數點，只要掌握技巧，就能輕鬆搞定！

---

## 小數除以整數

### 🔑 核心觀念

小數除以整數，直接用直式除法，**小數點對齊往上搬**就好。

### 📝 範例 1：7.2 ÷ 3

```
      2.4
    ------
 3 ) 7.2
     6        ← 3 × 2 = 6
     ---
     1 2      ← 把 2 拉下來，變成 12
     1 2      ← 3 × 4 = 12
     ---
       0      ← 整除！
```

**答案：7.2 ÷ 3 = 2.4** ✅

### 📝 範例 2：9.45 ÷ 5

```
      1.89
    -------
 5 ) 9.45
     5         ← 5 × 1 = 5
     ---
     4 4       ← 拉下 4
     4 0       ← 5 × 8 = 40
     ---
       45      ← 拉下 5
       45      ← 5 × 9 = 45
       --
        0
```

**答案：9.45 ÷ 5 = 1.89** ✅

---

## 小數除以小數——移動小數點

### 🔑 核心觀念

除數是小數時，我們要**把除數變成整數**，方法是：

> 除數的小數點往右移幾位，被除數的小數點也跟著往右移幾位。

這樣做不會改變答案（等於分子分母同乘以 10 或 100）。

### 📝 範例 1：4.56 ÷ 1.2

```
第一步：除數 1.2 小數點往右移 1 位 → 12
第二步：被除數 4.56 小數點也往右移 1 位 → 45.6

所以 4.56 ÷ 1.2 = 45.6 ÷ 12
```

```
       3.8
    -------
12 ) 45.6
     36       ← 12 × 3 = 36
     ---
      96      ← 拉下 6，變成 96
      96      ← 12 × 8 = 96
      --
       0
```

**答案：4.56 ÷ 1.2 = 3.8** ✅

### 📝 範例 2：6.3 ÷ 0.07

```
第一步：除數 0.07 小數點往右移 2 位 → 7
第二步：被除數 6.3 小數點也往右移 2 位 → 630

所以 6.3 ÷ 0.07 = 630 ÷ 7 = 90
```

**答案：6.3 ÷ 0.07 = 90** ✅

## 餘數的處理

有時候除不盡，會有餘數。小數除法的餘數要特別注意：

### 🔑 核心觀念

**餘數的小數點位置，要看原本被除數的小數點**，不是移動後的！

### 📝 範例：7.5 ÷ 2

```
      3
    -----
 2 ) 7.5
     6
     ---
     1.5  ← 除不盡，餘數是 1.5
```

但如果繼續除下去：

```
      3.75
    ------
 2 ) 7.5 0     ← 補 0 繼續除
     6
     ---
     1 5
     1 4
     ---
       10
       10
       --
        0
```

**答案：7.5 ÷ 2 = 3.75** ✅

---

## 四捨五入取概數

有些除法永遠除不盡（無限小數），這時候就要用**四捨五入**。

### 🔑 規則

- 要取到小數點下第一位 → 算到第二位再四捨五入
- 要取到小數點下第二位 → 算到第三位再四捨五入

### 📝 範例：10 ÷ 3（取到小數點下第二位）

```
10 ÷ 3 = 3.333...

算到小數點下第三位 → 3.333
第三位是 3，小於 5，捨去 → 3.33
```

**答案：10 ÷ 3 ≈ 3.33** ✅

### 📝 範例：5.7 ÷ 7（取到小數點下第一位）

```
5.7 ÷ 7 = 0.8142...

算到小數點下第二位 → 0.81
第二位是 1，小於 5，捨去 → 0.8
```

**答案：5.7 ÷ 7 ≈ 0.8** ✅

## 迷思大破解

### ❌ 迷思 1：「移動小數點時，只移除數不移被除數」

**錯！** 除數和被除數的小數點要**一起移動相同位數**，這樣商才不會變。

就像分數 4.56/1.2，分子分母同乘 10 → 45.6/12，值不變。

### ❌ 迷思 2：「餘數的小數點看移動後的位置」

**錯！** 餘數的小數點要對應**原來被除數**的小數點位置。

例如 7.54 ÷ 0.3，移動後變 75.4 ÷ 3，商 25 餘 0.4。
餘數是 0.04（看原本的被除數 7.54 的位置），不是 0.4！

### ❌ 迷思 3：「除以小數，答案一定變小」

**錯！** 除以比 1 小的數，答案反而**變大**！

例如：6 ÷ 0.5 = 12 🤯

想想看：6 個蘋果，每 0.5 個裝一袋，當然可以裝 12 袋！

## 本單元重點整理

| 題型 | 關鍵技巧 |
|------|---------|
| 小數 ÷ 整數 | 小數點對齊往上搬 |
| 小數 ÷ 小數 | 先移動小數點讓除數變整數 |
| 有餘數 | 餘數對應原被除數的小數點 |
| 除不盡 | 四捨五入取概數 |

> 🌟 記住口訣：**除數變整數，被除數跟著走！**
