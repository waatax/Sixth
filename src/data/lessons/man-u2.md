**學習目標：**
在這堂課中，我們將化身為文字導演與故事大師！你將掌握記敘文的五大要素（人、事、時、地、物），精通「起承轉合」情節起伏的波浪骨架，學會 6 大吸睛開頭與 5 大回味結尾，並熟練運用「五感摹寫」與「Show, Don't Tell（展現而非告知）」的寫作心法，讓平淡無奇的日常瞬間化為扣人心弦的動人篇章！

## 🎯 學習導引：為什麼要學這個？

你有沒有過這樣的經驗：在學校發生了一件超級好笑或感動的事，但寫成週記或作文時，卻變成「今天我們去戶外教學，看很多東西，吃了午餐，大家很開心就回家了」？這樣的文章讀起來就像一碗沒加鹽的清湯，既平淡又像「記流水帳」。

🎨 **寫作就像拍電影，文字就是你的鏡頭與畫筆！**
世界上最會說故事的人，能讓讀者一邊讀一邊緊張得屏住呼吸，或是感動得眼眶泛淚。學好記敘文，不僅能讓你在考場上輕鬆拿高分，更重要的是，你能用文字把生命中那些珍貴的回憶、親人的溫暖笑容、挫折中的奮鬥過程「永遠保鮮」。掌握說故事的能力，就是掌握打動人心的最強超能力！

## 🔑 核心觀念 1：記敘文的骨架——起承轉合的情節波浪圖

一篇精彩的記敘文絕對不是平鋪直敘的直線，而是一條充滿起伏與張力的**情節波浪線**：

```text
                        【轉 (Climax)】
                      衝突爆發 / 意外轉折 / 情感最高潮
                               ▲
                              / \
                             /   \
            【承 (Rising)】 /     \
            細節推展 / 鋪陳積累 /       \   【合 (Resolution)】
                   ▲       /         \   感悟領會 / 餘韻悠長 / 首尾呼應
                  / \     /           ▼
                 /   └───┘
       【起 (Hook)】
       引子點題 / 製造懸念 / 交代背景
```

### 📊 本單元核心考點與重點公式速查表

| 核心知識點 / 考點主題 | 📐 核心公式 / 定理 / 規則架構 | 💡 黃金記憶口訣 / 速記法 | ⚠️ 常考易錯陷阱 / 必勝解題秘訣 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#e91e63}{\textbf{記敘文起承轉合}}$ | **起**：點題開篇、交代背景（人事時地）<br>**承**：順勢敘述、展開情節<br>**轉**：突生波瀾、衝突高潮（轉折關鍵）<br>**合**：總結點睛、昇華感悟 | **「起如鳳頭開門見，承如豬肚鋪情節，轉如豹尾掀高潮，合如晨鐘留餘韻」** | ❌ 通篇平鋪直敘記流水帳！「轉」是記敘文的核心靈魂，必須寫出衝突、挑戰或情緒轉折 |
| $\textcolor{#2196f3}{\textbf{三大敘事時間順序}}$ | **順敘**：依時間先後發生順序（脈絡清晰）<br>**倒敘**：先寫結局或高潮，再回溯起因（引人入勝）<br>**插敘**：敘述途中插入過去回憶，再回到主線 | **「順敘條理明，倒敘吸眼球，插敘添厚度」** | ⚠️ 倒敘寫作時，切換回回憶段落與返回現實時，要有明確的時間過渡詞 |
| $\textcolor{#ff9800}{\textbf{人物描寫三維法}}$ | 1. **外貌神態**（抓特徵顯性格）<br>2. **動作細節**（連續動詞寫活過程）<br>3. **心理獨白**（真實刻畫掙扎與成長） | **「動詞精準寫動作，神態外貌映內心」** | 💡 避免空洞形容（如「他很生氣」），改用細節描寫（如「他雙拳緊握，咬緊牙關」） |
| $\textcolor{#2e7d32}{\textbf{五感描摹法}}$ | 調動「視覺、聽覺、嗅覺、味覺、觸覺」立體描寫環境與事物 | **「看聽聞嘗摸，五感寫作立體活」** | 💡 寫景物或美食時，融合至少 3 種感官描寫，文章立體感瞬間倍增 |

## 🔑 核心觀念 2：文字魔法——「Show, Don't Tell (展現而非告知)」

![記敘文寫作的起承轉合 (Narrative Writing) - 圖解 2](./images/man_u2_concept2.svg)

好作家的第一鐵律是：**不要直接「告訴」讀者結論，而是用具體畫面「展現」給讀者看！**

$$\textcolor{#e91e63}{\textbf{動人畫面}} = \textcolor{#2196f3}{\textbf{五感摹寫 (Sensory)}} + \textcolor{#4caf50}{\textbf{微動作分解 (Action)}} + \textcolor{#ff9800}{\textbf{心理獨白 (Monologue)}}$$

```text
  【文字導演・慢動作分鏡拆解法 🎬】

  [平淡一句話] ➔ 「媽媽很生氣」
       ↓ (啟動文字分鏡放大鏡)
  ┌─────────────────────────────────────────────────────────────┐
  │ ① 特寫神態 (Eyes/Face)  : 眼神如利刃般射來，眉頭緊蹙成「川」字 │
  │ ② 慢動作 (Action)       : 雙手抱胸，右腳尖焦躁地在地板上點擊 │
  │ ③ 環境音效 (Sound)      : 空氣瞬間凝結，只聽見時鐘滴答作響   │
  │ ④ 心理共鳴 (Feeling)    : 我屏住呼吸，後背竄起一陣陣涼意     │
  └─────────────────────────────────────────────────────────────┘
```

### 📊 Show, Don't Tell 魔法升級對照表

| 想要表達的情緒/狀態 | ❌ 平淡告知 (Tell - 枯燥) | ✅ 生動展現 (Show - 畫面躍然紙上) |
| :--- | :--- | :--- |
| **生氣憤怒** | 老師今天非常生氣。 | 老師猛地將課本拍在講桌上，臉色鐵青，眉頭緊鎖成一個深深的「川」字，教室裡的空氣瞬間凝結成冰。 |
| **緊張害怕** | 站在台上我很緊張。 | 我的手心不斷冒出冷汗，心臟像有一隻小兔子在瘋狂擂鼓，拿著麥克風的右手忍不住微微顫抖。 |
| **炎熱天氣** | 今天天氣真的很熱。 | 柏油路被毒辣的太陽曬得冒出陣陣熱浪，路旁的行道樹無精打采地垂著葉子，連知了都熱得扯著嗓子嘶鳴。 |
| **悲傷難過** | 小英聽到消息後很傷心。 | 小英雙手捂著臉，淚水如斷線的珍珠般從指縫中滑落，雙肩止不住地劇烈抽泣。 |

## 🔑 核心觀念 3：五感摹寫矩陣——打通讀者的感官通道

![記敘文寫作的起承轉合 (Narrative Writing) - 圖解 3](./images/man_u2_concept3.svg)

描寫景色或場景時，善用「**視、聽、嗅、味、觸**」五種感官，能讓文章立體逼真：

```text
               ┌────────── 【五感摹寫矩陣】 ──────────┐
               │                                      │
         【👁️ 視覺】金黃色酥脆外皮    【👂 聽覺】油鍋裡滋滋作響
         【👃 嗅覺】濃郁的胡椒香氣    【👅 味覺】鮮甜肉汁在舌尖爆發
                     【✋ 觸覺】滾燙燙手、外酥內嫩
               │                                      │
               └──────────────────────────────────────┘
```

### 📊 五感摹寫實戰庫

| 感官維度 | 摹寫焦點 | 精彩範例句子 |
| :--- | :--- | :--- |
| **視覺 (Sight) 👁️** | 色彩、光影、形狀、動作態勢 | 夕陽如同一枚燒紅的銅錢，將整片天空染成了絢爛的橘紅色與紫霞。 |
| **聽覺 (Hearing) 👂** | 聲音的高低、節奏、自然音效 | 窗外春雨綿綿，「淅淅瀝瀝」地敲打著玻璃，宛如大自然演奏的催眠曲。 |
| **嗅覺 (Smell) 👃** | 氣味的濃淡、擴散、記憶聯想 | 剛踏進廚房，空氣中便瀰漫著麻油與老薑爆炒的濃郁香氣，那是家的味道。 |
| **味覺 (Taste) 👅** | 酸甜苦辣、層次變化、口感 | 輕咬一口檸檬塔，酸冽的果香瞬間在味蕾間炸裂，隨後泛起一絲絲蜂蜜的甘甜。 |
| **觸覺 (Touch) ✋** | 溫度、質地、軟硬、風的拂動 | 清晨微涼的山風拂過臉頰，腳底踩在鬆軟厚實的落葉堆上，發出沙沙的聲響。 |

## 🔑 核心觀念 4：寫作實戰法寶——6大開頭法與 5大結尾法

![記敘文寫作的起承轉合 (Narrative Writing) - 圖解 4](./images/man_u2_concept4.svg)

### 🌟 6 大吸睛開頭法

1. $\textcolor{#2196f3}{\textbf{開門見山法}}$：直接破題，簡潔有力。
   - *例*：「每當翻開書桌抽屜裡的相本，那一張泛黃的黑白照片總會勾起我無盡的思念。」
2. $\textcolor{#4caf50}{\textbf{設問懸念法}}$：拋出問題，引發讀者強烈好奇心。
   - *例*：「你曾嚐過失敗的滋味嗎？那是一杯苦澀卻能讓人回甘的黑咖啡。」
3. $\textcolor{#ff9800}{\textbf{環境渲染法}}$：描寫背景環境，營造氛圍。
   - *例*：「秋風瑟瑟，枯黃的楓葉紛紛揚揚地飄落，整條街道籠罩在一層淡淡的憂傷中。」
4. $\textcolor{#e91e63}{\textbf{對話切入法}}$：用緊張生動的對話開場，直接將讀者拉入現場。
   - *例*：「『快跑！只剩下最後三十秒了！』隊長在終點線前扯著嗓子大喊。」
5. $\textcolor{#9c27b0}{\textbf{名言引用法}}$：引用名言錦句或古詩詞，提升文章格局。
   - *例*：「古人說：『不經一番寒徹骨，怎得梅花撲鼻香？』這次的挫折，讓我對這句話有了深刻的領悟。」
6. $\textcolor{#00bcd4}{\textbf{倒敘回憶法}}$：先寫目前的成果或結果，再回溯過去的故事。
   - *例*：「凝望著架上那座閃閃發光的冠軍獎盃，我的思緒不禁飄回了一年前那個汗水淋漓的盛夏午後。」

### 🌟 5 大回味結尾法

1. $\textcolor{#2196f3}{\textbf{感悟昇華法}}$：點出事件背後的人生哲理與成長。
2. $\textcolor{#4caf50}{\textbf{首尾呼應法}}$：結尾與開頭的景物或話語相互呼應，形成完整的結構圓環。
3. $\textcolor{#ff9800}{\textbf{展望期許法}}$：帶著從事件中獲得的力量，勇敢迎向未來的挑戰。
4. $\textcolor{#e91e63}{\textbf{留白餘韻法}}$：言有盡而意無窮，留給讀者無限想像與回味空間。
5. $\textcolor{#9c27b0}{\textbf{引用點題法}}$：用一句經典名言為全文畫下最完美的句點。

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【起承轉合寫作架構剖析】
- 📌 **題目情境**：作文題目《一次難忘的接力賽跑》，請規劃「起、承、轉、合」四段的寫作大綱。
- 💡 **思考關鍵**：
  - 起：交代運動會背景與緊張期待的心情。
  - 承：描寫賽前熱身與前半段棒次的激烈競爭。
  - 轉：製造意外波折與高潮（如交接棒失誤掉棒，全力奮勇追趕）。
  - 合：總結比賽結果與體會到的團隊運動家精神。
- 📐 **詳盡步驟**：
  1. 第一段（起）：運動會晴空萬里，全班屏息以待最後壓軸的大隊接力。
  2. 第二段（承）：槍聲響起，隊友們如離弦之箭，你追我趕，比分咬得極緊。
  3. 第三段（轉）：輪到關鍵第四棒時，交接棒突然滑落！在全場驚呼中，選手迅速拾起接力棒，咬緊牙關奮起直追超越對手。
  4. 第四段（合）：雖然最終獲得亞軍，但我們體會到了「永不放棄」的真正意義。

### 📝 範例 2：【人物描寫手法示範】
- 📌 **題目情境**：如何生動描寫一位「既生氣又難過」的老師？
- 📐 **詳盡步驟**：
  - 動作與神態：老師放下手中的紅筆，雙唇緊抿，眉頭深鎖成一個川字。
  - 心理與語氣：他深深嘆了一口氣，聲音微微發顫地說：「我不是生氣你們考不好，而是心疼你們放棄了自己的潛力。」

## 🧠 迷思大破解

*   ❌ **迷思 1：寫作文一定要從「早上幾點起床、吃了什麼早餐」開始寫？**
    *   ✅ **正確觀念**：這是最標準的「流水帳」！文章要有「剪裁」與「詳略」。與主題無關的日常瑣事要大膽刪除，把最珍貴的篇幅留給最具戲劇性與情感張力的「高潮（轉折）」部分。
*   ❌ **迷思 2：只要堆砌很多深奧難懂的成語，就是一篇好作文？**
    *   ✅ **正確觀念**：成語在精不在多！生搬硬套、堆砌華麗辭藻只會讓文章顯得做作且空洞。真正打動人心的作文，往往是用真摯的情感、精準的動作描寫與生動的細節說話。
*   ❌ **迷思 3：結尾一定要寫「我以後一定要好好讀書、報效國家」？**
    *   ✅ **正確觀念**：千萬不要喊「空洞的口號」！結尾的感悟必須從小事中自然流露。寫一次打翻牛奶的經歷，結尾感悟「學會寬容與冷靜」遠比寫「要成為國家的棟樑」真誠且動人得多。

#### ⚠️ 段考高頻失分防雷提醒

1．倒敘與插敘混淆：倒敘是「整篇文章」由結果開始倒著講；插敘是主線故事中途「暫時插入一段」過去回憶後又回到主線。

2．記敘文寫成流水帳：把一天從早到晚發生的所有事情巨細靡遺全寫出來，缺少重點剪裁與高潮轉折。

3．刻畫人物缺乏細節：形容人物只寫「他是一個好人」，而沒有透過具體行動、眼神或對話展現。

4．景物描寫與文章情感割裂：描寫風景時只堆砌華麗詞藻，卻與文章所要傳達的主題情感毫不相干。

## 🧩 段考回推補強：考卷會考、容易漏掉的觀念

### 作文審題四問

拿到題目先問：

1. 寫誰？（我、他人、物品）
2. 主題是什麼？（題目裡的關鍵字，例如「一次難忘」要寫出「為什麼難忘」）
3. 文體是什麼？
4. 重點放哪裡？

切題比文筆更重要。先花兩分鐘列大綱，分配段落。

### 字詞基本功：短文注音與國字

段考常用短文的方式考注音和國字。形近字要靠字義分辨：「揪」有抓的意思，部首是手；「糾」有纏繞之意，部首是糸。常見易錯：再接再「厲」、「按」部就班、迫不及「待」、川流不「息」。

寫作時用錯字也會扣分，寫完要檢查一次。

### 段落之間要有過渡句

段與段之間可用過渡句連接。例如：「經過這件事後，我才明白……」「然而，事情並沒有這麼順利……」。

開頭可用對話、問題、景物；結尾可用抒情、呼應題目、提出行動。頭尾呼應會讓文章完整。

## 📚 必備知識補充（題庫、講義、例題逐題回推）

測驗題庫、段考講義和課文例題會考到，但前面課文沒有說清楚的知識，都整理在這裡。

- **以小見大**：從一個小物品或小事寫出深厚情感，例如從一條舊圍巾寫出外婆的愛。
- 起承轉合中的**轉**：情節出現波折、突變，或心境改變。
- **外貌和神態描寫**要寫具體細節，例如皺紋、老繭、眼神，讓讀者看見人物。
- **情景交融**：用環境景物描寫烘托氣氛、反映人物心情，或暗示後面的情節。
- **第一人稱**（我）的寫法最大好處是親切、真實，方便直接寫出內心感受。
- 用景物象徵精神：暴風雨中仍挺立的小樹苗，象徵面對挫折堅忍不拔。
- 像流水帳一樣每件事寫一樣多，是**詳略不當**；重點要詳寫，次要的略寫。
- 寫對話時加上動作和語氣，例如「他拍拍胸脯，語氣堅定地說」，人物會更生動。
- **開門見山法**：開頭直接點出題目、主題或主要事件。
- **心理描寫**中的**內心獨白**是直接寫出人物心裡對自己說的話，例如「我該不該把錢包留下？不行！」
- **過渡句**的作用是承上啟下，讓前後段自然銜接。
- 選材要切題：〈我最敬佩的人〉要寫人物事蹟，不適合介紹電玩遊戲。
- **以動襯靜**：用一點點聲音或動作反襯環境的安靜，例如「古寺很靜，只聽見竹管的落水聲」。
- 「再接再厲」的厲是磨利；「迫不及待」的及是來得及；「川流不息」的息是停止。
- 說話內容前用冒號，再用引號標出，例如：他問：「你要去哪裡？」

## 🧭 題型教學：本單元會遇到的題型

每一種題型都有自己的作答方法。先看方法，再到下面的練習題實際演練。

### 選擇題

1. 先看題目考字音、字形、詞義、修辭或閱讀。
2. 把選項放回句子裡讀，看語意和語氣。
3. 注意褒貶和使用對象。

⚠️ **常見失分**：成語只看字面意思判斷。

✏️ **馬上練習**：下方第 7 題。

### 應用題

1. 讀兩次：第一次了解情境，第二次圈出數字、單位和問句。
2. 判斷用哪個概念或公式，先列式再計算。
3. 用完整的句子作答，問幾個就答幾個。

⚠️ **常見失分**：題目問兩件事只答一件，或答案單位和題目不同。

✏️ **馬上練習**：下方第 9 題。

### 改錯題

1. 逐字讀，懷疑的字先圈起來。
2. 把字放回語詞想字義，判斷部首是否合理。
3. 寫出錯字和正確字。

⚠️ **常見失分**：只找到一個錯字就停下來，同一句可能不只一個。

✏️ **馬上練習**：下方第 13 題。
