## 🔑 核心觀念 1：與死神搶時間——CPR + AED 「叫叫CD」

當有人突然倒下，沒有呼吸心跳時，大腦只要缺氧 4-6 分鐘就會開始壞死。因此，我們必須立刻進行 **心肺復甦術 (CPR)**。為方便記憶，我們使用**「叫、叫、C、D」**四步驟：

1. 🗣️ **叫 (檢查意識與呼吸)**：拍打患者雙肩，大聲呼喊：「先生/小姐，你還好嗎？」同時觀察胸部有沒有起伏（判斷有沒有呼吸）。
2. 📱 **叫 (求救)**：大聲呼救請旁人幫忙。「請那位穿紅衣服的同學幫我打 119！請穿藍衣服的同學幫我拿 AED！」
3. 🫀 **C (Chest Compressions，胸外按壓)**：
   - **位置**：兩乳頭連線中間的胸骨上。
   - **姿勢**：雙手十指緊扣，掌根貼緊胸骨，手臂打直，利用上半身的重量下壓。
   - **深度與速率**：下壓深度約 **5 公分**，速率維持在每分鐘 **100~120 下**（可以心裡默唱《Baby Shark》的節奏）。
   - *(註：在醫院外，目前推廣針對一般民眾的「單純按壓式CPR」，不用做人工呼吸，持續按壓直到救護人員抵達)*
4. ⚡ **D (Defibrillation，使用 AED 電擊去顫)**：AED 是一台會講話的傻瓜電擊器。
   - **開**：打開電源，聽從語音指示。
   - **貼**：將兩塊貼片貼在患者「右鎖骨下」與「左邊肋骨下緣」。
   - **分析**：機器分析心律時，**所有人離開，不要碰觸患者**。
   - **電**：若機器建議電擊，按下閃爍的電擊鈕（按下前必須大喊「大家離開！」確保沒人碰到患者）。

📊 **CPR 完整步驟流程表**

| 步驟口訣 | 動作重點說明 | 關鍵注意點 |
| :--- | :--- | :--- |
| **叫** (確認狀態) | 拍雙肩、大聲呼喊，看胸部有無起伏 | 只要「沒有正常呼吸」，就視為心跳停止 |
| **叫** (尋求救援) | 指定明確的人打 119 與拿 AED | 指定特徵（如：戴眼鏡的同學），避免沒人去 |
| **C** (胸外按壓) | 掌根在兩乳頭中間，用力壓、快快壓 | 深度 5cm，速率 100-120下/分，**胸部要完全回彈** |
| **D** (使用 AED) | 開機 $\rightarrow$ 貼片 $\rightarrow$ 分析 $\rightarrow$ 電擊 | 分析與電擊時，嚴禁任何人觸碰患者 |

## 🔑 核心觀念 2：異物卡喉嚨的救星——哈姆立克法

當有人吃東西噎到，出現雙手掐住脖子、無法說話咳嗽、臉色發青的情況時，代表呼吸道被完全阻塞了！這時要立刻使用**哈姆立克法**。

- **站立成人/兒童自救**：站在患者正後方，一腳前一腳後。一手握拳（大拇指側貼住患者肚臍上方的腹部），另一手包住拳頭，**向內向上**快速用力擠壓，利用肺部剩餘的空氣把異物「推」出來。
- **嬰兒適用**：使用「拍背壓胸法」，不能直接擠壓腹部。
- **自救**：如果只有自己一個人，可以將腹部頂住椅背或桌角，用力向內向上擠壓。

📊 **CPR vs 哈姆立克適用情境比較表**

| 比較項目 | 🫀 CPR (心肺復甦術) |  Heimlich (哈姆立克法) |
| :--- | :--- | :--- |
| **適用對象狀況** | 失去意識、**沒有呼吸**、倒在地上。 | 意識清醒，雙手掐脖，**無法呼吸/咳嗽**。 |
| **急救原理** | 代替心臟壓出血液，維持大腦供氧。 | 利用腹部壓力將氣管中的異物排出。 |
| **操作位置** | 胸骨正中央（兩乳頭連線中點）。 | 肚臍上方與胸骨下緣之間的腹部。 |

## 🔑 核心觀念 3：急性運動傷害的 PRICE 五步驟

運動難免會遇到拉傷、扭傷。遇到這類「急性運動傷害」，立刻執行 **PRICE** 步驟，可以大幅減少發炎與腫脹！

📊 **PRICE 急性運動傷害處理表格**

| 步驟字首 | 英文與中文 | 處理方法與目的 |
| :--- | :--- | :--- |
| **P** | **Protection (保護)** | 立刻停止運動，使用夾板或拐杖保護受傷部位，避免二次傷害。 |
| **R** | **Rest (休息)** | 讓受傷部位安靜休息，不再走動或給予重量。 |
| **I** | **Ice (冰敷)** | 急性期(前24~48小時)冰敷。每次 10~15 分鐘。目的：讓血管收縮，減少出血與腫脹。 |
| **C** | **Compression (壓迫)** | 用彈性繃帶從受傷部位「遠端往近端」包紮壓迫。目的：減少腫脹。 |
| **E** | **Elevation (抬高)** | 將受傷部位抬高超過心臟的位置。目的：促進血液回流，減少組織水腫。 |

🏠 **生活案例**：
小華跑步扭傷腳踝。同學馬上扶他坐下（保護+休息），護理師阿姨拿來冰袋包著毛巾敷在他的腳踝上（冰敷），接著用彈性繃帶幫他包紮（壓迫），並拿了一張椅子讓他把腳放上去（抬高）。這就是標準的 PRICE 流程！

## 🔑 核心觀念 4：日常急救小常識

生活中常會遇到一些小意外，錯誤的處理方法可能會讓情況更糟。

📊 **日常急救情境處理方法比較表**

| 意外狀況 | ❌ 常見的錯誤處理方式（千萬別做） | ✅ 正確的急救處理方式 |
| :--- | :--- | :--- |
| **流鼻血** | 頭往後仰（血液會流進呼吸道導致嗆到）。 | 頭部**微往前傾**，用手指捏住鼻翼兩側軟骨壓迫止血 5~10 分鐘，可用冰塊冰敷鼻樑。 |
| **擦傷流血** | 塗抹優碘、雙氧水或撒消炎粉（會破壞細胞）。 | 用**乾淨的清水/生理食鹽水**沖洗掉泥沙，用紗布壓迫止血，貼上人工皮或OK繃保持濕潤。 |
| **燙傷** | 塗牙膏、醬油、麵速力達母（易感染且散熱慢）。 | 遵循**「沖、脫、泡、蓋、送」**。先在流動冷水下沖 15~30 分鐘降溫。 |
| **運動抽筋** | 用力搥打肌肉。 | 輕輕**反向伸展**抽筋的肌肉（例如小腿後側抽筋，將腳尖往身體方向扳），並適度補充水分。 |

## 🧠 迷思大破解

- ❌ **迷思一：如果做 CPR 不小心把別人的肋骨壓斷了，我會不會被告？**
  - ✅ **破解**：不用擔心！台灣有《緊急醫療救護法》（被稱為善良的撒瑪利亞人法），保障基於善意救人的民眾，在進行急救時若造成傷害，可以免除法律責任。救人一命最重要，不要因為害怕而不敢壓！
- ❌ **迷思二：流鼻血的時候要趕快把頭往後仰，才不會讓血流出來。**
  - ✅ **破解**：大錯特錯！頭往後仰會讓鼻血倒流進喉嚨，吞進胃裡會想吐，流進氣管甚至會造成窒息！正確姿勢是頭部「微向前傾」，從外面捏住鼻翼止血。
- ❌ **迷思三：扭傷腳的當下要馬上用力揉它，或是塗抹熱水把瘀血揉散。**
  - ✅ **破解**：絕對不行！扭傷剛發生的 48 小時內屬於「急性發炎期」，血管正在破裂出血。這時候推拿、熱敷只會讓血管擴張，越腫越大。剛受傷一定要先「冰敷」和「休息」。

## ✏️ 隨堂自我小練習

1. **（選擇題）** 實施 CPR 胸外按壓時，正確的下壓深度與頻率大約是多少？
   (A) 深度 2 公分，每分鐘 60 下 (B) 深度 5 公分，每分鐘 100~120 下 (C) 深度 10 公分，每分鐘 80 下 (D) 越深越好，越快越好
   **解答**：(B)。深度約 5 公分，頻率 100~120下/分。
2. **（選擇題）** 同學在餐廳吃貢丸不小心噎到，雙手掐著脖子無法發出聲音，你應該立刻採取什麼行動？
   (A) 給他喝一大口水 (B) 幫他實施 CPR (C) 幫他實施哈姆立克法 (D) 叫他用力深呼吸
   **解答**：(C)。異物完全梗塞時應立刻使用哈姆立克法。
3. **（是非題）** 遇到有人倒地不醒，我們使用 AED 機器時，當機器正在「分析心律」和「準備電擊」時，我們都不能碰到患者的身體。
   **解答**：✅ 正確。碰到患者會干擾機器分析，電擊時觸碰則會讓救護者自己觸電。
4. **（情境題）** 小明在打掃時不小心把熱水灑在手上，手臂紅腫非常痛。請寫出燙傷處理的正確五字訣，並說明第一步該怎麼做？
   **解答**：沖、脫、泡、蓋、送。第一步是「沖」，要在流動的冷水下沖 15~30 分鐘，幫受傷的皮膚快速降溫。

## 🌍 你知道嗎？

💡 **AED 貼片為什麼是一上一下？**
AED 電擊去顫器的貼片，一片貼在右鎖骨下，另一片貼在左側肋骨下緣。你知道為什麼要這樣貼嗎？因為我們的心臟剛好位在胸腔的中央偏左，這樣一上一下的貼法，可以讓 AED 發出的電流「斜著穿越心臟」，將混亂跳動的心臟瞬間「重新開機」，這就是電擊去顫的科學原理喔！

🚁 **無人機送 AED：高科技急救網**
當有人心跳停止時，每晚一分鐘急救，存活率就會下降 10%。但在山上或是交通大打結的都市，救護車很難在黃金 5 分鐘內趕到。現在，瑞典等國家已經開始測試「無人機運送 AED」系統！當有人撥打 119，系統會立刻派出一架裝載 AED 的自動駕駛無人機，從天空直線飛到報案地點，直接空投 AED 給現場民眾使用，比救護車快上好幾倍！科技結合醫療，正在改變未來的急救模式！
