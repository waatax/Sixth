**單元 5：法律與生活——兒童人權與網路安全**
（108課綱核心素養：社-E-A1、社-E-A2、社-E-C1）
**學習目標：** 了解兒童應享有的基本權利，認識網路世界的法律規範（著作權、個資保護與網路霸凌），培養知法守法的法治觀念。

## 🎯 學習導引：為什麼要學這個？
你每天上網打遊戲、看影片、在通訊軟體上聊天，覺得這些都只是好玩嗎？其實，網路世界和真實世界一樣，都有法律在保護我們，也規範我們的行為。隨便轉傳一張好笑的同學照片，或者複製別人的文章當作自己的作業，可能都已經觸法了喔！學會這些法律知識，不只能保護自己，也能避免不小心傷害別人。

## 🔑 核心觀念 1：聯合國兒童權利公約 (CRC) 四大原則
兒童（18歲以下）因為心智還在發展，需要特別的保護。聯合國制定了CRC，強調兒童不是大人的附屬品，而是擁有獨立權利的主體。

📊 **CRC四大原則完整表格**

| 原則名稱 | 簡單定義 | 🏠 生活實例 |
| :--- | :--- | :--- |
| **生存權** | 擁有基本的生存條件與醫療照顧 | 生病時父母必須帶你看醫生；擁有乾淨的食物和水。 |
| **受保護權** | 免於暴力、虐待、疏忽與剝削 | 禁止家暴、禁止雇用童工；免受網路霸凌。 |
| **發展權** | 有接受教育、休閒遊戲與參與文化活動的權利 | 你有權利上學受教育，也有權利擁有下課玩耍的時間。 |
| **參與權** | 有權表達意見，且意見應受到大人的重視 | 學校決定營養午餐菜單或制服款式時，聽取學生的意見。 |

## 🔑 核心觀念 2：著作權保護與合理使用
- **著作權**：保護創作人的心血。文章、圖畫、音樂、影片，只要創作完成就受保護。
- **合理使用**：為了學校寫報告，可以「合理引用」別人的資料，但一定要「註明出處」，而且不能整篇照抄。

## 🔑 核心觀念 3：個資防護與網路霸凌
- **個人資料**：姓名、身分證字號、地址、電話、照片等，只要能辨識出你是誰的資料都是個資。
- **防護 3不原則**：不隨意**上傳**私密照片、不**分享**朋友個資、不向陌生網友**透露**真實身分。
- **網路霸凌**：在網路上散布謠言、留下辱罵字眼、排擠同學。這不只是開玩笑，可能觸犯「公然侮辱罪」或「誹謗罪」。

🏠 **生活案例**：
1. **複製作業侵權**：小明寫報告時，把維基百科的內容全部複製貼上，當作自己的作品交出去。這不只違反校規，更是侵害了著作權！
2. **網路詐騙與求助**：如果在網路上買遊戲點數遇到詐騙，要立刻截圖保存對話紀錄，並告訴父母或撥打 **165反詐騙專線**。

## 🔑 核心觀念 4：少年事件處理法基本概念
為了保護犯錯的未成年人（12歲以上未滿18歲），臺灣有特別的《少年事件處理法》。重點不在於嚴厲處罰，而是幫助少年「改過自新」，提供輔導與教育，讓他們有重新開始的機會。

## 🧠 迷思大破解
❌ **錯誤迷思 1**：在網路上用假名罵人，警察絕對抓不到我。
✅ **正確觀念**：凡走過必留下痕跡！警方可以透過網路 IP 位址追蹤到發文者，躲在鍵盤後面罵人一樣要負法律責任。

❌ **錯誤迷思 2**：我是小孩，就算犯法也不會被關，所以沒關係。
✅ **正確觀念**：少年犯法雖然適用《少年事件處理法》以輔導為主，但情節嚴重者仍會被收容或感化教育。而且，你的父母必須負起連帶的「民事賠償責任」！

❌ **錯誤迷思 3**：父母未經同意偷看我的日記或手機，是因為他們愛我，沒有關係。
✅ **正確觀念**：這可能侵犯了兒童的「隱私權」（受保護權的一環）。大人應該用溝通代替偷看，尊重兒童也是獨立的個體。

## 🚀 +10% 現代素養前瞻新知
**「數位足跡（Digital Footprint）」**：你在網路上按的每一個讚、留的每一言、搜尋的每一個關鍵字，都會被記錄下來，這就是數位足跡。而且這些足跡「永遠不會消失」！現在許多大學面試或公司找人時，都會去搜尋對方的網路發言。所以，在按下「發送」鍵之前，請想一想：這句話在十年後被別人看到，你會不會後悔？
