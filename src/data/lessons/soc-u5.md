## 🔑 核心觀念 1：聯合國《兒童權利公約 (CRC)》四大基本原則
![圖解說明](./images/soc_u5_concept1.jpg)

聯合國在 1989 年通過《兒童權利公約》（CRC），明確指出：未滿 18 歲的兒童**不是大人的附屬品**，而是擁有完整人權與尊嚴的「$\textcolor{#2196f3}{\textbf{獨立權利主體}}$」！

```text
               【 聯合國兒童權利公約 (CRC) 四大支柱 】

                      ┌─────────────────────────┐
                      │    兒童四大核心權利     │
                      └────────────┬────────────┘
        ┌──────────────────┬───────┴──────────┬──────────────────┐
        ▼                  ▼                  ▼                  ▼
 ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
 │  ① 生存權   │    │ ② 受保護權 │    │  ③ 發展權   │    │  ④ 參與權   │
 │ (基本生命與 │    │ (免受暴力、 │    │ (教育、休閒 │    │ (自由表達與 │
 │  醫療照護)  │    │ 虐待與剝削) │    │  遊戲與文化)│    │  意見受尊重)│
 └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 📊 兒童權利公約四大原則深度對照表

| 原則名稱 | 核心意涵 | 🏠 生活情境與權利實踐 | 違法侵權反面案例 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{生存權}}$<br>(Life) | 享有生存與發展的最基本權利，獲得足夠營養、住所與醫療照顧。 | 生病時家長帶孩子就醫；國家提供兒童免費疫苗接種。 | 惡意棄養嬰幼兒；不給兒童吃飽穿暖。 |
| $\textcolor{#e91e63}{\textbf{受保護權}}$<br>(Protection) | 免於一切形式的身體暴力、精神虐待、性剝削、疏忽照顧與童工勞動。 | 受到家庭暴力時可撥打 113 尋求社工與警方緊急保護。 | 父母體罰虐待小孩；逼迫未滿法定年齡兒童從事危險工作。 |
| $\textcolor{#9c27b0}{\textbf{發展權}}$<br>(Development) | 享有充分接受教育、休息休閒、從事遊戲與文化藝術活動的權利。 | 享有 $12$ 年國民基本教育；下課享有戶外運動與玩耍時光。 | 強迫學童輟學打工；剝奪孩子正常的休息與遊戲時間。 |
| $\textcolor{#ff9800}{\textbf{參與權}}$<br>(Participation) | 對於與自身相關的一切事務，有自由表達意見並獲得大人認真聆聽的權利。 | 學校在研議修改校規、制服或營養午餐菜單時，納入學生代表。 | 大人在涉及孩子監護權時完全不聽取孩子的意願與想法。 |

## 🔑 核心觀念 2：智慧財產權與「著作權合理使用」
![圖解說明](./images/soc_u5_concept2.jpg)

### 📚 著作權 (Copyright) 的核心精神
- 只要作者創作出文章、繪畫、照片、音樂或程式碼，「$\textcolor{#2196f3}{\textbf{在創作完成的那一刻}}$」，就自動享有著作權，不需要特別登記或申請！
- 著作權包含：**著作人格權**（姓名表示、公開發表等）與 **著作財產權**（重製、公開播送、改作等）。

```text
               【 課堂作業「著作權合理使用」三原則 】

           ① 目的正當 ──► 限於個人學習、學校課堂報告研究使用
           ② 比例適當 ──► 僅能引用部分圖文，絕不能全篇照抄複製
           ③ 明確標示 ──► 必須在作業末尾清楚標註「作者與來源出處」
```

### 🔣 認識創用 CC (Creative Commons) 授權標誌
在網路上尋找報告素材時，可挑選作者標記創用 CC 的作品：
- 👤 **BY（姓名標示）**：只要標註原作者名字就可以使用。
- 🚫 **NC（非商業性）**：不能拿來賺錢賣商品。
- 🔄 **SA（相同方式分享）**：改作後的作品也必須用相同方式公開。
- 🚷 **ND（禁止改作）**：只能原封不動使用，不能修圖或剪輯改編。

## 🔑 核心觀念 3：個資防護、網路霸凌與兒少防護
![圖解說明](./images/soc_u5_concept3.jpg)

網路世界具有「傳播快、範圍廣、足跡永久留存」的特性，必須謹記自我保護防線！

```text
                     【 網路安全「三不一要」防護金律 】

         ❌ 不隨意發布 ──► 絕不上傳自己的身體隱私照與機密個資
         ❌ 不任意轉傳 ──► 絕不轉發同學的醜照、嘲諷貼圖或未求證謠言
         ❌ 不單獨見面 ──► 絕不私下與陌生網友單獨約在隱密地點見面
         ✅ 要勇敢求助 ──► 遇到恐嚇、勒索或霸凌，立即截圖並告訴師長
```

### ⚖️ 網路違法行為之刑事法律責任對照表

| 常見網路脫序行為 | 觸犯之法律與罪名 | 法律後果與責任 |
| :--- | :--- | :--- |
| 在社群平臺或群組用難聽字眼（如「豬頭」、「垃圾」）辱罵同學 | 刑法：$\textcolor{#d32f2f}{\textbf{公然侮辱罪}}$ | 需負刑事責任，並面臨名譽損害之民事金錢賠償。 |

| 盜用同學的帳號密碼登入遊戲偷走虛擬寶物或發文 | 刑法：$\textcolor{#d32f2f}{\textbf{妨害電腦使用罪}}$ | 涉及違法入侵他人系統，處有期徒刑或罰金。 |
| 拍攝、持有、散布或誘騙他人提供未成年私密影像 | 違反《$\textcolor{#d32f2f}{\textbf{兒童及少年性剝削防制條例}}$》 | **重大犯罪！** 處數年以上重刑，絕無寬貸！ |

## 🔑 核心觀念 4：《少年事件處理法》與家長連帶民事賠償
![圖解說明](./images/soc_u5_concept4.jpg)

我國法律對未滿 18 歲的少年有特別的保護機制：

```text
               ┌───────────────────────────────┐
               │    少年事件處理法 (12~18歲)   │
               └──────┬─────────────────┬──────┘
                      ▼                 ▼
             ┌────────────────┐ ┌────────────────┐
             │ 核心目的：輔導 │ │ 家長連帶責任   │
             │(保護教育、矯正)│ │(民法187條賠償) │
             └────────────────┘ └────────────────┘
```

1. **輔導為先的精神**：少年因心智仍在成熟階段，若觸犯法律，少年法院以「$\textcolor{#4caf50}{\textbf{保護處分}}$」（如：假日生活輔導、保護管束、感化教育）為主，目的在導正偏差行為，給予少年重新站起來的機會。
2. **父母連帶賠償責任**：依據《民法》第 187 條規定，未成年人如果侵害他人權利（例如霸凌造成同學受傷或名譽受損），其**法定代理人（父母）必須與少年負連帶損害賠償責任**，父母將面臨龐大的金錢賠償！

## 🧠 迷思大破解

❌ **迷思 1**：在網路上開分身假帳號罵人，警察一定查不到我？
✅ **正確觀念**：網路凡走過必留下痕跡！警方可透過網路 IP 位址、連線歷程向電信公司申請調閱使用者真實身分，躲在鍵盤後面造謠辱罵一樣會被依法送辦！

❌ **迷思 2**：我是小學生未滿 18 歲，犯法反正不會被關，所以不用害怕？
✅ **正確觀念**：大錯特錯！少年觸犯法律情節重大者，仍會被裁定送進少年矯正學校執行「感化教育」限制人身自由，且父母更要承擔鉅額民事賠償，絕不可心存僥倖！

❌ **迷思 3**：父母偷看小孩的手機私訊和日記，是因為關心，不算侵權？
✅ **正確觀念**：聯合國 CRC 公約與我國憲法均保障兒童的「**隱私權**」。家人之間應建立互信與開放對話，大人不應以未經同意的偷看方式侵犯孩子的隱私空間。

## ✏️ 隨堂自我小練習

1. **(選擇題)** 學校在重新規劃下課活動區與修訂班規時，主動舉辦學生座談會聽取六年級同學的看法。請問這符合聯合國《兒童權利公約 (CRC)》中的哪一項基本原則？
   (A) 生存權  
   (B) 受保護權  
   (C) 發展權  
   (D) 參與權  
   **💡 解析**：選 $\textcolor{#2196f3}{\textbf{(D)}}$。兒童有權對涉及自身的事務表達意見，並獲得大人的尊重與採納，此為「參與權」。

2. **(選擇題)** 小宇在班級網頁上發表文章，看見網路上有一幅具有創用 CC 標誌「👤 BY、🚫 NC」的插畫作品。請問小宇可以在下列哪一種情況下合法使用這幅插畫？
   (A) 將插畫印在 T 恤上拿到學校園遊會販賣賺錢  
   (B) 將插畫塗改面貌後當作自己的原創作品發表  
   (C) 在作業中引用插畫，並清楚標示原作者姓名且不作為商業營利用途  
   (D) 完全不標註作者直接當作網站首頁封面  
   **💡 解析**：選 $\textcolor{#2196f3}{\textbf{(C)}}$。「BY」代表需姓名標示，「NC」代表非商業使用，因此在標註作者且非營利報告中使用是合法的。

3. **(選擇題)** 小明因為跟同學吵架，憤而在 Instagram 公開動態上張貼同學的醜照並用不堪入目的三字經髒話羞辱對方。請問小明的行為最可能觸犯刑法中的哪一項罪名？
   (A) 竊盜罪  
   (B) 公然侮辱罪  
   (C) 侵占罪  
   (D) 妨害秘密罪  
   **💡 解析**：選 $\textcolor{#2196f3}{\textbf{(B)}}$。在不特定多數人可共見共聞的網路上以言語侮辱他人人格，構成刑法「公然侮辱罪」。

4. **(簡答題)** 如果你在網路遊戲中，遇到陌生網友以「送高級武器」為誘餌，要求你開啟視訊鏡頭拍攝身體隱私部位，你應該採取哪些正確的自我保護步驟？
   **💡 參考答案**：
   - 第一時間**堅決拒絕**對方的要求。
   - **立刻截圖存證**對話紀錄與帳號資訊，並封鎖檢舉該用戶。
   - **立即告訴父母或學校老師**，必要時撥打 **110 報案專線** 或 **113 保護專線** 求助。
