# 單元 5：圓周長與扇形

> 🎯 學完這個單元，你就能算出任何圓形或扇形的周長！

---

## 認識圓周率 π

### 什麼是圓周率？

你有沒有試過用繩子繞圓形物品一圈，然後量量看繩子有多長？

科學家發現，不管圓多大多小：

> **圓周長 ÷ 直徑 = 一個固定的數 ≈ 3.14159...**

這個神奇的固定數，就叫做**圓周率**，用希臘字母 **π**（讀作 pai）來表示。

### 📌 重要數值

- π ≈ **3.14**（小學常用）
- π ≈ **3.14159**（更精確）
- π 是一個永遠除不盡的數（無限不循環小數）

### 🧪 動手驗證

找幾個圓形的東西（杯蓋、硬幣、時鐘），用繩子量周長和直徑，算算看：

| 物品 | 周長 (cm) | 直徑 (cm) | 周長 ÷ 直徑 |
|------|-----------|-----------|------------|
| 杯蓋 | 約 25.1 | 約 8 | ≈ 3.14 |
| 硬幣 | 約 8.2 | 約 2.6 | ≈ 3.15 |

每一個都會接近 3.14，是不是很神奇！

## 圓周長公式

### 🔑 核心公式

已知**直徑 d**：

> **C = π × d = πd**

已知**半徑 r**（直徑 = 2 × 半徑）：

> **C = 2 × π × r = 2πr**

### 📝 範例 1：直徑 10 公分的圓

```
C = πd
C = 3.14 × 10
C = 31.4 公分
```

### 📝 範例 2：半徑 7 公分的圓

```
C = 2πr
C = 2 × 3.14 × 7
C = 6.28 × 7
C = 43.96 公分
```

### 📝 範例 3：已知周長求半徑

一棵大樹的樹幹周長是 157 公分，求直徑。

```
C = πd
157 = 3.14 × d
d = 157 ÷ 3.14
d = 50 公分

半徑 = 50 ÷ 2 = 25 公分
```

## 半圓和扇形的周長

### 🔑 半圓周長

半圓的周長包含兩部分：
1. **弧長**（圓周的一半）= πr
2. **直徑**（底下那條直線）= 2r

> **半圓周長 = πr + 2r**

### 📝 範例：半徑 5 公分的半圓

```
弧長 = π × 5 = 3.14 × 5 = 15.7 公分
直徑 = 2 × 5 = 10 公分

半圓周長 = 15.7 + 10 = 25.7 公分
```

### 🔑 扇形弧長

扇形就像一片披薩🍕，它是圓的一部分。

> **弧長 = 圓周長 × (圓心角 / 360°)**

### 📝 範例 1：半徑 6 公分、圓心角 90° 的扇形

```
圓周長 = 2 × 3.14 × 6 = 37.68 公分

弧長 = 37.68 × (90 / 360)
     = 37.68 × 1/4
     = 9.42 公分
```

扇形的周長（整圈）= 弧長 + 兩條半徑

```
扇形周長 = 9.42 + 6 + 6 = 21.42 公分
```

### 📝 範例 2：半徑 10 公分、圓心角 60° 的扇形

```
圓周長 = 2 × 3.14 × 10 = 62.8 公分

弧長 = 62.8 × (60 / 360)
     = 62.8 × 1/6
     ≈ 10.47 公分

扇形周長 = 10.47 + 10 + 10 = 30.47 公分
```

## 常見角度的扇形

記住這些常見比例，計算更快速：

| 圓心角 | 佔圓的比例 | 弧長 |
|--------|-----------|------|
| 360° | 整圓 | 2πr |
| 180° | 1/2 圓 | πr |
| 120° | 1/3 圓 | 2πr/3 |
| 90° | 1/4 圓 | πr/2 |
| 60° | 1/6 圓 | πr/3 |

## 迷思大破解

### ❌ 迷思 1：「半圓的周長就是圓周長的一半」

**錯！** 半圓的周長 = 弧長（圓周的一半）**加上直徑**。

很多同學忘記加直徑那條線，答案就少了一截！

正確算法：半圓周長 = πr + 2r

### ❌ 迷思 2：「圓周長 = πr」

**錯！** 差了一個 2！

- 圓周長 = **2**πr = πd
- 千萬不要漏掉那個 **2** 喔！

### ❌ 迷思 3：「扇形周長就是弧長」

**錯！** 扇形的周長 = 弧長 + **兩條半徑**。

扇形像一片披薩，除了弧邊，還有兩條直線邊呢！

### ❌ 迷思 4：「π = 3.14，就是剛好這個數」

**不完全對！** 3.14 只是 π 的近似值。π 其實是無限不循環小數 3.14159265...

在考試中，題目如果沒有特別說明，就用 3.14 來算。
