# 📌 單元標題與學習目標：單元 6 戶外冒險、無痕山林與危機自主應變

**課綱指標**：$\textcolor{#2e7d32}{\textbf{綜 1-III-3}}$ 能自主規劃戶外探索活動，掌握洋蔥式三層穿衣法、裝備檢查與環境天候風險評估技能。  
$\textcolor{#2e7d32}{\textbf{綜 3-III-2}}$ 熟練指北針操作與等高線地圖判讀，並能在野外迷途時落實「STOP 原則」與「求生 333 原則」自主脫困。  
$\textcolor{#2e7d32}{\textbf{環 2-III-1}}$ 深入實踐無痕山林（Leave No Trace, LNT）七大黃金準則，成為敬畏自然、守護生態的負責任綠色冒險家。

**學習目標**：學會避免棉質衣物引發致命失溫的「三層穿衣法（排汗、保暖、防風雨）」；精熟等高線疏密陡緩與指北針定向越野（Orienteering）技巧；將無痕山林七大準則化為生活本能；徹底破除「山中迷路要順著溪谷往下走」的致命錯誤迷思；學會用三聲國際求救哨音與求生毯保障生命安全！

## 🎯 學習導引：為什麼要學這個？

六年級的童軍露營、畢業登山或是全家週末露營，是親近大自然最棒的機會：
- 🏕️ **戶外場景 A（令人措手不及的午後雷陣雨）**：
  - 剛上山時晴空萬里，下午突然烏雲密布下起傾盆大雨！氣溫從 28℃ 驟降到 15℃，全身體溫狂掉、瑟瑟發抖……
  - 穿純棉 T 恤的人衣服濕透貼在身上，而穿防風排汗機能服的人卻依然溫暖乾爽！
- 🧭 **戶外場景 B（在森林岔路迷失方向）**：
  - 走著走著，發現前面的路標不見了，手機完全沒有 4G 訊號，四周全是一模一樣的高大樹木，你該慌亂到處亂跑，還是留在原地？

| 戶外探險要素 | 盲目冒險（容易發生山難） | 科學探險（安全又敬畏自然） |
| :--- | :--- | :--- |
| **服裝穿著** | 穿棉質牛仔褲、吸水全棉 T 恤 | 洋蔥式三層穿著：排汗層 + 保暖層 + 防風雨外層 |
| **環境態度** | 隨意採摘花木、丟棄果皮廚餘在山林 | 嚴格落實「無痕山林 (LNT)」七大準則，垃圾全數帶下山 |

| **導航工具** | 僅依賴隨時可能沒電的手機線上地圖 | 預先下載「離線地圖」、隨身攜帶實體地圖與指北針 |

## 🔑 核心觀念 1：戶外行前裝備與洋蔥式三層穿搭法

![戶外冒險與危機應變 (Outdoor Adventure & LNT) - 圖解 1](./images/comp_u6_concept1.svg)

在野外，**「失溫（Hypothermia）」是山林中威脅生命的第一大殺手**！

```text
                  [ 洋蔥式三層穿衣法系統 ]
┌────────────────────────────────────────────────────────┐
│ 【外層 (Outer Layer)】：防風防水防護層                 │
│ - 材質：GORE-TEX 或防風防水透氣風雨衣                  │
│ - 功能：阻絕強烈冷風與暴雨，鎖住體溫不被風寒效應帶走   │
├────────────────────────────────────────────────────────┤
│ 【中層 (Middle Layer)】：保暖蓄熱層                    │
│ - 材質：刷毛衣 (Fleece) 或輕量羽絨衣                   │
│ - 功能：抓住靜止空氣形成保暖層，維持身體核心溫度       │
├────────────────────────────────────────────────────────┤
│ 【底層 (Base Layer)】：排汗透氣層                      │
│ - 材質：聚酯纖維、羊毛等「快乾排汗機能布料」           │
│ - 功能：迅速將汗水導離皮膚表面，保持乾爽避免著涼       │
└────────────────────────────────────────────────────────┘
```

> ⚠️ **致命大禁忌——絕對不穿純棉（Cotton）衣物進山！**
> 登山界有一句名言：「**Cotton Kills（棉花會殺人）！**」
> 純棉吸水性極強卻極難乾燥，流汗或淋雨後棉衣像一塊濕冷海綿緊貼皮膚，散熱速度是乾衣服的 25 倍，能在短短數小時內引發失溫昏迷！

## 🔑 核心觀念 2：無痕山林 (Leave No Trace, LNT) 七大黃金準則

![戶外冒險與危機應變 (Outdoor Adventure & LNT) - 圖解 2](./images/comp_u6_concept2.svg)

無痕山林源自美國，是一套保護自然環境、讓後代子孫享有原始美景的全球環境倫理：

```text
               ┌───────────────────────────────────────────────┐
               │              無痕山林 (LNT) 七大準則          │
               └───────────────────────┬───────────────────────┘
  ┌────────────┬────────────┬─────────────┼────────────┬────────────┐
  ▼            ▼            ▼             ▼            ▼            ▼
【1.事前規劃】【2.走在步道】【3.妥善處垃圾】【4.保持原貌】【5.減低用火】【6.尊重野生物】
掌握天氣路況  不抄捷徑破壞  廚餘果皮帶下山 不摘野花石頭  使用爐具不生火 遠觀不餵食不驚擾
```
- **準則 7：考量其他使用者 (Be Considerate of Other Visitors)**：在步道上保持禮貌輕聲細語、上坡者優先通行、不外放吵鬧音樂。
- 🍎 **迷思破解：香蕉皮和果皮可以隨手丟在山林裡當肥料嗎？**
  - **絕對不行！** 高山氣溫低、微生物活性弱，一個香蕉皮需要整整 2 年才能完全分解；且人類水果的殘留農藥會害野生動物生病，改變動物覓食習性！

## 🔑 核心觀念 3：等高線地圖、定向越野與野外迷途 STOP 原則

![戶外冒險與危機應變 (Outdoor Adventure & LNT) - 圖解 3](./images/comp_u6_concept3.svg)

### 1. 等高線地圖 (Contour Map) 的閱讀密碼：
- **等高線密集** $\rightarrow$ 地形陡峭（懸崖或陡坡）！
- **等高線稀疏** $\rightarrow$ 地勢平緩（平台或鞍部）！
- **同心圓閉合且內圈數值最高** $\rightarrow$ 山頂（峰頂）！

### 2. 野外迷路求生指南——「STOP 原則」：
如果發現自己脫隊、迷失方向，請立刻默念四個英文字母：
1. **S (Stop 停下腳步)**：立刻原地停下！絕對不能驚慌盲目亂跑，越跑只會離步道越遠。
2. **T (Think 冷靜思考)**：回想最後看見路標或隊友的地方是哪裡？現在大約幾點？
3. **O (Observe 仔細觀察)**：環顧四周，尋找避風避雨的遮蔽處，檢查背包裡的水、乾糧與保暖衣物。
4. **P (Plan 制定計畫)**：穿上防風衣或披上金色求生毯，吹哨發出求救訊號，留在原地等待搜救！

```text
                  [ 野外求生極限 333 原則 ]
   ┌───────────────────────────────────────────────────────────┐
   │ ❄️ 人在失溫狀態下，只能存活 【3 小時】！(保暖是第一優先！) │
   │ 💧 人在完全沒有水的情況下，只能存活 【3 天】！             │
   │ 🍞 人在完全沒有食物的情況下，能維持生命約 【3 週】！        │
   └───────────────────────────────────────────────────────────┘
```

> 💥 **全台搜救隊呼籲的最高鐵則**：**「迷路千萬不要往溪谷下切！」**
> 很多山友以為順著河流往下走會有人家，但臺灣高山溪谷全是落差幾十公尺的深淵瀑布與濕滑巨石，下切容易摔傷受困，且溪谷水聲轟隆會掩蓋搜救呼喊，上方有濃密樹冠阻擋空拍機與直升機搜索。**留在有遮蔽的稜線高處原地待援，生還率高達 90% 以上！**

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【野外迷路求生情境處置】
- 📌 **題目情境**：六年級的小華在森林步道健行時不慎脫離隊伍，天色逐漸昏暗，山風呼嘯，氣溫驟降。請問小華此時採取哪一項行動最正確？
  - (A) 順著山坡溪谷一路往下衝，尋找村落
  - (B) 躲在一處能避風雨的岩壁下，拿出求生毯包裹身體，每隔一分鐘吹響三聲短哨，在原地等待搜救
  - (C) 大聲哭喊直到把體力耗盡
  - (D) 嘗試爬到最高的大樹樹頂睡覺
- 💡 **思考關鍵**：防失溫第一（求生 333 原則）、不下切溪谷、原地吹哨待援。
- 📐 **詳盡步驟**：
  1. 依據求生 333 原則，失溫 3 小時即可致命，保暖是第一優先，披上求生毯防風保溫。
  2. 留在原地不盲目移動，利用哨子節省體力並發出穿透力極強的定向求救訊號。
- **答案**：$\mathbf{(B)}$。

### 📝 範例 2：【背包打包重心配置】
- 📌 **題目情境**：在整理登山背包時，帳篷、瓦斯罐、水壺等「較重的物品」，應該放在背包的哪一個位置最省力且不易跌倒？
- 📐 **詳盡步驟**：
  - 重物應該打包在「**靠近背部中上方（靠近身體肩胛骨重心處）**」！
  - 若將重物放在背包最底部或遠離背部的外側，會使身體重心向後傾倒，導致登山者容易向後摔倒墜崖或嚴重腰痠背痛！

## 🧠 迷思大破解

❌ **迷思 1**：野外口渴時，隨便捧起清澈見底的溪水直接喝，是最天然甘甜的礦泉水。
✅ **正確觀念**：極度危險！清澈的溪水上游可能漂浮著野生動物的排泄物或腐爛動物屍體，水中含有肉眼看不見的致命寄生蟲（如賈第蟲、隱孢子蟲）與大腸桿菌。野外水源必須經過「濾水器過濾」並「煮沸 1~3 分鐘」才能飲用！

❌ **迷思 2**：在野外遇到台灣黑熊，要立刻躺在地上裝死或爬到樹上躲避。
✅ **正確觀念**：千萬不要！黑熊是雜食性動物，非常擅長爬樹，也會吃腐肉，裝死等於把自己變成免費大餐！正確做法是：**保持冷靜、不要尖叫或轉身狂奔（會激發黑熊追捕獵物的本能），面對黑熊緩慢向後倒退離開**。

❌ **迷思 3**：只要手機裝了 Google Maps，登山就絕對不會迷路。
✅ **正確觀念**：Google Maps 在深山中沒有離線航跡，且深山經常沒有手機訊號！登山必須使用支援 GPS 衛星定位的「專業離線地圖 App（如山林日誌、綠野遊蹤、Gaia GPS）」，預先下載好等高線航跡圖！

❌ **迷思 4**：露營時燃燒營火很浪漫，把塑膠袋和寶特瓶丟進火堆燒掉算環保。
✅ **正確觀念**：燃燒塑膠會釋放劇毒「戴奧辛 (Dioxin)」污染山林空氣，未燃燒完全的塑膠殘渣更會滲入泥土百年不化，引發森林大火更會面臨牢獄之災！

## 🧩 段考回推補強：考卷會考、容易漏掉的觀念

### 無痕山林七原則重點

事前充分規劃、走在步道上、帶走垃圾、不帶走自然物、減少用火、尊重野生動物、考慮其他人。

香蕉皮、橘子皮也要帶下山，高山環境分解很慢，也可能影響生態。

### 等高線和方位判讀

等高線越密，坡越陡；越疏，坡越緩。線條向高處彎的是山谷，向低處彎的是山脊。迷路時不要往溪谷走，因為可能遇到瀑布或斷崖。

指北針 N 指向北；白天可用太陽方向輔助，但要小心季節和時間差異。

### 山域緊急應變

迷路用 **STOP**：Stop 停下、Think 思考、Observe 觀察、Plan 計畫。

求救哨音：吹三聲、停一下，再重複。手機沒訊號時可試撥 112，並節省電力。失溫症狀是發抖、口齒不清；要換乾衣、保暖。天氣變壞要趁早下撤。

## 🧭 題型教學：本單元會遇到的題型

每一種題型都有自己的作答方法。先看方法，再到下面的練習題實際演練。

### 選擇題

1. 先讀題幹，圈出「不」「錯誤」「最適合」等關鍵字。
2. 每個選項都看完，刪掉明顯錯的。
3. 剩下兩個時，回到題幹條件逐一比對。

⚠️ **常見失分**：看到第一個「好像對」的選項就選，常會漏看更完整的答案。

✏️ **馬上練習**：下方第 7 題。

### 填充題

1. 先確定空格要填的是數字、名詞還是單位。
2. 把答案放回句子讀一次，看通不通順。
3. 注意題目要求的格式，例如最簡分數、注音或國字。

⚠️ **常見失分**：只寫數字忘了單位，或沒有化成題目要求的形式。

✏️ **馬上練習**：下方第 17 題。

### 應用題

1. 讀兩次：第一次了解情境，第二次圈出數字、單位和問句。
2. 判斷用哪個概念或公式，先列式再計算。
3. 用完整的句子作答，問幾個就答幾個。

⚠️ **常見失分**：題目問兩件事只答一件，或答案單位和題目不同。

✏️ **馬上練習**：下方第 18 題。

### 排序題

1. 先找第一個（開頭、最早、最小），再找最後一個。
2. 中間的用前後關係判斷。
3. 排好後從頭讀或從頭算一次。

⚠️ **常見失分**：只看一兩個項目就決定，容易整串排錯。

✏️ **馬上練習**：下方第 12 題。
