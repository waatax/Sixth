## 🔑 核心觀念 1：傳統書信的六大黃金結構

![應用文的智慧與生活實踐 (Practical Chinese) - 圖解 1](./images/man_u7_concept1.svg)

一封標準而得體的傳統書信，由上至下依序包含以下六大板塊：

```text
              [ 標準書信結構排版示意圖 ]
┌────────────────────────────────────────────────────────┐
│ 敬愛的王老師： (稱謂頂格書寫)                           │
│     道鑒： (提稱語，空兩格或換行空兩格)                 │
│     時光飛逝，轉眼間小學六年的時光即將劃上句點……         │
│ (正文：每段開頭空兩格，行文中提到受信人尊稱時「挪抬」)   │
│     肅此 敬祝 (啟事句與結尾祝道語)                      │
│ 教安 (受詞換行頂格，以示最高敬意)                      │
│                               學生 林小華 敬上 (署名敬詞)│
│                               113年6月10日 (日期)       │
└────────────────────────────────────────────────────────┘
```

### 1. 稱謂（頂格）：
- 寫信人對收信人的稱呼（如：敬愛的王老師、親愛的爸爸媽媽）。
- **書寫規範**：必須在信紙「最頂格」開始寫，絕對不能空格！

### 2. 提稱語：
- 寫在稱謂下方，用來請對方「看信」的禮貌用詞（如同「請您過目」）。
- **不可混淆的專用提稱語**：
  - 👴 給祖父母、父母（長輩）：$\textcolor{#e91e63}{\textbf{膝下、膝前}}$（象徵幼兒時在父母膝下承歡）。
  - 👨‍🏫 給師長：$\textcolor{#2196f3}{\textbf{函丈、壇席、道鑒}}$（函丈指講席前一丈之地，以示不敢逼近）。
  - 🤝 給平輩（同學、朋友）：$\textcolor{#2e7d32}{\textbf{台鑒、大鑒、左右}}$。
  - 👶 給晚輩（弟妹、學弟妹）：$\textcolor{#9c27b0}{\textbf{如晤、如面、知悉}}$。

### 3. 正文與「挪抬」禮儀：
- 正文每段開頭空兩格。
- **挪抬與平抬**：在正文中如果寫到對方的尊稱（如：您、老師、母親），在該詞前面「空一格」，稱為「$\textcolor{#ff9800}{\textbf{挪抬}}$」；或者直接換行頂格書寫，稱為「平抬」，展現謙恭敬意。

### 4. 結尾祝道語（祝賀詞）：
- 針對不同身分對象的專屬祝福：
  - 👴 父母長輩：$\textcolor{#e91e63}{\textbf{叩請 福安、金安}}$。
  - 👨‍🏫 師長：$\textcolor{#2196f3}{\textbf{敬請 道安、教安}}$。
  - 🤝 平輩：$\textcolor{#2e7d32}{\textbf{順祝 時綏、大安}}$。
  - 💼 商界人士：$\textcolor{#ff9800}{\textbf{祝 籌安、商祺}}$。

### 5. 署名敬詞：
- 寫出自己的名字與身分謙詞：
  - 給父母：兒／女 $\bigcirc\bigcirc$ $\textcolor{#e91e63}{\textbf{叩上 / 敬稟}}$。
  - 給老師：學生 $\bigcirc\bigcirc$ $\textcolor{#2196f3}{\textbf{敬上 / 謹上}}$。
  - 給平輩：友 $\bigcirc\bigcirc$ $\textcolor{#2e7d32}{\textbf{敬啟 / 頓首 / 拜啟}}$。
  - 給晚輩：兄／姊 $\bigcirc\bigcirc$ $\textcolor{#9c27b0}{\textbf{示 / 字}}$。

## 🔑 核心觀念 2：中式直式信封的「郵差視角」大破解

![應用文的智慧與生活實踐 (Practical Chinese) - 圖解 2](./images/man_u7_concept2.svg)

全台國小段考與國中會考中，**失分率最高的題目就是信封格式**！
只要記住一個核心真理：**「信封外面的文字，是寫給辛苦送信的郵差先生看的！」**

```text
                  [ 中式直式信封標準版型 ]
┌───────┬───────────────────────────────────┬───────┐
│       │           (郵遞區號)              │       │
│  寄   │           1 0 0 0 0               │       │
│  件   │                                   │  貼   │
│  人   │   新北市板橋區文化路一段 100 號   │  郵   │
│  地   │                                   │  票   │
│  址   │      王 大 明  老師  道啟         │  處   │
│       │   (姓名)   (稱謂)  (啟封詞)       │       │
│林小華 │                                   │       │
│  謹緘 │   臺北市中正區重慶南路一段 10 號  │       │
│       │           (收件人地址)            │       │
└───────┴───────────────────────────────────┴───────┘
```

### 1. 框內收件人稱謂：
- 中間長方形紅框內填寫收件人。
- **格式**：`[姓名]` + `[稱謂]` + `[啟封詞]`
  - 例如：`王大明 老師 道啟`、`李志明 先生 台啟`。
- ⚠️ **世紀大陷阱**：
  - 稱謂是「**寄信人對收件人的稱呼**」！
  - 絕對不能寫成「王老師大明」（顛倒姓名）！
  - 絕對不能寫「王大明 伯父 收」！因為「收」是命令詞，郵差不是寄信人的僕人。

### 2. 啟封詞（請收件人拆開信件）：
- 👴 給長輩：$\textcolor{#e91e63}{\textbf{安啟、福啟}}$。
- 👨‍🏫 給師長：$\textcolor{#2196f3}{\textbf{道啟}}$。
- 🤝 給平輩：$\textcolor{#2e7d32}{\textbf{台啟、大啟}}$。
- 💼 給軍政界：$\textcolor{#ff9800}{\textbf{勛啟}}$。
- 👶 給晚輩：$\textcolor{#9c27b0}{\textbf{收啟、啟}}$。

### 3. 左下角寄件人署名處（緘封詞）：
- 左下角寫寄信人的姓名與地址。
- **緘（ㄐㄧㄢ，Jian）**：封口的意思。
  - 給長輩/師長：林小華 $\textcolor{#2196f3}{\textbf{謹緘}}$（小心謹慎地封口）。
  - 給平輩：林小華 $\textcolor{#2e7d32}{\textbf{緘}}$。
- ⚠️ **不可犯的大錯**：左下角絕對不能寫「敬緘」！「敬」是尊敬別人，自己封信不能尊敬自己，只能寫「謹緘」！

## 🔑 核心觀念 3：便條與畢業演講致詞攻略

![應用文的智慧與生活實踐 (Practical Chinese) - 圖解 3](./images/man_u7_concept3.svg)

### 1. 便條紙的「五要原則」：
便條是簡便的書信，通常寫在紙條上傳遞即時訊息：
1. **對象稱謂**：開頭寫清楚留給誰（如：媽媽：）。
2. **具體事項**：言簡意賅說明要做什麼事。
3. **去向地點與聯絡方式**：人在哪裡、手機號碼。
4. **預計返家時間**：讓家人安心。
5. **落款時間與日期**：必須詳細寫到「幾點幾分」（如：小華留 6月5日 16:30），不能只寫日期！

### 2. 六年級畢業致詞三幕結構：
- **第一幕（回首感恩）**：描繪一年級入學時的青澀，感恩師長悉心啟蒙與同窗晨昏相伴。
- **第二幕（高光時刻）**：回憶大隊接力奮力衝刺、畢業旅行的歡笑、克服難題的蛻變。
- **第三幕（揚帆啟航）**：引用勉勵金句，帶著母校的祝福，自信邁向七年級國中新篇章！

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【信封格式改錯大健檢】
- 📌 **題目情境**：小強寫了一封信給他的國小班導師「李國華」，信封中央欄位寫著：「**李國華 老師 敬啟**」，左下角寄件人欄位寫著：「**學生 陳小強 敬緘**」。請指出這封信的兩大嚴重禮儀錯誤，並說明正確寫法。
- 💡 **思考關鍵**：信封是給郵差看的，「敬啟」與「敬緘」都是國文應用文的大地雷！
- 📐 **詳盡步驟**：
  1. **錯誤一**：中央啟封詞使用「敬啟」。
     - **原因**：「敬啟」意思是「恭敬地陳述」，如果寫在信封中央，就變成「請郵差恭敬地向李老師說話」或「請老師恭敬地打開信」，大不敬！
     - **正確寫法**：給老師應使用「$\textcolor{#2196f3}{\textbf{道啟}}$」。
  2. **錯誤二**：寄件人使用「敬緘」。
     - **原因**：緘是自己把信封口，「敬」是尊稱對方，自己不能對自己的封口動作表示尊敬。
     - **正確寫法**：應使用「$\textcolor{#2e7d32}{\textbf{謹緘}}$」。

### 📝 範例 2：【實用便條撰寫】
- 📌 **題目情境**：小智放學後要去圖書館借科展參考書，預計傍晚 6 點回家。請為他草擬一張留給媽媽的得體便條。
- 📐 **詳盡步驟**：
  ```text
  親愛的媽媽：
      我放學後和組員小明一起到市立圖書館查閱科展書籍，
      預計傍晚 6:00 前會準時回到家吃晚餐。
      如果有緊急事項，請撥打我的手機：0912-345-678。
                                         兒子 小智 留
                                         113年5月20日 16:30
  ```

## 🧠 迷思大破解

❌ **迷思 1**：寫信給別人，開頭第一行一定要空兩格才禮貌。
✅ **正確觀念**：大錯特錯！書信開頭的「稱謂」必須**「頂格」**書寫，表示對收件人至高無上的尊敬；只有正文的段落開頭才空兩格。

❌ **迷思 2**：既然「敬」是尊敬的意思，信封中間寫「王伯父 敬啟」代表我非常尊敬伯父。
✅ **正確觀念**：這是全台灣每年國中會考必考的超級陷阱！「啟」是「打開、拆開」的意思，「敬啟」就是「恭敬地拆開」，沒有晚輩叫長輩「請你恭敬地打開這封信」的道理。請長輩拆信，必須用「福啟」或「安啟」！

❌ **迷思 3**：現代人都用 LINE 和 IG 傳訊息了，便條紙隨便寫兩句就好，不用留時間。
✅ **正確觀念**：便條若沒留時間，家人看到時根本無法判斷你是 10 分鐘前剛走、還是 3 小時前走的，完全失去傳遞時效資訊的功能，反而引發家庭虛驚！

❌ **迷思 4**：電子郵件 (Email) 可以像聊天室一樣隨便打字，不用管主旨和稱謂。
✅ **正確觀念**：在求學升學（如推甄高中、聯繫指導教授）與未來職場中，未寫清晰主旨、未具備敬語稱謂與簽名檔的信件，往往會被直接判定為「垃圾郵件」或「極不專業」而遭到刪除忽視！

## 🌍 你知道嗎？

**🦢 鴻雁傳書與魚傳尺素的千年浪漫！**
在古代沒有郵差與網路，人們是怎麼稱呼書信的呢？
西漢時期，蘇武出使匈奴被扣押牧羊十九年。漢朝使臣告訴單于，漢天子打獵時射下一隻大雁，大雁腳上繫著蘇武親筆寫的絹書，匈奴單于大驚之下只好放回蘇武，這就是成語$\textcolor{#e91e63}{\textbf{「鴻雁傳書」}}$的由來！
而古人把信寫在長度只有一尺的白色絹帛上，稱為「尺素」；再把信箋裝入雕刻成兩條鯉魚形狀的精緻木盒中密封，這就是「魚傳尺素」。古人對文字與問候的敬重之情，化作了千年流傳的美麗詩篇！

## 🚀 +10% 現代素養前瞻新知

**📧 現代數位公民必修課：專業 Email 社交禮儀 (Email Etiquette)！**
邁入 AI 時代，發送一封得體專業的電子郵件已成為國中專題與國際交流的必備基本功：
1. **主旨欄 (Subject) 是一張名片**：切忌空白或只寫「你好」！優秀範例：`【請益】六年五班林小華關於科展實驗變因之請教`。
2. **CC（副本）vs BCC（密件副本）**：
   - **CC (Carbon Copy)**：所有收件人都看得到其他人的信箱，適用於團隊協作周知。
   - **BCC (Blind Carbon Copy)**：保護隱私！收件人看不到其他人的信箱，發送全班家長通知時務必使用 BCC，防止個資洩漏！
3. **專業簽名檔 (Signature)**：信件結尾附上姓名、學校班級與聯絡方式，展現成熟負責任的數位公民形象！

<details>
<summary>對照白話說明與易錯提醒</summary>

提稱語寫在稱謂後面，表示對收信人的尊敬，要依對象選用：給父母、祖父母用「膝下」；給老師用「函丈」；給同學、朋友用「大鑒」或「足下」。

⚠️ **小心別犯錯**：「膝下」只能用在父母、祖父母，不能用在老師或朋友。

</details>

### 2. 信封的啟封詞

- 🧠 **一句話記住**：長輩：安啟；平輩：大啟、台啟。
- 🌱 **生活例子**：寫給外婆：「陳美華 外婆 安啟」；寫給同學：「林小明 同學 大啟」。

**先想想看**：遮住下面的說明，用自己的話說說「信封的啟封詞」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

信封中間寫收信人姓名，後面接「啟封詞」，是請對方打開信的禮貌用語。寫給長輩用「安啟」，寫給平輩用「大啟」或「台啟」。

⚠️ **小心別犯錯**：不能寫「敬啟」，因為那是要對方「恭敬地打開」，對收信人很不禮貌。

</details>

### 3. 信末的祝候語

- 🧠 **一句話記住**：長輩：福安；老師：教安；同學：學安。
- 🌱 **生活例子**：寫給老師的信結尾：「敬請 教安 學生 小明 敬上」。

**先想想看**：遮住下面的說明，用自己的話說說「信末的祝候語」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

信的結尾要寫祝福的話，叫祝候語，也要依對象選用：給祖父母、父母用「敬請 福安」；給老師用「敬請 教安」；給同學朋友用「祝 學安」或「敬祝 近安」。

⚠️ **小心別犯錯**：署名後的「敬上」用於長輩和老師，給朋友可用「上」或「筆」。

</details>

### 4. 便條的寫法（延伸應用）

- 🧠 **一句話記住**：便條四要素：稱呼、內容、署名、時間。
- 🌱 **生活例子**：「媽媽：我到圖書館寫作業，五點半回家。　小華 留　4 月 10 日下午 3:00」

**先想想看**：遮住下面的說明，用自己的話說說「便條的寫法」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

便條是用來簡單傳話的短信，例如請假、留言、借還東西。一張完整的便條要寫清楚四件事：給誰（稱呼）、什麼事（內容）、誰寫的（署名）、什麼時候寫的（日期和時間）。

⚠️ **小心別犯錯**：只寫「我出去一下」不夠清楚，要寫明去哪裡、什麼時候回來；也別忘了寫時間，對方才知道是什麼時候留的。

</details>
