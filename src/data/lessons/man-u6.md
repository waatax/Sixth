# 📌 單元標題與學習目標
## 單元 6：口語表達與簡報力 (108課綱對應：2-III-1, 2-III-2, 2-III-5)

**學習目標：**
在這堂課中，我們將從「會寫文章」升級到「會說話、會報告」！你將學會上台發表的自信心法、設計吸睛簡報的原則，以及如何進行有效的問答與正向回饋。掌握這些技巧，下次上台報告時，你就是全場最閃亮的焦點！

---

# 🎯 學習導引：為什麼要學這個？
想像一下：你花了三個禮拜做了一份超完美的科展報告，內容超豐富。但上台時，你一直低頭看稿、講話像蚊子叫、簡報上塞滿了密密麻麻的字，台下同學都在打瞌睡……這樣不是很可惜嗎？

在現代社會，不管是學校分組報告、競選班級幹部，還是未來出社會提案，「口語表達與簡報力」都是不可或缺的超能力！好的表達力能把你的努力「放大 10 倍」，讓別人聽得懂、記得住，甚至被你深深感動。

---

# 🔑 核心觀念 1：上台發表三要素
一場成功的演講，不是只要把稿子唸完就好。它由三個重要的部分組成：

1.  **內容 (說什麼)**：演講的架構是否清楚？有沒有吸引人的故事？
2.  **聲音表情 (怎麼說)**：語氣是否有高低起伏？重點處有沒有停頓？音量夠不夠大？
3.  **肢體語言 (視覺呈現)**：有沒有自信的站姿？適當的手勢？最重要的是——**眼神接觸**！
    *   👁️ **燈塔原則眼神接觸**：不要只盯著老師或天花板。想像自己是一座燈塔，眼神要像探照燈一樣，緩慢地掃過全場（左邊看一下、中間看一下、右邊看一下），讓每個觀眾都覺得「你在對他說話」。

📊 **演講評分四大維度表格**

| 評分維度 | 評分標準 (滿分 100 怎麼拿？) | 關鍵技巧提示 |
| :--- | :--- | :--- |
| **🗣️ 聲音表達 (30%)** | 音量清晰宏亮、語速適中、有輕重緩急。 | 重要的地方放慢速度，甚至停頓 2 秒。 |
| **🕺 肢體語言 (30%)** | 站姿挺拔不搖晃、有自然的手勢、落實「燈塔原則」眼神。 | 雙手自然下垂或放在腹部，避免玩手指。 |
| **📝 內容結構 (30%)** | 開場吸引人、主體條理分明、結尾有力。 | 善用故事或提問開場，用數字標示重點(第一...第二...)。 |
| **🤝 互動問答 (10%)** | 能從容應對提問、態度自信有禮貌。 | 仔細聆聽，不會的問題不硬拗。 |

# 🔑 核心觀念 2：簡報設計 Less is More (少即是多) 四大原則
簡報（PPT）是你的輔助工具，**你**才是主角！千萬不要把簡報變成「讀稿機」。

📊 **簡報設計原則對比表**

| 設計原則 | ❌ 不好的簡報 (NG示範) | ✅ 好的簡報 (神級示範) |
| :--- | :--- | :--- |
| **大字少字** | 把整段文章複製貼上，字體只有 12pt。 | **每頁只放核心關鍵字**，字體至少 32pt 以上。 |
| **圖像化** | 全都是文字，枯燥乏味。 | **一圖勝千言**。善用高畫質圖片或圖表輔助說明。 |
| **對比色** | 白底黃字，或是花俏的背景配上螢光字。 | **高對比**。例如：白底黑字、深藍底白字，確保看清楚。 |
| **統一風格** | 每一頁的字體、顏色、動畫都不一樣。 | 全份簡報使用 **1-2 種字體**，主色調一致，動畫簡單俐落。 |

# 🔑 核心觀念 3：演講稿架構與 1 分鐘自我介紹
不知道上台要說什麼？背熟這個黃金架構：

1.  **開場白 (Hook 抓住眼球)**：用一個故事、一個驚人的數據或一個問題開始。
2.  **主體三段式**：大腦最容易記住「3」件事。將重點分成三個部分來說明。
3.  **結語轉行動 (Call to Action)**：總結重點，並呼籲大家採取行動。

🏠 **生活案例**：
1. **1分鐘自我介紹**：開場「大家好，我是王小明，叫我閃電俠！」 主體「第一我愛跑步，第二我愛看書，第三我愛交朋友。」 結尾「希望未來多多指教！」
2. **班會上台報告**：開場「大家覺得班上最近是不是有點髒？」主體提出三個打掃的建議。結語「讓我們一起把教室變乾淨吧！」
3. **畢業感言演講**：開場講一個六年間最難忘的笑話，主體感謝老師、同學、父母三方，結尾祝福大家鵬程萬里。

# 🔑 核心觀念 4：三明治正向回饋法與 Q&A 技巧
當同學報告完，老師請你給意見時，該怎麼說才不傷人又能幫助同學？
🍔 **三明治回饋法**：
1.  **上層麵包 (讚美)**：具體說出他做得好的地方。（例：你的簡報圖片做得很精美！）
2.  **中間肉片 (建議)**：提出可以改進的具體建議。（例：如果講話速度能再慢一點點，大家會聽得更清楚。）
3.  **下層麵包 (鼓勵)**：給予正向的期許。（例：相信你下次報告一定會更棒！）

📊 **Q&A 應對技巧表**

| 狀況 | 應對技巧 | 說話範例 |
| :--- | :--- | :--- |
| **聽不清楚問題** | 請對方重述或自己確認。 | 「請問您的意思是......這樣對嗎？」 |
| **遇到好問題** | 先給予肯定，再回答。 | 「這是一個非常好的問題！我的看法是...」 |
| **真的不會回答** | **誠實為上策，不瞎掰。**承諾會後查證。 | 「這個問題很專業，我目前手邊沒有資料。下課後我查證完再回覆您，謝謝提問！」 |

# 🧠 迷思大破解

*   ❌ **迷思 1：上台報告就是要把簡報上的字一字不漏地唸出來。**
    *   ✅ **正確觀念**：簡報是給觀眾看的「視覺輔助」，你才是演講者！你應該用自己的話，對著觀眾解釋簡報上的重點，而不是轉過去背對觀眾唸 PPT。
*   ❌ **迷思 2：上台很緊張，手心冒汗，代表我表現得很差。**
    *   ✅ **正確觀念**：緊張是完全正常的！連專業的主持人上台前都會緊張。緊張代表你「在乎」這場演講。深呼吸，把緊張的能量轉化為講話的熱情就對了！
*   ❌ **迷思 3：別人問問題，如果我說「我不知道」，會顯得很笨。**
    *   ✅ **正確觀念**：沒有人是全知全能的。遇到不會的問題，誠實說「這部分我還沒有深入研究，謝謝你的提問讓我學到一課」，反而會展現出你的自信和謙虛，贏得更多尊重。
