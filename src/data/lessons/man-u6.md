## 🔑 核心觀念 2：簡報設計 Less is More (少即是多) 四大黃金法則

簡報（Slides/PPT）是你的**視覺助攻工具**，千萬不要把簡報當成演講者的「提詞讀稿機」！

$$\textcolor{#e91e63}{\textbf{神級簡報}} = \textcolor{#2196f3}{\textbf{大字少字 (高提煉)}} + \textcolor{#4caf50}{\textbf{一圖勝千言 (圖像化)}} + \textcolor{#ff9800}{\textbf{高對比配色 (易讀性)}} + \textcolor{#9c27b0}{\textbf{風格統一 (專業感)}}$$

### 📊 簡報設計四大法則對比表

| 設計法則 | 核心規範與技巧 | ❌ NG 示範 | ✅ 神級示範 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{1. 大字少字}}$ | 每頁只放**核心關鍵詞**或一句話。內文字體大小 $\ge 32\text{ pt}$，標題 $\ge 44\text{ pt}$。 | 將整篇作文或課文直接複製貼上，滿滿 12 號字。 | 投影片中央只放一個巨大數字「$\textcolor{#e91e63}{\textbf{45 億}}$」或一句重點標語。 |
| $\textcolor{#4caf50}{\textbf{2. 圖像化}}$ | **一圖勝千言**！善用高畫質照片、精準圖表或概念圖替代純文字。 | 全篇都是條列式黑白文字，毫無視覺焦點。 | 用一張海龜被塑膠吸管卡住的震撼特寫照片，配合數據圖表。 |
| $\textcolor{#ff9800}{\textbf{3. 高對比配色}}$ | 文字與背景顏色必須形成強烈反差（深底亮字 或 亮底深字）。 | 白底搭配淡黃色字體，或花俏雜亂的星空背景配紅字。 | 純白背景搭配深藍色字體，關鍵字用**桃紅色或亮黃色**突顯。 |
| $\textcolor{#9c27b0}{\textbf{4. 風格統一}}$ | 全份簡報使用 **1~2 種字體**，主色調不超過 3 種，排版邏輯一致。 | 每頁投影片換一種字體、背景顏色五顏六色、動畫花俏。 | 全份簡報統一採用俐落黑體，主色調為科技藍＋輔助灰。 |

## 🔑 核心觀念 3：演講稿黃金架構（Hook - Story - Action）

不知道上台該說什麼？背熟這個風靡全球的演說黃金架構：

```text
                  ┌──────────────────────────────┐
                  │   【1. 開場 Hook (抓住眼球)】  │ ── 拋出提問 / 震撼數據 / 懸念故事
                  └──────────────┬───────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 │   【2. 主體 3 點式 (Rule of 3)】│ ── 大腦最愛「3」件事，條理分明
                 └───────────────┬───────────────┘
                                 │
                  ┌──────────────┴───────────────┐
                  │   【3. 結語 Call to Action】   │ ── 總結核心 / 呼籲全體採取行動
                  └──────────────────────────────┘
```

### 🌟 實戰示範：1 分鐘自我介紹黃金範本
- **【Hook 開場】**：「大家早安！如果用一種動物來形容我，你們猜會是什麼呢？沒錯，就是一隻停不下來的『金頂電池兔』！」
- **【主體 3 點】**：「第一，我熱愛運動，是田徑隊的百米跑者；第二，我熱愛科學，做過十幾次有趣的科學實驗；第三，我熱愛交朋友，有問題找我準沒錯！」
- **【Action 結語】**：「期待在未來的日子裡，能和大家一起跑得更快、學得更多，謝謝大家！」

## 🔑 核心觀念 4：正向溝通藝術——三明治回饋法與 Q&A 應答

### 🍔 三明治回饋法（Sandwich Feedback Method）
當同學報告完畢，老師請你提供評語時，如何給出建設性又不傷人的高品質回饋？

```text
        ┌────────────────────────────────────────────────────────┐
        │   🍞 【上層麵包：真誠讚美】 具體指出對方的優點與亮點     │
        │   「你的簡報排版非常乾淨，開場的故事也非常生動！」       │
        ├────────────────────────────────────────────────────────┤
        │   🥩 【中間肉片：具體建議】 提出一個可以更好的改善方向 │
        │   「如果報告後半段音量能再大一點，全班會聽得更清楚！」 │
        ├────────────────────────────────────────────────────────┤
        │   🍞 【下層麵包：鼓勵期許】 給予信心支持與美好期待     │
        │   「你的台風很穩健，非常期待你下一次的精彩分享！」       │
        └────────────────────────────────────────────────────────┘
```

### 📊 高情商 Q&A 應對 SOP 表

| 面臨情境 | 正確心態與策略 | 高情商發言範例示範 |
| :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{沒聽清楚問題}}$ | 不要裝懂亂答，主動禮貌請求重述。 | 「抱歉，剛才後方有些雜音，請問您的問題是指⋯⋯這樣對嗎？」 |
| $\textcolor{#4caf50}{\textbf{遇到優質好問題}}$ | 先肯定對方的提問水準，再從容回答。 | 「這是一個非常深刻且關鍵的好問題！針對這點，我的看法是⋯⋯」 |
| $\textcolor{#e91e63}{\textbf{遇到不會回答的難題}}$ | **誠實為上策，絕不胡編瞎掰**，承諾會後查證。 | 「這個問題非常專業，我目前手邊沒有這份數據。我會在會後查詢完整資料後向您回覆，謝謝您的提問！」 |

## 🧠 迷思大破解

*   ❌ **迷思 1：上台演講一定要把稿子一字不漏全部背下來？**
    *   ✅ **正確觀念**：死記硬背最容易忘詞！一旦卡住一個字，整個人就會慌掉。高明的演說家只記「**核心架構（大綱與關鍵字）**」，上台時根據關鍵字自然地用自己的話說出來，才能展現最真實的魅力。
*   ❌ **迷思 2：上台感到緊張、心跳加快，代表我缺乏演講天賦？**
    *   ✅ **正確觀念**：全世界頂尖的演說家上台前都會心跳加速！緊張是身體分泌腎上腺素的自然現象，代表你「在乎這場發表」。透過深呼吸 3 次，將緊張的能量轉化為發表的熱情與專注力即可！
*   ❌ **迷思 3：觀眾問問題時，如果承認自己不知道，會很丟臉？**
    *   ✅ **正確觀念**：恰恰相反！不懂裝懂、胡言亂語才會徹底失去信譽。坦誠說出「這部分我目前還沒有深入研究，謝謝你的提問讓我開拓了新視野」，反而會贏得觀眾對你誠實與謙遜的由衷敬佩。
