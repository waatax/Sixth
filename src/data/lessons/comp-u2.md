**學習目標**：

## 🎯 學習導引：為什麼要學這個？

在學校裡，你是不是曾經遇過這些情況：好朋友不小心弄壞了你心愛的筆，你氣得大罵他，結果兩人冷戰了好幾天；或者是在分組討論時，你的意見一直被忽略，覺得委屈卻不知道怎麼開口？人與人相處就像跳雙人舞，有時候不小心踩到對方的腳是正常的。如果我們不懂得溝通，就會變成互相推擠；但如果我們學會了「情緒解碼」與「溝通技巧」，就能把誤會解開，讓這支友誼之舞跳得更順暢、更開心。今天，就讓我們來升級你的「溝通超能力」！

## 🔑 核心觀念 1：情緒紅綠燈 —— 做情緒的主人

當我們遇到衝突或不開心的事情時，大腦很容易瞬間「當機」，做出衝動的行為。這時候，我們需要在心裡裝一個**情緒紅綠燈**！

🔴 **紅燈：停！(Stop)**
覺察到自己正在生氣、難過或激動。深呼吸，告訴自己：「我現在很生氣，先不要說話或動作。」避免做出會後悔的事。
🟡 **黃燈：想！(Think)**
想一想：我為什麼會有這個情緒？事情的真相是什麼？如果我打人或罵人，會有什麼後果？有沒有更好的解決方法？
🟢 **綠燈：行！(Go)**
冷靜下來後，選擇一個對雙方都好、不傷害人的方式去表達或行動。

🏠 **生活案例一：被嘲笑的時候**
下課時，同學嘲笑小胖的髮型。
- **(紅燈)** 小胖覺得很生氣，拳頭握緊了，但他深呼吸三下，先忍住不打人。
- **(黃燈)** 小胖想：「如果我打他，會被老師處罰，事情更糟。我是因為覺得不被尊重而生氣。」
- **(綠燈)** 小胖走過去平靜地說：「你拿我的外表開玩笑，讓我覺得很不舒服，請你以後不要這樣。」

## 🔑 核心觀念 2：「你訊息」vs「我訊息」

我們常常在生氣時指責別人，這叫做「**你訊息**」(You-Message)，會讓對方覺得被攻擊而想要反擊。
真正聰明的溝通是使用「**我訊息**」(I-Message)，把焦點放在「**我的感受與需求**」上，這樣對方比較聽得進去！

🌟 **I-Message 四步驟公式**：
1. **我覺得...** (真實的情緒)
2. **當你...** (具體客觀的行為，不加批評)
3. **因為...** (這個行為對我的影響)
4. **我希望...** (具體的請求)

🏠 **生活案例二：朋友借東西弄壞**
- ❌ 你訊息：「**你**怎麼這麼自私！每次借東西都弄壞，我以後再也不借**你**了！」(對方會想防衛反駁)
- ✅ 我訊息：「**(當你)** 把我的限量版橡皮擦弄斷時，**(我覺得)** 很難過也很生氣，**(因為)** 那是我存錢買了很久的寶貝。**(我希望)** 你下次借東西可以更小心，並且買一個還給我。」

📊 **你訊息 vs 我訊息 完整對比表格 (5個校園情境改寫)**

| 校園情境 | ❌ 踩雷的「你訊息」(指責) | ✅ 高EQ的「我訊息」(表達感受) |
| :--- | :--- | :--- |
| **1. 同學未經同意拿走文具** | 「你這小偷！隨便拿別人的東西！」 | 「當你沒問過就拿走我的筆，我覺得不被尊重，因為我找不到筆會很著急。希望你下次先問我。」 |
| **2. 約好打球對方卻遲到半小時** | 「你每次都遲到，真的很沒有信用！」 | 「當你遲到半小時，我覺得很焦慮，因為我浪費了很多時間空等。希望你下次能準時。」 |
| **3. 分組討論時一直被打斷** | 「你閉嘴啦！都不聽別人講話！」 | 「當我講話被打斷時，我覺得很挫折，因為我的意見沒有被聽見。我希望你能讓我把話說完。」 |
| **4. 朋友在別人面前說你壞話** | 「你真的是個雙面人，太過分了！」 | 「聽到你在別人面前批評我，我很受傷，因為我把你當好朋友。我希望我們能直接溝通。」 |
| **5. 借給同學的書被塗鴉** | 「你眼睛有問題嗎？為什麼亂畫！」 | 「看到書上被塗鴉我很心痛，因為我很愛惜這本書。希望你能幫我把書弄乾淨。」 |

## 🔑 核心觀念 3：衝突處理的同理心五階段

發生衝突時，如何用「同理心」化解？可以跟著這五個階段走：

📊 **衝突處理五階段流程表**

| 階段 | 行動關鍵 | 具體做法 |
| :---: | :--- | :--- |
| **1. 停** | 暫停衝動 | 雙方先拉開距離，冷靜情緒(紅綠燈的紅燈)。 |
| **2. 聽** | 積極傾聽 | 輪流說話，專心聽對方的想法，不插嘴。 |
| **3. 想** | 換位思考 | 站在對方的角度想：「如果我是他，我會怎麼想？」(同理心) |
| **4. 說** | 溫和表達 | 使用「我訊息」說出自己的感受和需要。 |
| **5. 做** | 尋求雙贏 | 一起討論出一個兩個人都可以接受的解決方案。 |

## 🔑 核心觀念 4：積極傾聽技巧

溝通不只是「說」，更重要的是「聽」。**積極傾聽 (Active Listening)** 能讓對方覺得你真的在乎他。

📊 **積極傾聽技巧表**

| 技巧名稱 | 具體表現方式 | 效果 |
| :--- | :--- | :--- |
| **眼神接觸** | 看著對方的眼睛或鼻樑，不要滑手機或東張西望。 | 傳遞「我很重視你」的訊號。 |
| **肢體回應** | 適時點頭、身體微微向前傾。 | 讓對方知道你有在專心。 |
| **口語回應** | 發出「嗯嗯」、「原來如此」、「然後呢？」等聲音。 | 鼓勵對方繼續說下去。 |
| **重述與摘要** | 「所以你的意思是說...」、「聽起來你覺得很...」 | 確認自己沒有誤解對方的意思。 |

🏠 **生活案例三：分組被忽略的傾聽**
小安向小美抱怨分組時都沒人聽他講話。小美眼睛看著小安(眼神)，點點頭(肢體)，然後說：「所以你覺得很孤單，因為你的想法沒被採納對嗎？」(重述)。小安聽了覺得被理解，心情就好了大半。

## 🧠 迷思大破解

1. ❌ **迷思一：高EQ就是永遠不生氣、不發脾氣？**
   ✅ **正確觀念**：錯！每個人都會生氣，高EQ不是壓抑情緒，而是「用正確、不傷害人與自己的方式表達生氣」。生氣是正常的，重點是生氣之後你「做」了什麼。
2. ❌ **迷思二：只要我用了「我訊息」，對方就一定會聽我的？**
   ✅ **正確觀念**：錯！「我訊息」只是幫助你清楚表達自己，降低對方的防衛心。對方可能還是會有自己的想法，這時就需要用到「積極傾聽」和「衝突處理五階段」來溝通。
3. ❌ **迷思三：傾聽就是安靜地聽對方說話就好？**
   ✅ **正確觀念**：錯！如果你只是像木頭一樣安靜，對方會以為你在發呆。「積極」傾聽需要有眼神、點頭，以及重述對方的話，讓對方真實感受到「你懂我」。

## ✏️ 隨堂自我小練習

1. 🔢 **改寫練習**：你的弟弟未經同意就把你的布丁吃掉了。請用「我訊息四步驟（覺得+當你+因為+希望）」造一個句子來表達你的感受，而不是罵他「你是豬喔！」。
2. 🔢 **情境題**：小強在走廊上被同學撞倒，膝蓋破皮了。小強的「情緒紅綠燈」亮起了紅燈。請你給他一個黃燈（想）和綠燈（行）的具體建議。
3. 🔢 **技巧辨識**：當同學在跟你訴苦時，你對他說：「聽起來你因為落選而覺得很挫折對嗎？」這是使用了哪一種「積極傾聽技巧」？
4. 🔢 **排序題**：請將衝突處理五階段按照正確順序排列：(A)說出我訊息、(B)冷靜暫停、(C)尋求解決方案、(D)專心聽對方說、(E)換位思考同理對方。

## 🌍 你知道嗎？

💡 **大腦裡的「情緒警報器」：杏仁核 (Amygdala)**
你知道我們為什麼生氣時會失去理智嗎？因為我們大腦裡有一個叫「杏仁核」的部位，它就像警報器，一遇到威脅（例如被罵、被撞），它就會發出警報，瞬間切斷大腦掌管理智的「前額葉」的連線，這叫做「杏仁核劫持」。我們深呼吸、數十秒，就是在幫前額葉爭取時間，讓理智重新上線！

## 🚀 +10% 現代素養前瞻新知

**數位時代的「文字語氣」與貼圖溝通**
在現代，我們常透過 LINE 或 IG 聊天。沒有了「語氣」和「表情」，文字很容易被誤會！例如對方只回「喔」，你可能會覺得他生氣了，但其實他可能只是在忙。因此，數位溝通的素養告訴我們：善用「表情符號(Emoji)」😊和「貼圖」來輔助文字，傳達善意；如果發生嚴重衝突，**不要用打字的**，直接打電話或面對面溝通，才能真正聽見彼此的語氣，化解心結！
