# 📌 單元標題與學習目標：體適能與運動家精神——身心強健的恆毅力

**課綱指標**：$\textcolor{#f59e0b}{\textbf{體 1c-III-1}}$ 掌握健康體適能四大要素（心肺耐力、肌力肌耐力、柔軟度、身體組成），擬定個人運動處方並落實運動家精神。

**108 課綱核心素養與學習指標**：
- **健體-E-A1**：具備良好身體活動習慣，落實規律運動計畫以促進全人身心健全發展。
- **健體-E-C1**：具備運動道德思辨力，於競技中展現性別平權、尊重對手與遵守規則。
- **健體-E-C2**：在體育活動與團體競賽中，展現互助合作、勝不驕敗不餒之運動家品格。

**🎯 本單元學習目標**：
1. 深入掌握「$\textcolor{#e91e63}{\textbf{健康體適能四大要素}}$」的定義、教育部標準檢測項目與科學鍛鍊處方。
2. 熟練掌握規律運動「$\textcolor{#2196f3}{\textbf{333 原則}}$」與運動三階段（暖身 $\rightarrow$ 主運動 $\rightarrow$ 收操）。
3. 體認並在競賽中實踐「$\textcolor{#ff9800}{\textbf{運動家精神 (Sportsmanship)}}$」之四大核心基石。
4. 探索運動對大腦神經科學的神奇賦能（$\textcolor{#4caf50}{\textbf{多巴胺}}$、$\textcolor{#9c27b0}{\textbf{BDNF 腦神經肥料}}$）。

## 🔑 核心觀念 1：健康體適能四大核心要素 (Physical Fitness)

 │ - 鍛鍊：慢跑、游泳、跳繩│ - 檢測：【一分鐘屈膝仰臥起坐】    │

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【健康體適能四大要素與鍛鍊】
- 📌 **題目情境**：想要提升體適能檢測成績，請針對「心肺耐力」與「柔軟度」各規劃一項有效的訓練項目。
- 📐 **詳盡步驟**：
  1. **心肺耐力**：每週進行 3 次、每次至少 30 分鐘的中高強度有氧運動（如慢跑、游泳、跳繩），使心跳達到每分鐘 130 下以上。
  2. **柔軟度**：運動後進行各大肌群靜態伸展拉筋，每個伸展動作維持 15~30 秒，每日持續練習坐姿體前彎。

### 📝 範例 2：【運動家精神實踐】
- 📌 **題目情境**：在拔河決賽中，對手隊伍因為地面濕滑不慎失誤跌倒，此時身為隊長應展現何種運動家品格？
- 📐 **詳盡步驟**：全力以赴尊重比賽，賽後主動上前握手慰問對手，秉持「勝不驕、敗不餒」的胸襟，贏得全場尊敬。

## 🧠 迷思大破解

❌ **迷思 1**：只要狂做仰臥起坐，肚子上的脂肪就會全部燃燒消失？  
✅ **正確觀念**：運動生理學上「**無法局部減脂**」！仰臥起坐鍛鍊的是內部的腹直肌群；要消除覆蓋在上面的脂肪，必須透過全身性有氧運動（如慢跑、游泳）結合熱量赤字飲食！

❌ **迷思 2**：天氣很熱不用暖身，直接上場打球最省時間？  
✅ **正確觀念**：未熱身的肌肉與韌帶如同剛從冰箱拿出的橡皮筋，極易斷裂！暖身能提高深層體溫、潤滑關節液並預先啟動心肺，是預防運動傷害的第一道防線。

❌ **迷思 3**：裁判誤判時，身為球員應立刻上前大吼抗議？  
✅ **正確觀念**：這嚴重違反運動道德。競賽場上應由隊長或教練依規章循正常管道向裁判提出申訴。尊重裁判的判決是運動員的基本素養。

- 🌱 **生活例子**：800 公尺跑走測心肺耐力；仰臥起坐測肌耐力；坐姿體前彎測柔軟度。

### 2. 循序漸進才會進步

- 🧠 **一句話記住**：逐步增加 ＋ 充分休息 ＋ 均衡營養。
- 🌱 **生活例子**：這週每天跳繩 100 下，下週增加到 120 下。

**先想想看**：遮住下面的說明，用自己的話說說「循序漸進才會進步」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

運動時給身體一點點挑戰，休息和吃得營養之後，身體會變得更強壯。下一次再稍微增加次數或難度，慢慢進步，這叫漸進原則。

💡 **解題心法與重要規則**：逐步增加 ＋ 充分休息 ＋ 均衡營養。

⚠️ **小心別犯錯**：一下子做太多太難，容易受傷。

</details>

### 3. 規律運動與熱量平衡

- 🧠 **一句話記住**：每天動 60 分鐘；吃進的 ＝ 用掉的，體重穩定。
- 🌱 **生活例子**：下課跳繩、放學騎腳踏車、週末打球，都能累積運動時間。

**先想想看**：遮住下面的說明，用自己的話說說「規律運動與熱量平衡」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

每天至少運動 60 分鐘，包括會流汗、有點喘的有氧運動。吃進去的熱量和運動消耗的熱量要平衡，才能維持健康的體重。

💡 **解題心法與重要規則**：每天動 60 分鐘；吃進的 ＝ 用掉的，體重穩定。

⚠️ **小心別犯錯**：運動後喝一大杯含糖飲料，很容易把消耗的熱量又補回去。

</details>

### 4. 運動前暖身，運動後緩和（延伸應用）

- 🧠 **一句話記住**：運動前：暖身（動態）；運動後：緩和（靜態伸展，每個動作停留 15～30 秒）。
- 🌱 **生活例子**：跑步比賽前先慢跑兩圈、做弓箭步和手臂繞圈；跑完不要馬上坐下，先走一走，再伸展大腿和小腿。
- 🎯 **段考命題常考方式**：【什麼時候用】每次運動都記得「暖身 → 運動 → 緩和」三段。

**先想想看**：遮住下面的說明，用自己的話說說「運動前暖身，運動後緩和」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

運動前先暖身 5～10 分鐘（例如慢跑、動態伸展），讓身體溫度上升，肌肉和關節變靈活，可以減少受傷。運動後做緩和運動（例如慢走、靜態伸展），讓心跳慢慢恢復，也能減少肌肉痠痛。

💡 **解題心法與重要規則**：運動前：暖身（動態）；運動後：緩和（靜態伸展，每個動作停留 15～30 秒）。

⚠️ **小心別犯錯**：激烈運動後馬上坐下或躺下，可能會頭暈；要先慢慢走動。

</details>

### 體適能檢測項目對應

| 要素 | 檢測項目 |
| :--- | :--- |
| 心肺耐力 | 800 公尺跑走 |

| 柔軟度 | 坐姿體前彎 |
| 瞬發力 | 立定跳遠 |
| 身體組成 | BMI |

$BMI=\frac{體重（公斤）}{身高（公尺）\times身高（公尺）}$。各年齡標準不同，要對照常模。

### 運動處方怎麼排

運動三部曲：熱身 → 主要運動 → 緩和。熱身讓體溫升高，緩和幫助恢復。

333 原則：每週 3 次、每次至少 30 分鐘、心跳達到每分鐘約 130 下。進步要循序漸進，不可突然加太多運動量。抽筋時先停止，慢慢伸展。

### 運動家精神情境

遵守規則、尊重裁判和對手、勝不驕敗不餒、幫助受傷的對手。比賽輸了可以分析原因，而不是責怪隊友。

情境題判斷原則：做了之後是否尊重別人，同時也維護比賽公平？
