## 🔑 核心觀念 1：史丹佛設計思考五大步驟 (EDIPT)

設計思考（Design Thinking）是由美國史丹佛大學 d.school 與國際設計名廠 IDEO 發揚光大的創新方法論。它不是直線單向的，而是**「發散（探索各種可能）」與「收斂（聚焦最佳解法）」不斷循環迭代的雙鑽石模型**！

```text
               【史丹佛設計思考 EDIPT 與雙鑽石模型】
   ┌───────────【探索鑽石】───────────┐ ┌───────────【執行鑽石】───────────┐
   │    發散 (探索)     收斂 (聚焦)    │ │    發散 (點子)     收斂 (落實)    │
   │        ▲                ▼         │ │        ▲                ▼         │
   ▼       / ＼             / ＼       ▼ ▼       / ＼             / ＼       ▼
  🌱 ➔ ［E 同理］ ────► ［D 定義］ ────► ［I 發想］ ────► ［P 原型］ ────► ［T 測試］ ➔ 🚀
 (問題) (Empathize)    (Define)        (Ideate)      (Prototype)     (Test)   (方案)
           ▲                                                              │
           └────────────────── 反覆測試回饋、滾動修正 ───────────────────────┘
```

📊 **設計思考 EDIPT 五步驟完整實戰指南表**

| 步驟 (英文簡稱) | 階段任務與思維 | 核心提問句 | 實用工具與方法 | 實例：改造難倒長輩的藥袋包裝 |
| :--- | :--- | :--- | :--- | :--- |
| $\textcolor{#e91e63}{\textbf{E 同理 (Empathize)}}$ | 走入使用者生活，觀察行為與情緒痛點 | 使用者是誰？他們在哪個環節感到挫折？ | 現場觀察法、深度訪談、同理心地圖 (Empathy Map) | 發現阿嬤老花眼看不清藥袋上的小字，常吃錯藥 |
| $\textcolor{#2196f3}{\textbf{D 定義 (Define)}}$ | 收斂資訊，找出真正的「核心真問題」 | 真正的癥結點是什麼？（非表面症狀） | **HMW 句型**（How Might We... 我們如何能夠...） | 「我們如何讓視力退化的長輩一眼認出早中晚的藥？」 |
| $\textcolor{#ff9800}{\textbf{I 發想 (Ideate)}}$ | 發散思維，狂風暴雨般提出大量創新點子 | 有哪些瘋狂、有趣的解法？（不批判） | 腦力激盪 (Brainstorming)、便利貼心智圖、奔馳法 (SCAMPER) | 點子：放大字體、顏色區隔、點陣圖、鬧鐘藥盒、APP 語音播報 |
| $\textcolor{#4caf50}{\textbf{P 原型 (Prototype)}}$ | 快速動手做出「低成本、看得見的模型」 | 怎麼用 5 分鐘讓別人看懂我的點子？ | **Quick & Dirty**：瓦楞紙板、黏土、樂高積木、草圖分鏡 | 用厚紙板做成紅（早）、黃（中）、藍（晚）三色卡夾式藥盒 |
| $\textcolor{#9c27b0}{\textbf{T 測試 (Test)}}$ | 邀請真實使用者試用，收集真實回饋 | 使用者用得順手嗎？哪裡需要修改？ | 實境觀察試用、回饋矩陣 (Feedback Grid) | 請阿嬤盲測，阿嬤說顏色很好，但卡榫太緊，於是回頭修改卡榫 |

## 🔑 核心觀念 2：通用設計 (Universal Design, UD) 7 大原則

由美國建築大師羅納德·麥斯 (Ronald Mace) 提出，核心哲學為：**「無需特別改良或專業輔具，讓世界上所有人（小孩、長輩、身障者、孕婦、推嬰兒車者、左撇子）都能尊嚴且公平使用」**！

```text
                  【通用設計 7 大黃金原則】
                         通用設計 (UD)
           ┌──────────────────┼──────────────────┐
           ▼                  ▼                  ▼
     【1. 公平使用】     【2. 彈性使用】     【3. 簡易直覺】
    所有人無差別對待     左右撇子皆能使用     不需說明書秒懂
           │                  │                  │
     【4. 資訊明顯】     【5. 容許錯誤】     【6. 省力操作】
    視覺+聽覺雙重提示    防呆機制防意外      省力槓桿自動感應
                              │
                       【7. 尺寸空間適用】
                       輪椅通道與合宜高度
```

📊 **通用設計 7 大原則深度解析與生活實例表**

| 原則名稱 | 核心精神 | 日常生活中的好設計實例 |
| :--- | :--- | :--- |
| $\textcolor{#e91e63}{\textbf{1. 公平使用 (Equitable Use)}}$ | 對所有使用者一視同仁，不製造隔離或歧視 | 建築物主入口的緩坡道（推嬰兒車、坐輪椅、拖行李箱、走路皆共用同一尊嚴通道） |
| $\textcolor{#2196f3}{\textbf{2. 彈性使用 (Flexibility in Use)}}$ | 配合個人的喜好與使用能力 | 左右手對稱設計的剪刀、可微調高度的辦公椅與書桌 |
| $\textcolor{#ff9800}{\textbf{3. 簡易直覺 (Simple & Intuitive)}}$ | 不受語言、學歷或文化限制，一目了然 | 洗手液一按即出、紅綠燈走動與靜止的人形符號 |
| $\textcolor{#4caf50}{\textbf{4. 資訊明顯 (Perceptible Information)}}$ | 結合多種感官（視覺、聽覺、觸覺）傳達訊息 | 捷運到站前「閃爍燈號（視覺）＋語音廣播（聽覺）」、電梯按鈕上的點字（觸覺） |
| $\textcolor{#9c27b0}{\textbf{5. 容許錯誤 (Tolerance for Error)}}$ | 將意外或無意操作所造成的危險降至最低（防呆） | 電腦刪除檔案前彈出「確認刪除？」視窗、微波爐開門自動斷電 |
| $\textcolor{#00bcd4}{\textbf{6. 省力操作 (Low Physical Effort)}}$ | 能以最自然舒適的姿勢、最少的力氣輕鬆操作 | 紅外線自動感應水龍頭、門把採用「下壓式把手」取代傳統圓形旋轉喇叭鎖 |
| $\textcolor{#795548}{\textbf{7. 尺寸空間適用 (Size & Space)}}$ | 提供適當的空間供任何體型、姿勢或活動能力者接近 | 捷運站加寬的輪椅無障礙閘門、不同高度的洗手台與飲水機 |

## 🔑 核心觀念 3：視覺公共指標 (Pictogram) 與「形式跟隨功能」

### 1. 諾曼門 (Norman Door) 與「形式跟隨功能」
建築大師路易斯·蘇利文 (Louis Sullivan) 提出名言：$\textcolor{#e91e63}{\textbf{「形式永遠跟隨功能」(Form follows function)}}$。
- ❌ **諾曼門（爛設計）**：明明是「推」的門，卻安裝了讓人想去抓取的把手；明明是「拉」的門，卻做成平板。
- ✅ **優良設計**：需要「推」的門就裝上一塊金屬平板（只能推，無法拉）；需要「拉」的門才安裝把手！外觀造型本身就是使用說明的暗示！

```text
    【推拉門的直覺設計：形式跟隨功能】
         【推門 (Push)】               【拉門 (Pull)】
       ┌─────────────────┐           ┌─────────────────┐
       │                 │           │                 │
       │   ┌─────────┐   │           │       ┌┐        │
       │   │  [平板] │   │           │       ││ [把手] │
       │   └─────────┘   │           │       └┘        │
       │  (只能推，不用想)│           │  (自然伸手去拉) │
       └─────────────────┘           └─────────────────┘
```

### 2. 跨越語言的全球符號：$\textcolor{#2196f3}{\textbf{Pictogram (象形圖像符號)}}$
- 1964 年東京奧運因應各國選手湧入，首度大規模設計各項運動與設施的 Pictogram。
- 特色：造型極簡、黑白高對比、去除文化文字障礙，全球一眼辨識！

## 🔑 核心觀念 4：綠色永續設計與搖籃到搖籃 (C2C)

在氣候變遷的時代，設計師必須為地球負責！
- **線性經濟（搖籃到墳墓）**：開採資源 $\rightarrow$ 製造商品 $\rightarrow$ 丟棄變成垃圾。
- 🌟 **循環經濟（搖籃到搖籃 Cradle to Cradle, C2C）**：從一開始設計時，就確保所有零件能拆解、 $100\%$ 生物降解或無限循環再製造！

```text
               【從線性經濟邁向 C2C 循環經濟】
  【傳統線性：搖籃到墳墓】
   天然資源 ───► 工廠製造 ───► 消費使用 ───► 焚化爐/垃圾掩埋場 💥 (污染)

  【綠色永續：搖籃到搖籃 (C2C)】
   ┌──────────────────────────────────────────────┐
   ▼                                              │
  設計研發 ───► 無毒製造 ───► 共享與使用 ───► 拆解與 100% 循環再生 🔄
```

## 🧠 迷思大破解

❌ **迷思 1：設計師就是要把畫圖畫得很漂亮、很有藝術家氣質？**
✅ **正確觀念**：設計（Design）與純藝術（Fine Art）不同！純藝術在於表達自我情感；設計的核心在於**「解決別人的問題」**。一個不會畫畫但極具同理心、能想出絕妙動線的人，就是頂級的體驗設計師！

❌ **迷思 2：做原型 (Prototype) 必須花幾個月把它做得很精美、功能齊全？**
✅ **正確觀念**：大錯特錯！原型講求 **「快速失敗、便宜驗證 (Fail fast, fail cheap)」**。用厚紙板與膠帶花 10 分鐘做出的粗糙原型，只要能讓使用者測試關鍵概念，價值遠勝於花一個月做出的精美錯誤成品！

❌ **迷思 3：通用設計只是為了「照顧殘障人士」而做的特殊福利？**
✅ **正確觀念**：通用設計是為了「所有人」！當你雙手抱滿沉重包裹時，用手肘輕碰開門按鈕，或是走在平整的斜坡上，你就在享受通用設計的便利。每個人都會經歷童年、受傷生病或變老的時刻，通用設計讓每個生命階段都能活得尊嚴舒適！

   (A) 需要往外拉的門安裝直立握把  
   (B) 只能往前推的門安裝平整金屬按壓板  
   (C) 只能往前推的門卻安裝了巨大的圓形金屬拉環把手  
   (D) 盛裝熱湯的碗在碗底加厚並設有防燙底圈  

### 二、情境改造實作題
4. **【校園痛點診斷與改造】**：
   **情境**：學校資源回收區常常垃圾大分類混亂，廚餘桶旁滴得到處都是油水，紙類回收箱裡常被丟入喝剩的奶茶紙杯。
   請你運用「設計思考五步驟 (EDIPT)」，寫下一套具體的校園回收區改造行動方案。

---

### 💡 【詳細解析與解答】

1. **答案：(B)**  
   **解析**：同時使用「聲音（聽覺）」與「閃燈（視覺）」傳遞即將關門的危險訊息，讓聽障者或戴耳機的乘客都能明確接收資訊，符合 $\textcolor{#4caf50}{\textbf{資訊明顯}}$ 原則。

2. **答案：(C)**  
   **解析**：動手做出具象化且低成本的模型以驗證概念，是 $\textcolor{#4caf50}{\textbf{原型 (Prototype)}}$ 階段的核心任務。

3. **答案：(C)**  
   **解析**：只能「推」的門若安裝了「拉環把手」，外觀形式（拉把）暗示了錯誤的功能操作（拉），導致使用者困惑，屬於經典的「諾曼門」反面教材。

4. **校園改造實作示範解答**：
   - **E 同理**：下課觀察同學丟垃圾行為，訪談發現很多人「怕弄髒手」且「遠看分不清哪個桶子裝什麼」。
   - **D 定義 (HMW)**：「我們如何讓同學在 1 秒內不髒手、直覺完成乾淨的紙杯與廚餘分類？」
   - **I 發想**：廚餘桶加裝腳踏式掀蓋；紙杯回收箱改為「專用圓形孔洞」（只能放杯子，防丟大垃圾）；桶蓋上方加上生動的圖示與色彩。
   - **P 原型**：利用回收紙箱切割出杯子大小的圓孔，用彩色麥克筆畫上醒目的 Pictogram 標示。
   - **T 測試**：將紙箱原型放置在走廊實測一週，收集同學反饋並計算分類正確率改善成果。

## 🚀 +10% 現代素養前瞻新知

**🧠 人工智慧 UX (使用者體驗) 與以人為本的設計未來**

然而，**AI 永遠無法代替人類走進養老院握著長輩的手體會孤獨，也無法親自感受到輪椅族在人行道高低差前的無助。**
