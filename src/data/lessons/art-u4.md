## 🔑 核心觀念 1：設計思考五大步驟 EDIPT

設計思考是由美國史丹佛大學發揚光大的一套解決問題的方法。它不是直線的，而是一個可以不斷循環、修正的過程。這五個步驟簡稱為 **EDIPT**。

### 🏠 生活案例
1. **重新設計校門口路標**：放學時家長接送區總是大塞車。同學透過「同理」，發現家長看不清楚停車區標示；於是「定義」問題為標示不夠直覺；接著「發想」用顏色區分年級；最後用紙板「製作原型」並拿到校門口「測試」。這就是標準的設計思考！

### 📊 設計思考五步驟完整表格
| 步驟 (英文) | 定義與精神 | 核心問題 | 工具與方法 | 範例：改造難開的果醬瓶 |
| :--- | :--- | :--- | :--- | :--- |
| **E 同理 (Empathize)** | 站在使用者的角度，感受他們的痛苦與需求。 | 使用者是誰？他們遇到什麼困難？ | 訪談、觀察、人物誌 | 觀察阿嬤扭不開果醬瓶，手會痛。 |
| **D 定義 (Define)** | 將觀察到的現象收斂，找出真正的核心問題。 | 問題的真正癥結點在哪裡？ | 問題定義句 (HMW: 如何我們能...) | 「我們如何能讓力氣小的長輩輕鬆開瓶？」 |
| **I 發想 (Ideate)** | 腦力激盪，提出越多越瘋狂的點子越好！ | 有哪些解決方案？ | 腦力激盪 (心智圖)、便利貼 | 加上把手、改變蓋子材質、用按壓的... |
| **P 原型 (Prototype)** | 用最便宜、快速的方法把點子做成實體模型。 | 怎麼讓別人看到我的點子？ | 紙板、黏土、樂高、草圖 | 用黏土和厚紙板做一個有把手的瓶蓋套。 |
| **T 測試 (Test)** | 讓使用者實際試用，收集回饋並改進。 | 這個方法真的有效嗎？哪裡要改？ | 實地操作、問卷回饋 | 請阿嬤試用模型，阿嬤說把手太短不好握，於是重新修改。 |

## 🔑 核心觀念 2：通用設計 (Universal Design) 7大原則

**通用設計**的理念是：「這項設計能不能讓**所有人**（包括小孩、老人、身障者、左撇子等）都能公平、方便地使用？」

### 🏠 生活案例
2. **無障礙低底盤公車**：以前的公車階梯很高，坐輪椅的人或推嬰兒車的媽媽根本上不去。現在的「低底盤公車」加上斜坡板，讓所有人都能輕鬆上車。這就是通用設計的最佳體現！

### 📊 通用設計 7 大原則表格
| 原則 | 說明 | 生活實例 |
| :--- | :--- | :--- |
| **1. 公平使用** | 讓不同能力的人都能用，不造成歧視。 | 建築物外的斜坡道（輪椅、推車、走路都能用）。 |
| **2. 彈性使用** | 適應各種偏好和能力（例如左右手都可用）。 | 左右撇子都能用的剪刀。 |
| **3. 簡易直覺** | 不管經驗、知識或語言，一看就知道怎麼用。 | 飯店房間裡一按就全關的「總開關」。 |
| **4. 資訊明顯** | 不受環境影響，能有效傳達重要資訊。 | 捷運門關閉前的閃燈與警示音（視覺+聽覺）。 |
| **5. 容許錯誤** | 就算不小心操作錯誤，也不會造成危險。 | 電腦刪除檔案前會跳出「確定要刪除嗎？」的警告。 |
| **6. 省力操作** | 可以用最少的力氣，保持舒適地使用。 | 自動感應的水龍頭或自動門。 |
| **7. 空間尺寸適用** | 不論使用者的體型或姿勢，都有足夠空間使用。 | 捷運車廂內加寬的驗票閘門。 |

## 🔑 核心觀念 3：公共視覺指標 Pictogram 與「形式跟隨功能」

當你到國外旅行，看不懂當地文字時，你是怎麼找到廁所的？就是靠 **Pictogram（圖像符號）**！
好的設計遵守**「形式跟隨功能」 (Form follows function)** 的哲學：一個東西的外表長怎樣，應該是由它的功能來決定的。

### 📊 好設計 vs 不好設計對比表
| 比較項目 | ✅ 好的設計 (好用又好看) | ❌ 不好的設計 (好看但難用) |
| :--- | :--- | :--- |
| **門把設計** | 推的門裝一塊平板，拉的門裝把手（直覺）。 | 推的門卻裝了把手，讓人總是不小心用拉的。 |
| **視覺指標** | 廁所標誌用明顯的男女圖像，色彩對比強烈。 | 廁所標誌設計得很藝術抽象，讓人站在門口猜半天。 |
| **水壺** | 握把符合人體工學，倒水時重心穩定。 | 造型像個藝術雕塑，但倒水時會燙到手。 |

## 🔑 核心觀念 4：綠色設計與永續實作

在設計時，我們不能只考慮人類，還要考慮地球！**綠色設計 (Green Design)** 強調減少浪費、使用環保材料。

### 🏠 生活案例
3. **網購的永續包裝**：以前網購寄來，紙箱裡塞滿了塑膠泡泡紙。現在許多品牌改用「蜂巢紙」來緩衝，或是使用可以回收重複使用的「循環包裝袋」。

### 💡 完整校園問題改造工作坊實作步驟
現在，換你們動手了！
1. **分組探險 (Empathize)**：拿著相機，去校園裡尋找 3 個讓你覺得「不方便」或「不美觀」的角落（如：垃圾桶總是滿出來、走廊轉角容易撞到人）。
2. **選定挑戰 (Define)**：各組投票選出一個最想解決的問題，寫下 HMW (如何我們能...) 挑戰句。
3. **瘋狂點子 (Ideate)**：每個人在便利貼上畫出 3 個解法，貼在黑板上分類。
4. **動手做 (Prototype)**：利用回收紙箱、膠帶、奇異筆，做出 1:1 的模型。
5. **實地測試 (Test)**：把模型放到實際位置，請其他班的同學試用，並記錄他們的反應。

## 🧠 迷思大破解

* ❌ **迷思一：設計師就是要會畫很漂亮的圖。**
  ✅ **破解**：不對喔！畫圖只是工具之一。設計的核心是「解決問題」。如果你能用幾何圖形拼湊出一個很棒的發明，你也是一個超級設計師！
* ❌ **迷思二：做原型 (Prototype) 應該要花很多時間把它做得很精緻。**
  ✅ **破解**：剛好相反！原型應該要「快又便宜 (Quick and Dirty)」。因為如果你花了一個月做得很精緻，測試後發現方向全錯，那不就太浪費了嗎？
* ❌ **迷思三：一個東西只要長得漂亮，就是好設計。**
  ✅ **破解**：記住「形式跟隨功能」！如果一把椅子美若天仙，但坐上去五分鐘就會腰痠背痛，那它只能算藝術品，不能算是一個好的「椅子設計」。

## 🌍 你知道嗎？
**日本的「音姬」發明**：日本人在上廁所時，非常害怕別人聽到自己發出的聲音，因此以前常常會不斷沖水來掩蓋聲音，造成大量水資源浪費。於是，設計師發明了「音姬」——一個按鈕按下去就會發出流水聲的小機器。這個設計不僅同理了使用者的心理需求，還成功達到了「綠色設計」省水的效果！

## 🚀 +10% 現代素養前瞻新知
**AI 輔助設計與生成式 AI (Generative AI)**：
現在的設計師有了一位超級強大的助手——AI！像 Midjourney 或是 ChatGPT 這樣的生成式 AI，可以在「發想 (Ideate)」階段幫助我們快速生成上百種產品外觀的圖片；或者在設計網頁時，自動排版出最符合人類視覺習慣的版面。不過，AI 無法代替人類去「同理」別人的感受。所以，擁有溫暖的同理心，才是未來設計師最不會被取代的超能力！
