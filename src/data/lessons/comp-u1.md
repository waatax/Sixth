# 單元 1：時間與金錢管理——打造自律高效的精彩生活

學會規劃時間與善用金錢，是邁向獨立自主的第一步！

---

## ⏳ 核心觀念一：時間管理「四象限法則」

美國管理學家柯維提出將事情按「重要性」與「緊急性」分類：

```text
                  緊急                    不緊急
          ┌─────────────────────┬─────────────────────┐
          │  第一象限 (重要且緊急) │  第二象限 (重要但不緊急)│
  重  要  │  - 明天的段考       │  - 長期閱讀與運動    │
          │  - 突然生病就醫     │  - 人際經營與生涯規劃│
          ├─────────────────────┼─────────────────────┤
          │  第三象限 (不重要但緊急)│ 第四象限 (不重要不緊急)│
  不重要  │  - 突如其來的打擾   │  - 無目的滑手機追劇  │
          │  - 別人的瑣碎請求   │  - 沉迷電玩浪費時間  │
          └─────────────────────┴─────────────────────┘
```

> **成功秘訣**：高效人士花最多時間在**「第二象限」**（重要但不緊急的打底功夫），預防事情惡化成第一象限的危機！

## 💰 核心觀念二：金錢管理與理財觀念

### 1. 「需要」與「想要」大辨析
*   **需要 (Needs)**：維持生存與基本學習的必備開銷（文具、三餐、車資、教科書）。
*   **想要 (Wants)**：滿足慾望但缺少也能生活的開銷（最新款名牌球鞋、昂貴遊戲虛寶、流行盲盒）。

### 2. 六三一存錢法則
將每個月獲得的零用錢或紅包分成三份：
*   **60%**：日常必要開銷。
*   **30%**：儲蓄與緊急預備金（存進銀行不隨意動用）。
*   **10%**：投資自己（買好書、參加營隊學習新技能）或公益捐助。
