## 🎯 學習導引：為什麼要學這個？

你有沒有過這樣的經驗：明明把一篇很長的文章「從頭到尾每個字都唸完了」，但翻到後面的題目時，腦袋卻一片空白，完全不知道剛才讀了什麼？或者遇到題目問「作者真正想表達的是什麼」時，總覺得每個選項看起來都好像對？

📖 **閱讀不等於「看字」，真正的閱讀是「思考與解碼」！**
在資訊爆炸的現代社會，我們每天都會看到大量的社群貼文、新聞報導、課本知識與網路文章。學會系統性的閱讀理解策略，就像是給大腦裝上了一副「透視眼鏡」與「濾鏡系統」：你能夠一眼抓住核心重點、看穿作者沒說出口的言外之意，還能分辨哪些是客觀事實、哪些只是誇大的個人意見。這把閱讀金鑰，將伴隨你一生的學習！

## 🔑 核心觀念 1：閱讀理解金字塔——四大思維層次

國際知名的 PIRLS 與 PISA 閱讀評量將閱讀理解劃分為四個由淺入深的層次。讀懂一篇文章就像攀登金字塔：

```text
                  ▲
                 / \     【第四層：比較評估】判斷可信度、提出個人批判與反思
                /───\
               /     \    【第三層：整合詮釋】跨段落串聯訊息、歸納核心主旨
              /───────\
             /         \   【第二層：推論理解】結合線索與常識，讀出「弦外之音」
            /───────────\
           /             \  【第一層：擷取訊息】掃描關鍵字、定位文本明確資訊
          └───────────────┘
```

### 📊 本單元核心考點與重點公式速查表

| 核心知識點 / 考點主題 | 📐 核心公式 / 定理 / 規則架構 | 💡 黃金記憶口訣 / 速記法 | ⚠️ 常考易錯陷阱 / 必勝解題秘訣 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#e91e63}{\textbf{訊息擷取與定位}}$ | 圈畫題目關鍵字 $\rightarrow$ 掃描文章對應段落 $\rightarrow$ 提取字面明確訊息 | **「題幹關鍵字圈出來，回文定位找答案」** | ❌ 憑主觀印象作答！擷取訊息題答案必定百分之百能在原文中找到對應字句 |
| $\textcolor{#2196f3}{\textbf{推論理解策略}}$ | 結合上下文線索 $+$ 生活常理背景知識 $\rightarrow$ 解讀弦外之音與角色動機 | **「字面線索加常識，推敲背後真意圖」** | ⚠️ 推論必須「言之有據」，不可天馬行空過度解讀脫離文本脈絡 |
| $\textcolor{#ff9800}{\textbf{事實 vs 觀點判別}}$ | **事實 (Fact)**：客觀存在、可被驗證真偽的數據或事件<br>**觀點 (Opinion)**：主觀感受、價值判斷、個人喜好或主張 | **「事實能驗證真假，觀點帶主觀感受」**<br>「今天氣溫 32 度」是事實；「今天好熱」是觀點 | 💥 段考閱讀高頻陷阱：文章中作者的情緒形容詞（如最美麗、最棒）屬於主觀觀點 |
| $\textcolor{#2e7d32}{\textbf{六何法 (5W1H) 脈絡分析}}$ | 何人(Who)、何時(When)、何地(Where)、何事(What)、為何(Why)、如何(How) | **「人時地事為何怎，六何分析抓全篇」** | 💡 記敘文與新聞閱讀必備神器：用 5W1H 可以在 1 分鐘內精準梳理複雜故事脈絡 |

## 🔑 核心觀念 2：推論理解的邏輯公式——當個閱讀名偵探

![高年級閱讀理解策略 (Reading Comprehension) - 圖解 2](./images/man_u1_concept2.svg)

很多人以為「推論」就是憑感覺猜測，其實推論是一門嚴謹的邏輯思考！

$$\textcolor{#e91e63}{\textbf{推論 (Inference)}} = \textcolor{#2196f3}{\textbf{文章線索 (Text Clues)}} + \textcolor{#4caf50}{\textbf{讀者先備知識 (Prior Knowledge)}}$$

```text
  ┌───────────────────────┐       ┌────────────────────────┐
  │   文章明確線索 (Clues)  │   +   │  生活先備知識 (Schema)  │
  │ 「小明猛抓手臂，起紅疹」 │       │ 「被蚊蟲叮咬或過敏會癢」 │
  └───────────┬───────────┘       └───────────┬────────────┘
              │                               │
              └───────────────┬───────────────┘
                              ▼
                ┌───────────────────────────┐
                │     得出合理推論 (Inference)│
                │ 「小明可能被蚊子叮或過敏了」 │
                └───────────────────────────┘
```

### 🔍 推論的四大常見類型與實戰

1. $\textcolor{#e91e63}{\textbf{推論原因（Why）}}$：
   - *文本*：「阿豪一看到成績單，便默默地把頭低得不能再低，眼眶泛紅。」
   - *推論*：阿豪這次考試考得不理想，心裡感到難過與自責。
2. $\textcolor{#2196f3}{\textbf{推論心境（Emotion）}}$：
   - *文本*：「姐姐一邊哼著輕快的旋律，一邊蹦蹦跳跳地收拾行李箱。」
   - *推論*：姐姐非常期待即將到來的旅行，心情雀躍不已。
3. $\textcolor{#4caf50}{\textbf{推論後續發展（Prediction）}}$：
   - *文本*：「狂風呼嘯，大樹被吹得劇烈搖晃，天空壓著厚重的黑雲，遠處傳來隆隆雷聲。」
   - *推論*：一場狂風暴雨即將降臨。
4. $\textcolor{#ff9800}{\textbf{推論詞義（Contextual Meaning）}}$：
   - *文本*：「在沙漠中跋涉了三天三夜，口乾舌燥的旅人們終於看到一片綠洲，大家無不喜出望外，如逢**甘霖**。」
   - *推論*：「甘霖」在此比喻「在危難絕望中出現的及時救助與希望」。

## 🔑 核心觀念 3：火眼金睛——分清「事實 (Fact)」與「觀點 (Opinion)」

![高年級閱讀理解策略 (Reading Comprehension) - 圖解 3](./images/man_u1_concept3.svg)

在現代閱讀與批判性思考中，最關鍵的能力之一就是**區分客觀事實與主觀觀點**。

### 📊 事實 vs 觀點深度對比表

| 比較維度 | 客觀事實 $\textcolor{#2196f3}{\textbf{Fact}}$ | 主觀觀點 $\textcolor{#e91e63}{\textbf{Opinion}}$ |
| :--- | :--- | :--- |
| **定義說明** | 可以被具體檢驗、查證、客觀存在的真實情況。 | 個人基於價值觀、感受、情緒所產生的想法或信念。 |
| **特徵特點** | 具有客觀性、數據支持、不因個人喜好而改變。 | 具有主觀性、爭議性，不同人會有完全不同的看法。 |
| **關鍵語言標記** | 「根據研究顯示⋯⋯」、「測量結果為⋯⋯」、「發生於⋯⋯」 | 「我認為⋯⋯」、「最好/最差」、「應該⋯⋯」、「我覺得⋯⋯」 |
| **驗證方式** | 可以透過實驗、歷史文獻、測量儀器證明其真偽。 | 無法以「真假對錯」來二分，只能討論是否合理。 |

```text
                      【判斷句子屬性思考流程】
                                 │
                         這句話能被查證嗎？
                                ╱  ╲
                            是 ╱    ╲ 否（純屬個人感受）
                              ▼      ▼
                   【客觀事實 Fact】  【主觀觀點 Opinion】
                   「玉山海拔 3952m」 「玉山是臺灣最美的山」
```

### 💡 實戰辨析小試身手
1. 「地球繞著太陽公轉。」 $\rightarrow$ $\textcolor{#2196f3}{\textbf{事實}}$（可透過天文科學證實）
2. 「夏天吃芒果冰是人生最大的享受。」 $\rightarrow$ $\textcolor{#e91e63}{\textbf{觀點}}$（每個人喜好不同）
3. 「這款手機的電池容量是 $5000\text{ mAh}$。」 $\rightarrow$ $\textcolor{#2196f3}{\textbf{事實}}$（可檢測的客觀規格）
4. 「這款手機是市場上最值得購買的旗艦機。」 $\rightarrow$ $\textcolor{#e91e63}{\textbf{觀點}}$（受個人預算與需求影響）

## 🔑 核心觀念 4：六何分析法 (5W1H)——拆解長文的超級工具

![高年級閱讀理解策略 (Reading Comprehension) - 圖解 4](./images/man_u1_concept4.svg)

當我們面對結構複雜的記敘文或新聞報導時，使用**六何分析法（5W1H）**能迅速將混亂的資訊轉化為條理分明的結構圖！

### 📊 六何法（5W1H）架構與實戰解析

| 六何要素 | 英文對應 | 核心提問 | 實戰示範（以「少年發明自動澆花器」為例） |
| :--- | :--- | :--- | :--- |
| $\textcolor{#e91e63}{\textbf{何人 (Who)}}$ | Who | 主角是誰？參與者有哪些人？ | 臺灣國中生小傑與輔導老師 |
| $\textcolor{#2196f3}{\textbf{何事 (What)}}$ | What | 發生了什麼事件？主角做了什麼？ | 發明智慧土壤濕度感測自動澆花器並榮獲科展首獎 |
| $\textcolor{#4caf50}{\textbf{何時 (When)}}$ | When | 事件發生在哪個具體時間或年代？ | 2023 年暑假期間（耗時三個月） |
| $\textcolor{#ff9800}{\textbf{何地 (Where)}}$ | Where | 故事發生在什麼地點或環境？ | 學校科學實驗室與阿公的花園 |
| $\textcolor{#9c27b0}{\textbf{何因 (Why)}}$ | Why | 事件發生的起因、動機是什麼？ | 看到阿公年邁且經常忘記澆花導致農作物枯死 |
| $\textcolor{#00bcd4}{\textbf{如何 (How)}}$ | How | 過程如何進行？運用什麼方法？結果如何？ | 結合濕度感測器與微控制器程式，自動感應補水 |

```text
              ┌───────── 【六何法 5W1H 架構】 ─────────┐
              │                                        │
        【Who 何人】─── 小傑            【When 何時】─── 2023年
        【What 何事】── 發明自動澆花器   【Where 何地】── 學校/農園
        【Why 何因】─── 減輕長輩負擔     【How 如何】─── 傳感器自動控制
              │                                        │
              └────────────────────────────────────────┘
```

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【事實 (Fact) vs 觀點 (Opinion) 辨析】
- 📌 **題目情境**：閱讀以下四個句子，判斷何者為「客觀事實」，何者為「主觀觀點」？
  (1) 臺灣最高峰玉山海拔標高為 3952 公尺。
  (2) 玉山是全臺灣風景最迷人、最值得一去的高山。
- 💡 **思考關鍵**：
  - 事實：有數據支持、可被客觀檢驗與證明真偽。
  - 觀點：個人喜好、價值判斷、情緒形容詞（如最美麗、無聊、應該）。
- 📐 **詳盡步驟**：
  1. (1) 為「客觀事實」：海拔 3952 公尺是透過測量儀器測得的確定數據。
  2. (2) 為「主觀觀點」：「最迷人」、「最值得一去」是說話者的個人主觀感受。

### 📝 範例 2：【六何法 (5W1H) 文章脈絡拆解】
- 📌 **題目情境**：分析一段新聞報導：「昨日下午三點，消防隊員在陽明山國家公園成功營救了一名因大霧迷路的高中登山客。」請用 5W1H 標註各項要素。
- 📐 **詳盡步驟**：
  - **何時 (When)**：昨日下午三點
  - **何地 (Where)**：陽明山國家公園
  - **何人 (Who)**：消防隊員、迷路的高中登山客
  - **何事 (What)**：成功營救登山客
  - **何因 (Why)**：因為大霧導致視線不佳迷路
  - **如何 (How)**：消防隊員搜救行動

## 🧠 迷思大破解

*   ❌ **迷思 1：一字不漏地慢慢讀、全部背下來，才叫真正讀懂？**
    *   ✅ **正確觀念**：高明的閱讀者會根據閱讀目的切換速度！尋找特定資訊時使用「**掃讀（Scanning）**」，瀏覽全文大意時使用「**略讀（Skimming）**」，遇到核心論點或優美段落時才進行「**精讀（Close Reading）**」。靈活切換策略才是高手！
*   ❌ **迷思 2：做推論題時，只要發揮想像力，寫得越有創意越好？**
    *   ✅ **正確觀念**：推論不是天馬行空的「幻想」！所有的推論都必須在文章中找到**至少一處明確的文字證據（線索）**作為依據，脫離文本證據的猜想在考試與邏輯推論中都是錯誤的。
*   ❌ **迷思 3：報紙或網路新聞上寫的內容，全部都是「客觀事實」？**
    *   ✅ **正確觀念**：新聞報導中常常交織著「事實」與「記者的主觀觀點/採訪對象的看法」。閱讀時必須啟動批判思維，獨立檢驗數據來源，避免將別人的偏見誤當成客觀真理。

## 🌍 你知道嗎？

古人讀書講求「讀書百遍，其義自見」，但在資訊海量的現代，如果每本書都讀一百遍，我們的大腦會無法負荷！
宋代大文豪**蘇軾（蘇東坡）**曾創立一套超厲害的閱讀法叫「**八面受敵讀書術**」：他每次讀同一部經典時，每次只設定一個目標。例如第一遍只讀歷史興衰，第二遍專門研究軍事謀略，第三遍專注賞析文字修辭。這種「帶著明確問題與策略」的讀書方法，正是現代「任務導向閱讀理解」的最佳典範！

## 🚀 +10% 現代素養前瞻新知

**數位時代的「查核力」：如何用 AI 檢驗假訊息？**
在網路社群時代，許多農場文與假新聞會刻意使用「聳動的標題（Clickbait）」與「偽裝成事實的個人偏見」來吸引點閱。身為數位原住民，我們可以運用「**橫向閱讀法（Lateral Reading）**」：
1. **跳出原始網頁**：打開新的分頁，搜尋該訊息的核心關鍵字。
2. **多方交叉查證**：檢視具公信力的事實查核機構（如：台灣事實查核中心）或官方科學機構是否有一致的報導。
3. **辨別資訊來源**：善用生成式 AI 工具提問：「請幫我檢視這則訊息中的論點是否有嚴謹的學術數據支持？」
學會批判性閱讀，才能在數位浪潮中保持清醒的獨立思考力！
