## 🔑 核心觀念 1：槓桿原理——給我一個支點

![簡單機械：三類槓桿原理與省力省距離規律 (Levers)](./images/sci_u6_concept1.svg)

$\textcolor{#e91e63}{\textbf{槓桿 (Lever)}}$ 是一根能在固定點周圍自由轉動的硬桿。在任何槓桿操作中，必定存在三個核心點與兩個關鍵力臂：

```text
                               【 槓桿三要素與力臂示意圖 】
                    ┌─────────────────── 施力臂 ───────────────────┐
                    │                                              │
    [ 抗力 F₂ ] ◄───┘                                              └───► [ 施力 F₁ ]
        ▼                                                                  ▼
    ┌───────┐                                                          ┌───────┐
    │抗力點 │ ═══════════════════════ ▲ ══════════════════════════════ │施力點 │
    └───────┘                      [ 支點 ]                            └───────┘
        │                             │
        └─── 抗力臂 ──────────────────┘
```

1. $\textcolor{#00bcd4}{\textbf{支點 (Fulcrum, }\blacktriangle\textbf{)}}$：槓桿旋轉時固定不動的支撐點。
2. $\textcolor{#2196f3}{\textbf{施力點 (Effort Point)}}$：我們的手或動力源施加外力的地方。
3. $\textcolor{#9c27b0}{\textbf{抗力點 (Load Point)}}$：承受欲移動物體重量或阻力的地方。
4. $\textcolor{#ff9800}{\textbf{施力臂 (Effort Arm)}}$：從「支點」到「施力作用線」的垂直距離。
5. $\textcolor{#4caf50}{\textbf{抗力臂 (Load Arm)}}$：從「支點」到「抗力作用線」的垂直距離。

### ⚖️ 槓桿平衡黃金公式（力矩守恆）

$$\textcolor{#2196f3}{\textbf{施力}} \times \textcolor{#ff9800}{\textbf{施力臂}} = \textcolor{#9c27b0}{\textbf{抗力}} \times \textcolor{#4caf50}{\textbf{抗力臂}}$$

- $\textcolor{#e91e63}{\textbf{施力臂} > \textbf{抗力臂}}$：$\textcolor{#e91e63}{\textbf{省力槓桿}}$（施力小於抗力），但手需要移動較長的距離（費距離）。
- $\textcolor{#2196f3}{\textbf{施力臂} < \textbf{抗力臂}}$：$\textcolor{#2196f3}{\textbf{費力槓桿}}$（施力大於抗力），但物品能移動較長範圍（省距離、動作靈活）。
- $\textcolor{#4caf50}{\textbf{施力臂} = \textbf{抗力臂}}$：$\textcolor{#4caf50}{\textbf{等臂槓桿}}$（不省力也不費力，如天平、翹翹板）。

## 🔑 核心觀念 2：三類槓桿大解密——誰在中間？

![巧妙的簡單機械 (Simple Machines) - 圖解 2](./images/sci_u6_concept2.svg)

依據「$\textcolor{#e91e63}{\textbf{支點}}$、$\textcolor{#9c27b0}{\textbf{抗力點}}$、$\textcolor{#2196f3}{\textbf{施力點}}$」三者相對位置的不同，槓桿精準劃分為三大類別：

```text
   【第一類槓桿：支點在中間】       【第二類槓桿：抗力點在中間】       【第三類槓桿：施力點在中間】
       [抗] ─── ▲ ─── [施]              ▲ ─── [抗] ─── [施]              ▲ ─── [施] ─── [抗]
      (可省力/可費力/改方向)             (施力臂必長 ➔ 必定省力)           (抗力臂必長 ➔ 必定費力)
```

| 核心知識點 / 考點主題 | 📐 核心公式 / 定理 / 規則架構 | 💡 黃金記憶口訣 / 速記法 | ⚠️ 常考易錯陷阱 / 必勝解題秘訣 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#e91e63}{\textbf{槓桿原理平衡公式}}$ | $\text{施力} \times \text{施力臂} = \text{抗力} \times \text{抗力臂}$<br>$F_1 \times L_1 = F_2 \times L_2$ | **「施力乘施力臂 ＝ 抗力乘抗力臂」**<br>力臂：支點到力的作用線的垂直距離 | 💥 力臂越長越省力！施力臂 $> $ 抗力臂 $\Rightarrow$ 省力但費距離 |
| $\textcolor{#2196f3}{\textbf{三類槓桿判定法}}$ | 第一類：**支點在中間**（剪刀、翹翹板、拔釘器）<br>第二類：**抗力點在中間**（開瓶器、獨輪車、裁紙刀）<br>第三類：**施力點在中間**（筷子、鑷子、釣竿、掃帚） | **「一支二抗三施力，誰在中間就第幾」**<br>第二類必省力，第三類必費力但省距離！ | ⚠️ 筷子、鑷子是「費力槓桿」，目的是為了「省距離、操作靈巧精細」 |

## 🔑 核心觀念 3：滑輪與輪軸——旋轉的槓桿

![巧妙的簡單機械 (Simple Machines) - 圖解 3](./images/sci_u6_concept3.svg)

### 🔄 滑輪系統：定滑輪 vs 動滑輪

```text
       【定滑輪 (Fixed Pulley)】                      【動滑輪 (Movable Pulley)】
         固定在天花板頂端 ──────┐                       繩子一端固定在天花板 ───┐
                ( 🔘 )          │                                       │    ( 🔘 ) ◄── 手向上拉
                 /   \          │                                       │    /   \        (施力 F)
                /     \         │                                       │   /     \
    (施力 F) ◄─┘       [ 📦 重物 ]                                      └──┴───────┘
  - 相當於【第一類等臂槓桿】                                                 │ [ 📦 重物 ]
  - ❌ 不省力 (施力 = 物重)                                     - 相當於【第二類省力槓桿】
  - ✅ 改變施力方向 (向下拉，物體向上升)                         - ✅ 省力一半 (施力 = 1/2 物重)
  - 繩拉距離 ＝ 物體上升距離                                     - ❌ 費距離 (繩拉距離 = 2 × 物升距離)
```

```text
                        【 滑輪組 (1 定滑輪 ＋ 1 動滑輪) 】
                        結合兩者優點：既能【省力一半】，又能【改變施力方向】！
```

### 🏎️ 輪軸 (Wheel and Axle)——同軸旋轉的槓桿
輪軸是由半徑較大的大圓柱（**輪，半徑 $R$**）與半徑較小的小圓柱（**軸，半徑 $r$**）緊密固定在同一個中心軸上共同旋轉的裝置。

$$\textcolor{#2196f3}{\textbf{輪軸平衡公式：}} \text{施力} \times \text{輪半徑 } R = \text{抗力} \times \text{軸半徑 } r$$

1. $\textcolor{#e91e63}{\textbf{施力在「輪」上}}$（施力臂為大半徑 $R$）：$\textcolor{#e91e63}{\textbf{省力、費距離}}$。
   - 🏠 實例：汽車方向盤、螺絲起子把手、喇叭鎖門把、水龍頭十字把手。
2. $\textcolor{#2196f3}{\textbf{施力在「軸」上}}$（施力臂為小半徑 $r$）：$\textcolor{#2196f3}{\textbf{費力、省距離（轉速快）}}$。
   - 🏠 實例：竹蜻蜓中心軸、擀麵棍、電風扇扇葉軸心、自行車後輪齒輪帶動大輪。

## 🔑 核心觀念 4：斜面與螺旋——平緩的幾何魔法

![巧妙的簡單機械 (Simple Machines) - 圖解 4](./images/sci_u6_concept4.svg)

### 📐 斜面 (Inclined Plane)
將重物沿著傾斜的斜面推上去，所需的推力遠小於垂直直接搬起物品的重力。

$$\textcolor{#2196f3}{\textbf{斜面省力規律：}} \text{斜面長度 } L \text{ 越長、高度 } H \text{ 越低（坡度越平緩）} \longrightarrow \textcolor{#e91e63}{\textbf{越省力}}$$

```text
                  【 斜面與螺旋的幾何關係 】
                  /|                  ┌──────────┐
                 / |                  │ 🔩 螺絲釘 │ ──► 螺絲釘本質上就是
       斜邊 L   /  | 高度 H           │  (螺旋)  │     「捲繞在圓柱上的斜面」！
               /   |                  │  ═════   │
              /____|                  │  ═════   │     螺紋越密 ➔ 斜面越平緩
             底邊                      └──────────┘     鎖入時越省力，但轉圈越多
```

### 🔩 螺旋 (Screw)
將三角形的斜面紙張沿著鉛筆捲起來，斜邊形成的一圈圈螺旋紋路就是「$\textcolor{#9c27b0}{\textbf{螺紋}}$」。
- **螺紋越密集（螺距越小）**：相當於斜面越平緩，鎖入木材時$\textcolor{#e91e63}{\textbf{越省力}}$，但需要轉動的總圈數越多（費距離）。
- 🏠 實例：螺絲釘、旋轉樓梯、千斤頂、保溫杯螺紋瓶蓋。

## 🔑 核心觀念 5：宇宙終極鐵則——功的守恆定律

![簡單機械生活複合應用 (Compound Machines)](./images/sci_u6_concept5.svg)

在不考慮摩擦阻力的理想狀態下，任何簡單機械都必須嚴格遵守熱力學與力學的黃金法則：

$$\textcolor{#e91e63}{\textbf{功 (Work) 守恆：}} \textcolor{#2196f3}{\textbf{功 (W)}} = \textcolor{#e91e63}{\textbf{施力 (F)}} \times \textcolor{#ff9800}{\textbf{移動距離 (S)}}$$

$$\textcolor{#e91e63}{\textbf{使用任何機械，絕不可能「既省力又省距離」，也絕不可能「無中生有創造能量」！}}$$

- 想省一半的力（施力變成 $1/2$），手就必須多拉一倍的距離（距離變成 $2$ 倍）。
- 想節省動作距離（速度變快、範圍變大），就必須付出更大的肌肉力量。

## 📝 經典範例剖析與考題示範 (Step-by-Step Worked Examples)

### 📝 範例 1：【槓桿原理與三類槓桿判別】
- 📌 **題目情境**：判斷下列生活工具屬於省力槓桿、費力槓桿還是等臂槓桿？
  (1) 開瓶器 (2) 掃帚掃地 (3) 實驗室等臂天平
- 💡 **思考關鍵**：
  - 施力臂 $>$ 抗力臂 ➔ 省力槓桿。
  - 施力臂 $<$ 抗力臂 ➔ 費力槓桿（但省距離、工作方便）。
  - 施力臂 $=$ 抗力臂 ➔ 等臂槓桿。
- 📐 **詳盡步驟**：
  1. 開瓶器：抗力點在中間，施力臂大於抗力臂 ➔ **省力槓桿**。
  2. 掃帚：施力點在手握中間處，施力臂小於抗力臂 ➔ **費力槓桿**（但手動一小段，掃帚末端能掃很大範圍）。
  3. 等臂天平：兩端臂長相等 ➔ **等臂槓桿**。

### 📝 範例 2：【滑輪與輪軸的力學規律】
- 📌 **題目情境**：吊車想要吊起一個 $100$ 公斤的重物，若使用一個「定滑輪」需要施力多少？若改用一個「動滑輪」需要施力多少？
- 💡 **思考關鍵**：定滑輪不省力（改方向）；動滑輪省力一半。
- 📐 **詳盡步驟**：
  1. 定滑輪：施力大小等於物重 $= \mathbf{100\text{ 公斤重}}$（僅改變施力方向向下）。
  2. 動滑輪：重物由兩段繩子共同分擔，施力 $= 100 \div 2 = \mathbf{50\text{ 公斤重}}$（省力一半，但拉繩距離需變為 2 倍）。

---

## 🧠 迷思大破解

❌ **迷思 1**：筷子和鑷子用起來很費力，所以它們是不好的發明，應該全部淘汰改用省力機械。
✅ **正確觀念**：大錯特錯！第三類槓桿雖然「費力」，但它的核心價值在於「$\textcolor{#4caf50}{\textbf{省距離與高靈敏操作}}$」。我們手指只需微幅移動 $0.5\text{ cm}$，筷子尖端就能夾動 $2\text{ cm}$ 的範圍，讓我們能靈巧、衛生且精確地夾取細小食物或手術縫合。

❌ **迷思 2**：動滑輪可以幫我們省下一半的力氣，所以使用動滑輪做工可以替我們省下一半的總能量。
✅ **正確觀念**：根據「$\textcolor{#e91e63}{\textbf{功的守恆定律}}$」，機械無法創造能量！動滑輪雖然讓你只需出 $5\text{ kg}$ 的力舉起 $10\text{ kg}$ 的重物，但你的手必須拉動 $2\text{ 公尺}$ 的繩子才能讓物體上升 $1\text{ 公尺}$，總功依然完全相同。

❌ **迷思 3**：鎖螺絲釘時，螺紋越寬越稀疏的螺絲釘越好用，因為轉兩圈就鎖進去了。
✅ **正確觀念**：螺紋稀疏代表斜面坡度極陡，雖然轉的圈數少（省距離），但鎖入時需要耗費極大的力氣，容易滑牙甚至轉不動；若想輕鬆省力鎖入硬木，應選擇螺紋細密（平緩斜面）的螺絲釘。

## ✏️ 隨堂自我小練習

1. **(計算題)** 工人想用一根長鐵撬（槓桿）撬起一顆重達 $120\text{ 公斤}$ 的大巨石（抗力）。如果支點距離巨石（抗力臂）為 $20\text{ 公分}$，工人施力位置距離支點（施力臂）為 $100\text{ 公分}$。請問工人至少需要施加多少公斤的力氣才能撬動巨石？
   **解答**：
   根據槓桿平衡公式：$\text{施力} \times \text{施力臂} = \text{抗力} \times \text{抗力臂}$
   $$\text{施力} \times 100\text{ cm} = 120\text{ kg} \times 20\text{ cm}$$
   $$\text{施力} \times 100 = 2400 \Longrightarrow \text{施力} = \textcolor{#4caf50}{\textbf{24 公斤}}$$
   *(工人只需用 24 公斤的力就能舉起 120 公斤巨石，省力達 5 倍！)*

2. **(選擇題)** 小明使用裁紙刀切厚紙板，抗力點在刀片中央，支點在刀片前端轉軸，手握把手處在後端。請問裁紙刀屬於哪一類槓桿？
   (A) 第一類槓桿  (B) 第二類槓桿  (C) 第三類槓桿  (D) 不屬於槓桿
   **解答**：$\textcolor{#4caf50}{\textbf{(B)}}$。抗力點在中間（位於支點與施力點之間），屬於必定省力的第二類槓桿。

3. **(選擇題)** 在升旗典禮上，國旗藉由旗桿頂部的滑輪緩緩升起。請問旗桿頂部的滑輪屬於下列何者？
   (A) 定滑輪，能省力一半
   (B) 動滑輪，能省力一半
   (C) 定滑輪，不能省力但能改變施力方向
   (D) 動滑輪，能改變施力方向
   **解答**：$\textcolor{#4caf50}{\textbf{(C)}}$。旗桿頂部滑輪位置固定不動，為定滑輪，向下施力即可將國旗向上拉起。

4. **(簡答題)** 腳踏車在上下坡變速時，如果遇到陡峭上坡，騎乘者應該將後輪齒輪調大還是調小？請依輪軸原理說明原因。
   **解答**：應調為「**大齒輪**」。後輪齒輪由鍊條帶動為施力端（輪），後輪外胎為抗力端（軸）。調大後輪齒輪增加了施力半徑，使輪軸更省力，踩踏起來較為輕鬆。

5. **(填空題)** 螺絲起子的把手半徑為 $3\text{ cm}$，金屬軸心半徑為 $0.5\text{ cm}$。手握把手旋轉是施力在 $\underline{\hspace{1.5cm}}$ 上，這是一種 $\underline{\hspace{1.5cm}}$（填「省力」或「費力」）的簡單機械應用。
   **解答**：$\textcolor{#2196f3}{\textbf{輪}}$；$\textcolor{#e91e63}{\textbf{省力}}$。

### 1. 槓桿平衡的原理

- 🧠 **一句話記住**：施力 × 施力臂 = 抗力 × 抗力臂。
- 🌱 **生活例子**：翹翹板：重 30 公斤的小孩坐在離支點 2 公尺，要和坐在 1 公尺處的 60 公斤大人平衡：30 × 2 = 60 × 1。

<details>
<summary>對照白話說明與易錯提醒</summary>

槓桿有支點、施力點、抗力點。槓桿平衡時，施力 × 施力臂（支點到施力點的距離）= 抗力 × 抗力臂（支點到抗力點的距離）。

💡 **解題心法與重要規則**：施力 × 施力臂 = 抗力 × 抗力臂。

⚠️ **小心別犯錯**：力臂是「到支點的距離」，不是到槓桿尾端的距離。

### 2. 省力槓桿與費力槓桿

- 🧠 **一句話記住**：施力臂 > 抗力臂 → 省力；施力臂 < 抗力臂 → 費力但省時、方便。
- 🌱 **生活例子**：用很長的扳手轉螺絲比較輕鬆，因為施力臂變長了。

**先想想看**：遮住下面的說明，用自己的話說說「省力槓桿與費力槓桿」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

施力臂比抗力臂長，用比較小的力就能做事，叫省力槓桿（開瓶器、剪刀剪厚紙）；施力臂比抗力臂短，要花比較大的力，但動作快又方便，叫費力槓桿（筷子、鑷子）。

💡 **解題心法與重要規則**：施力臂 > 抗力臂 → 省力；施力臂 < 抗力臂 → 費力但省時、方便。

⚠️ **小心別犯錯**：費力槓桿不是沒用，它可以讓動作更精細、移動距離更大。

</details>

### 3. 定滑輪與動滑輪

- 🧠 **一句話記住**：定滑輪：不省力、改方向；動滑輪：省一半力、繩子拉兩倍長。
- 🌱 **生活例子**：升旗用定滑輪；工地吊重物常用動滑輪或組合滑輪。

**先想想看**：遮住下面的說明，用自己的話說說「定滑輪與動滑輪」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

定滑輪固定不動，不能省力，但能改變用力的方向（例如往下拉讓國旗往上升）。動滑輪會跟著物體一起移動，可以省一半的力，但繩子要拉兩倍長。

💡 **解題心法與重要規則**：定滑輪：不省力、改方向；動滑輪：省一半力、繩子拉兩倍長。

⚠️ **小心別犯錯**：省力的同時一定要多拉一些距離，不會「又省力又省距離」。

</details>

### 4. 輪軸：大輪帶小軸，省力好轉（延伸應用）

- 🧠 **一句話記住**：施力在輪 → 省力（但手要轉比較大的圈）；施力在軸 → 費力，但輪子轉得快。
- 🌱 **生活例子**：門把、螺絲起子、水龍頭把手、汽車方向盤都是輪軸。轉動粗粗的握柄（輪），細細的刀頭（軸）就能把螺絲轉緊。
- 🎯 **段考命題常考方式**：【什麼時候用】看到「一大一小、固定在一起轉動」的工具，就想到輪軸。

**先想想看**：遮住下面的說明，用自己的話說說「輪軸：大輪帶小軸，省力好轉」是什麼意思，再想一個你身邊的例子。

<details>
<summary>對照白話說明與易錯提醒</summary>

輪軸是由一個大輪和一根小軸固定在一起、一起轉動的工具。把力量用在大輪上，只要比較小的力氣就能轉動小軸，所以比較省力；輪越大，越省力。

💡 **解題心法與重要規則**：施力在輪 → 省力（但手要轉比較大的圈）；施力在軸 → 費力，但輪子轉得快。

⚠️ **小心別犯錯**：握柄越粗（輪越大）越省力；不要以為細的握柄比較好轉。

</details>

## 🧩 段考回推補強：考卷會考、容易漏掉的觀念

### 力的傳遞：齒輪、鏈條、液壓

課本常把傳動工具一起考：

- **齒輪咬合**：兩個齒輪直接咬合時方向相反；每轉過的「齒數」相同。大齒輪 30 齒、小齒輪 10 齒，大的轉 1 圈，小的轉 3 圈。
- **鏈條**：腳踏車前後齒輪以鏈條相連，方向相同。
- **液壓（帕斯卡原理）**：液體能傳遞壓力，例如油壓千斤頂、油壓拖板車。注射筒用水管相連時，推一邊，另一邊會被推出。

### 省力或費力，只看力臂

施力臂 > 抗力臂：省力但費時。施力臂 < 抗力臂：費力但省時或操作精細。施力臂 = 抗力臂：不省力也不費力。

生活例子：開瓶器省力、鑷子和筷子費力、翹翹板和天平等臂。**不是所有應用槓桿的工具都省力**。支點不一定在中間，看哪個點固定不動。

### 定滑輪、動滑輪和輪軸

- **定滑輪**：支點在滑輪中心，施力臂 = 抗力臂，不省力但能改變施力方向。旗桿就是。
- **動滑輪**：可省力，但不能改變方向，繩子要拉比較長。
- **輪軸**：施力在大輪上省力（門把、螺絲起子）；施力在軸上費力但省時（腳踏車後輪）。

**第 16 題**【選擇・課綱】　升旗時用的是哪一種裝置？優點是什麼？

**A.** 動滑輪，省力

<details>
<summary>看答案與解說</summary>

✅ **正確答案** 腳踏板 → 前齒輪 → 鏈條 → 後齒輪 → 後輪；前齒輪用小的、後齒輪用大的

🔍 **審題關鍵**：想想每踩一圈，後輪轉幾圈。

📐 **解題步驟**：

1. 力量從踏板經前齒輪和鏈條傳到後輪。
2. 前小後大時，踩一圈後輪轉較少。
3. 踩的力量較小，但速度較慢。

⚠️ **易錯提醒**：省力會費時，不可能都得到。

📖 **回課文複習**：本頁「齒輪、鏈條、液壓」。

</details>
