# 單元 7：速率

> 🎯 學完這個單元，你就能解決生活中的距離、時間、速率問題，還能挑戰追趕和相遇問題！

---

## 什麼是速率？

**速率**就是在一定時間內走過的距離，用來描述移動的快慢。

### 🔑 核心公式

> **速率 = 距離 ÷ 時間**

延伸出來的三個公式（三角關係）：

| 求什麼 | 公式 |
|--------|------|
| 速率 | 速率 = 距離 ÷ 時間 |
| 距離 | 距離 = 速率 × 時間 |
| 時間 | 時間 = 距離 ÷ 速率 |

> 💡 記憶技巧：想像一個三角形，上面是「距離」，左下是「速率」，右下是「時間」。
> 遮住你要求的那個，剩下兩個的關係就是答案！

---

## 時速、分速、秒速

速率的單位取決於距離和時間的單位：

| 名稱 | 意思 | 單位範例 |
|------|------|---------|
| 時速 | 每小時走多遠 | 公里/時（km/h） |
| 分速 | 每分鐘走多遠 | 公尺/分（m/min） |
| 秒速 | 每秒走多遠 | 公尺/秒（m/s） |

### 📝 範例：小明跑步

小明在 5 分鐘內跑了 1000 公尺。

```
分速 = 1000 ÷ 5 = 200 公尺/分
```

他每分鐘跑 200 公尺，跑得滿快的！🏃

---

## 速率單位換算

### 🔑 換算關係

```
時速 → 分速：÷ 60
分速 → 秒速：÷ 60
時速 → 秒速：÷ 3600

秒速 → 分速：× 60
分速 → 時速：× 60
秒速 → 時速：× 3600
```

### 📝 範例 1：時速 72 公里 → 秒速多少公尺？

```
第一步：換距離單位 72 公里 = 72000 公尺
第二步：換時間單位 1 小時 = 3600 秒

秒速 = 72000 ÷ 3600 = 20 公尺/秒
```

### 📝 範例 2：秒速 5 公尺 → 時速多少公里？

```
第一步：5 × 3600 = 18000 公尺/時
第二步：18000 ÷ 1000 = 18 公里/時

時速 = 18 公里/時
```

### 📝 範例 3：分速 300 公尺 → 時速多少公里？

```
300 × 60 = 18000 公尺/時
18000 ÷ 1000 = 18 公里/時
```

## 追趕問題

### 🔑 核心觀念

兩個人或物體**同方向**移動，速度不同時：

> **追上的距離 = (快的速率 - 慢的速率) × 時間**

或者反過來：

> **追上的時間 = 距離差 ÷ (快的速率 - 慢的速率)**

### 📝 範例 1：哥哥追弟弟

弟弟先出發，走了 600 公尺後哥哥才出發。弟弟分速 50 公尺，哥哥分速 80 公尺。
幾分鐘後哥哥追上弟弟？

```
速率差 = 80 - 50 = 30 公尺/分（哥哥每分鐘多走 30 公尺）
距離差 = 600 公尺

追上的時間 = 600 ÷ 30 = 20 分鐘
```

### 📝 範例 2：腳踏車追行人

小華步行分速 60 公尺，出發 10 分鐘後小明騎腳踏車分速 240 公尺追他。

```
小華先走的距離 = 60 × 10 = 600 公尺
速率差 = 240 - 60 = 180 公尺/分

追上時間 = 600 ÷ 180 = 10/3 ≈ 3.33 分鐘
```

## 相遇問題

### 🔑 核心觀念

兩個人或物體**面對面**移動：

> **相遇時間 = 總距離 ÷ (甲的速率 + 乙的速率)**

### 📝 範例 1：火車站出發

甲和乙分別從相距 2400 公尺的兩地同時出發，面對面走。甲分速 50 公尺，乙分速 70 公尺。幾分鐘後相遇？

```
速率和 = 50 + 70 = 120 公尺/分
相遇時間 = 2400 ÷ 120 = 20 分鐘
```

### 📝 範例 2：兩車相向行駛

A 城到 B 城距離 360 公里。甲車從 A 城時速 40 公里出發，乙車從 B 城時速 50 公里出發，兩車相向行駛。幾小時後相遇？

```
速率和 = 40 + 50 = 90 公里/時
相遇時間 = 360 ÷ 90 = 4 小時
```

## 解題步驟整理

| 步驟 | 動作 |
|------|------|
| ① | 讀題，找出已知條件（距離、速率、時間） |
| ② | 統一單位（公里→公尺、小時→分鐘等） |
| ③ | 判斷題型（基本題、追趕、相遇） |
| ④ | 套公式計算 |
| ⑤ | 檢查答案的單位和合理性 |

## 迷思大破解

### ❌ 迷思 1：「時速 60 公里 = 秒速 60 公尺」

**大錯特錯！** 時速和秒速的單位完全不同。

時速 60 公里 = 60000 公尺/3600 秒 ≈ **16.67 公尺/秒**

差了快 4 倍！換算時一定要注意距離和時間都要換。

### ❌ 迷思 2：「追趕問題用速率相加」

**錯！** 追趕問題是同方向，要用**速率相減**。

- 同方向追趕 → 速率**相減**
- 面對面相遇 → 速率**相加**

方向相同就「減」，方向相反就「加」！

### ❌ 迷思 3：「速率快的一定先到」

**不一定！** 還要看出發時間和距離。

就像龜兔賽跑的故事，如果兔子晚出發太久或中途休息，烏龜也可能先到！

重點是要算出**實際到達的時間**，不能只看速率。

## 本單元重點整理

| 觀念 | 公式 |
|------|------|
| 基本公式 | 速率 = 距離 ÷ 時間 |
| 追趕問題 | 時間 = 距離差 ÷ 速率差 |
| 相遇問題 | 時間 = 總距離 ÷ 速率和 |
| 單位換算 | 時速 ÷ 3600 = 秒速 |

> 🌟 記住口訣：**速率就是距除時，追趕用減相遇加！**
