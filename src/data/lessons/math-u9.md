## 🔑 核心觀念 1：放大圖與縮圖的幾何特徵

![圖解說明](./images/math_u9_concept1.jpg)

當我們把一個圖形依固定倍率放大或縮小時：
1. $\textcolor{#2196f3}{\textbf{對應角相等}}$：所有對應的角度大小**完全不變**！
2. $\textcolor{#e91e63}{\textbf{對應邊成等比例}}$：每一條對應邊都乘上（或除以）相同的倍數。
3. $\textcolor{#2e7d32}{\textbf{圖形形狀相同}}$：形狀維持相似，絕不會變形或歪斜。

```text
     原三角形 A                     放大 2 倍三角形 B
         ▲                                ▲
        / \  邊長 5                      /   \   邊長 10 (5 × 2)
      3/ 60°\                          3×2/ 60° \
      /______\                           /________\
         4                                   8 (4 × 2)
     ★ 頂角永遠是 60°，不會變成 120°！
```

## 🔑 核心觀念 2：長度 vs 面積的平方倍數法則（超級重點）

這是所有段考與競賽中最容易被忽略的幾何鐵則：

```text
  ┌─────────────────────────────────────────────────────────────┐
  │ 🌟 幾何縮放黃金法則：                                        │
  │ • 當邊長放大 $\textcolor{#e91e63}{\textbf{n}}$ 倍時：                                       │
  │ • 周長放大 $\textcolor{#e91e63}{\textbf{n}}$ 倍                                             │
  │ • 面積放大 $\textcolor{#d32f2f}{\textbf{n^2}}$ **倍**（$n \times n$ 倍）！                  │
  │ • 體積放大 $\textcolor{#2196f3}{\textbf{n^3}}$ **倍**（$n \times n \times n$ 倍）！        │
  └─────────────────────────────────────────────────────────────┘
```

### 📊 邊長倍數與面積倍數對照表

| 邊長變化倍數 ($n$) | 周長變化倍數 ($n$) | 面積變化倍數 ($n^2$) | 視覺網格示意 |
| :--- | :--- | :--- | :--- |
| **放大 2 倍** | 2 倍 | $\mathbf{2^2 = 4}$ **倍** | 1 格變 4 格（田字形） |
| **放大 3 倍** | 3 倍 | $\mathbf{3^2 = 9}$ **倍** | 1 格變 9 格（九宮格） |
| **縮小為 $\frac{1}{2}$** | $\frac{1}{2}$ | $\mathbf{(\frac{1}{2})^2 = \frac{1}{4}}$ | 面積縮小為原本的四分之一 |
| **縮小為 $\frac{1}{3}$** | $\frac{1}{3}$ | $\mathbf{(\frac{1}{3})^2 = \frac{1}{9}}$ | 面積縮小為原本的九分之一 |

## 🔑 核心觀念 3：比例尺的三種表示法與意義

**比例尺**表示「圖上距離」和「實際距離」縮小的比例關係：

$$ \textcolor{#e91e63}{\textbf{\text{比例尺} = \text{圖上距離} : \text{實際距離} = \frac{\text{圖上距離}}{\text{實際距離}}}} $$

### 📊 比例尺常見三種表示法

| 表示形式 | 範例寫法 | 意義說明 |
| :--- | :--- | :--- |
| **1. 數字比表示** | $\textcolor{#e91e63}{\textbf{1 : 25000}}$ 或 $\frac{1}{25000}$ | 圖上 $1\text{ cm}$ 代表實際 $25000\text{ cm}$（$= 250\text{ m}$） |
| **2. 文字說明表示** | $\textcolor{#2196f3}{\textbf{圖上 1 公分代表實際 500 公尺}}$ | 前後項直接帶生活常用單位 |
| **3. 線段圖示表示** | `0 100 200m` <br> `└──┴──┘` | 地圖邊緣繪製標尺，拿直尺即可直接對比量測 |

## 🔑 核心觀念 4：比例尺的雙向計算與單位統一技巧

進行比例尺運算時，$\textcolor{#d32f2f}{\textbf{最關鍵的步驟就是「單位換算」}}$！

### 📏 必背單位換算階梯：
- $1\text{ 公里 (km)} = 1000\text{ 公尺 (m)} = \textcolor{#e91e63}{\textbf{100000\text{ 公分 (cm)}}}$（後面有 5 個 0！）
- $1\text{ 公尺 (m)} = \textcolor{#2196f3}{\textbf{100\text{ 公分 (cm)}}}$

### 📝 範例 1：求實際距離（地圖比例尺 $1 : 25000$）
圖上量得甲、乙兩地距離為 $4\text{ cm}$，實際距離是多少公里？
1. $\text{實際距離} = 4 \times 25000 = 100000\text{ cm}$。
2. 換算單位：$100000\text{ cm} = 1000\text{ m} = \textcolor{#e91e63}{\textbf{1\text{ 公里 (km)}}}$。

### 📝 範例 2：求圖上距離（比例尺 $1 : 50000$）
兩地實際距離為 $3$ 公里，在圖上的長度是多少公分？
1. 統一單位：$3\text{ km} = 300000\text{ cm}$。
2. $\text{圖上距離} = 300000 \div 50000 = \textcolor{#2196f3}{\textbf{6\text{ 公分 (cm)}}}$。

### 📝 範例 3：求比例尺
圖上長度 $2\text{ cm}$ 代表實際距離 $500\text{ m}$，求比例尺。
1. 統一單位：$500\text{ m} = 50000\text{ cm}$。
2. $\text{比例尺} = 2 : 50000 = \textcolor{#e91e63}{\textbf{1 : 25000}}$（前項化簡為 1）。

## 🧠 迷思大破解

❌ **迷思 1**：長方形邊長放大 2 倍，面積也會放大 2 倍。
✅ **正確觀念**：大錯特錯！長變 2 倍，寬也變 2 倍，面積會變成 $2 \times 2 = \textcolor{#d32f2f}{\textbf{4 倍}}$！若邊長放大 3 倍，面積會放大 $3^2 = \textcolor{#d32f2f}{\textbf{9 倍}}$！

❌ **迷思 2**：放大圖中，三角形的內角也會跟著變大。
✅ **正確觀念**：圖形放大或縮小時，$\textcolor{#2196f3}{\textbf{角度完全保持不變}}$！三角形內角和永遠是 $180^\circ$。

❌ **迷思 3**：比例尺 $1 : 10000$ 比 $1 : 1000$ 還大。
✅ **正確觀念**：恰好相反！
- $1 : 1000$（分母小）是「大比例尺」，涵蓋範圍小但細節非常詳細（如校園平面圖）。
- $1 : 100000$（分母大）是「小比例尺」，涵蓋範圍超大但地圖物體縮得很小（如全臺灣地圖）。

## ✏️ 隨堂自我小練習

1. **(三角形放大題)** 一個直角三角形的三邊長分別為 $3\text{ cm}$、$4\text{ cm}$、$5\text{ cm}$，放大 $3$ 倍後，新三角形的三邊長與面積分別是多少？
   - **詳細解析**：
     - 新三邊長：$3 \times 3 = 9\text{ cm}$、$4 \times 3 = 12\text{ cm}$、$5 \times 3 = 15\text{ cm}$。
     - 原面積 $= 3 \times 4 \div 2 = 6\text{ cm}^2$。
     - 新面積 $= 6 \times (3^2) = 6 \times 9 = 54\text{ cm}^2$（亦可驗算：$9 \times 12 \div 2 = 54\text{ cm}^2$）。
   - **答案**：三邊長為 $9\text{ cm}, 12\text{ cm}, 15\text{ cm}$；面積為 $54\text{ cm}^2$。

2. **(面積反推題)** 一塊長方形農地在縮圖上的面積為 $12\text{ cm}^2$。如果這張縮圖的比例尺為 $1 : 500$，請問這塊農地的「實際面積」是多少平方公尺？
   - **詳細解析**：
     - 邊長放大倍數為 $500$ 倍。
     - 面積放大倍數為 $500^2 = 250000$ 倍。
     - $\text{實際面積} = 12 \times 250000 = 3000000\text{ cm}^2$。
     - 單位換算：$1\text{ m}^2 = 10000\text{ cm}^2 \rightarrow 3000000 \div 10000 = 300\text{ m}^2$。
   - **答案**：$300$ 平方公尺。

3. **(地圖求實距)** 比例尺 $1 : 20000$ 的地圖上，兩座涼亭相距 $8\text{ cm}$，實際距離是多少公尺？
   - **詳細解析**：
     - $\text{實際距離} = 8 \times 20000 = 160000\text{ cm}$。
     - $160000\text{ cm} = 1600\text{ 公尺}$（$= 1.6\text{ 公里}$）。
   - **答案**：$1600$ 公尺。

4. **(求圖上距離)** 實際距離為 $6$ 公里的兩座車站，在比例尺 $1 : 200000$ 的地圖上相距多少公分？
   - **詳細解析**：
     - 統一單位：$6\text{ km} = 600000\text{ cm}$。
     - $\text{圖上距離} = 600000 \div 200000 = 3\text{ cm}$。
   - **答案**：$3$ 公分。

5. **(求比例尺)** 圖上長度 $5\text{ cm}$ 代表實際長度 $2.5$ 公里，請問這張地圖的比例尺是多少？（請以比的形式表示）
   - **詳細解析**：
     - 統一單位：$2.5\text{ km} = 250000\text{ cm}$。
     - $\text{比例尺} = 5 : 250000 = 1 : 50000$。
   - **答案**：$1 : 50000$。

## 🚀 +10% 現代素養前瞻新知

**🗺️ Google 地圖與 GIS 向量圖層切片 (Tile Map) 比例尺演算法！**
當你在手機上瀏覽 Google Maps 或 Apple Maps，用手指放大縮小時，地圖是如何瞬間切換不同清晰度與道路標籤的？

現代地理資訊系統 (GIS) 採用了「$\textcolor{#2196f3}{\textbf{金字塔多級瓦片演算法 (Map Tile Pyramid)}}$」：
- 第 0 層：將整顆地球縮小成一張 $256 \times 256$ 像素的小圖片（極小比例尺）。
- 每次放大一級（Zoom Level + 1），地圖長寬各放大 2 倍，面積分割成 4 張瓦片（$2^2$ 倍！）。
- 當你放大到街道級別（第 18 層）時，地圖被精準切分成數億張高解析度微型瓦片，伺服器依據比例尺即時傳輸當前視野內的圖層，兼顧極速載入與精準導航！
