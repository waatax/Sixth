## 🔑 核心觀念 1：認識「比」與「比值」

### 1. 比的符號與各項名稱
我們用「$a : b$」來表示 $a$ 和 $b$ 的比，讀作「**$a$ 比 $b$**」：
- 冒號前面的 $a$ 稱為「**前項**」。
- 冒號後面的 $b$ 稱為「**後項**」。
- ⚠️ **極度重要**：**後項 $b$ 絕對不能為 $0$！**（因為後項是要拿來當除數的，分母不能為 0）

### 2. 什麼是「比值」？
「比值」就是**前項除以後項所得到的商**：
$$ \text{比值} = \text{前項} \div \text{後項} = \frac{\text{前項}}{\text{後項}} $$
- 比值是一個具體的**數值**（可以寫成整數、最簡分數或小數），通常不帶單位。

### 📝 範例 1：求下列各比的比值
- $3 : 5 \rightarrow \text{比值} = 3 \div 5 = \frac{3}{5} = 0.6$
- $12 : 4 \rightarrow \text{比值} = 12 \div 4 = 3$
- $2.4 : 1.6 \rightarrow \text{比值} = 2.4 \div 1.6 = \frac{24}{16} = \frac{3}{2} = 1.5$

### 📊 比值大小代表的意義

| 比值條件 | 數學意涵 | 生活實例 |
| :--- | :--- | :--- |
| **比值 $> 1$** | 前項比後項**大** | 哥哥與弟弟的零用錢比 $3 : 2$，比值 $1.5$（哥哥拿比較多） |
| **比值 $= 1$** | 前項和後項**一樣大** | 紅色與藍色顏料比 $5 : 5$，比值 $1$（等量混色） |
| **比值 $< 1$** | 前項比後項**小** | 糖與水的比 $1 : 8$，比值 $\frac{1}{8} = 0.125$（水比糖多很多） |

## 🔑 核心觀念 2：等比性質與相等的比

如果兩個比的**比值相同**，我們就稱這兩個比是「**相等的比**」，可以用等號連接（稱為比例式）：
$$ a : b = c : d \iff \frac{a}{b} = \frac{c}{d} $$

### 等比性質（黃金法則）
> 比的前項和後項**同乘**或**同除**以同一個不為 0 的數，其**比值不變**！
- $a : b = (a \times k) : (b \times k)$（其中 $k \ne 0$）
- $a : b = (a \div k) : (b \div k)$（其中 $k \ne 0$）

---

## 🔑 核心觀念 3：化為「最簡整數比」四大題型攻防戰

**最簡整數比**的定義：
1. 前項和後項都必須是**整數**。
2. 前項和後項互為**互質**（最大公因數為 1）。

### 📊 化簡最簡整數比四大題型統整表

| 題型種類 | 範例題目 | 解題關鍵步驟 | 示範演算過程 |
| :--- | :--- | :--- | :--- |
| **整數比** | $24 : 36$ | 同除以兩數的**最大公因數 (GCD)** | $\text{GCD}(24, 36) = 12$ <br> $(24 \div 12) : (36 \div 12) = \mathbf{2 : 3}$ |
| **小數比** | $0.35 : 0.8$ | 先同乘 10、100 變整數，再約分 | 同乘 100 $\rightarrow 35 : 80$ <br> 同除以 5 $\rightarrow \mathbf{7 : 16}$ |
| **分數比** | $\frac{2}{3} : \frac{5}{6}$ | 先同乘分母的**最小公倍數 (LCM)** 消除分母 | $\text{LCM}(3, 6) = 6$，同乘 6 <br> $(\frac{2}{3} \times 6) : (\frac{5}{6} \times 6) = \mathbf{4 : 5}$ |
| **小數與分數混和**| $0.75 : \frac{9}{8}$ | 先全部化為分數（或小數），再消除分母 | $0.75 = \frac{3}{4}$ <br> $\frac{3}{4} : \frac{9}{8}$ 同乘 8 $\rightarrow 6 : 9 \rightarrow \mathbf{2 : 3}$ |

## 🔑 核心觀念 4：比例分配生活應用題

### 📝 範例 2：按比例分配糖果
老師把 60 顆巧克力按照 $3 : 2$ 的比例分給小明和小華，請問小明和小華各分到幾顆？
1. **總份數**：$3 + 2 = 5$ 份。
2. **每份的數量**：$60 \div 5 = 12$ 顆。
3. **小明（佔 3 份）**：$12 \times 3 = 36$ 顆。
4. **小華（佔 2 份）**：$12 \times 2 = 24$ 顆。
**檢驗**：$36 + 24 = 60$ 顆，且 $36 : 24 = 3 : 2$ ✅

## 🧠 迷思大破解

❌ **迷思 1**：「比」和「比值」是一模一樣的東西。
✅ **正確觀念**：形式不同！「比」帶有冒號（如 $2 : 3$），表示兩個量的對應關係；「比值」是一個單一的數值（如 $\frac{2}{3}$ 或 $0.667$），表示前項除以後項的商。

❌ **迷思 2**：調製檸檬紅茶，檸檬原汁與紅茶是 $1 : 5$；那我把前項和後項都加上 2，變成 $3 : 7$，喝起來酸甜味道一定一模一樣。
✅ **正確觀念**：大錯特錯！比的等比性質是「**同乘或同除**」，絕對**不能「同加或同減」**！
$\frac{1}{5} = 0.2$，但 $\frac{3}{7} \approx 0.428$（檸檬濃度大幅飆升變超酸！），味道完全變了！

❌ **迷思 3**：求最簡整數比時，答案寫成 $\frac{2}{3}$ 就可以了。
✅ **正確觀念**：題目如果問「最簡整數**比**」，答案一定要寫成冒號形式「$2 : 3$」；如果問「**比值**」，才寫成分數「$\frac{2}{3}$」或小數。

## 📊 本單元重點速查整理表格

| 概念項目 | 定義與公式 | 計算規範 | 記憶口訣 |
| :--- | :--- | :--- | :--- |
| **比** | $a : b$（$a$ 前項、$b$ 後項） | 後項 $b \ne 0$，順序不可任意顛倒 | 前項對後項，順序要記牢 |
| **比值** | $\text{比值} = a \div b = \frac{a}{b}$ | 算出來是單一數值（分數/小數/整數） | 前除以後得比值，不帶單位 |
| **等比性質** | $a : b = (a \times k) : (b \times k)$ | 同乘同除不為 0，同加同減必出錯 | 同乘同除值不變，加減變形大忌諱 |
| **最簡整數比** | 前後項皆為整數且互質 | 分數乘 LCM，小數乘十百，整數除 GCD | 分母小數全消除，互質最簡才交卷 |

## ✏️ 隨堂自我小練習

1. **(化簡題)** 將下列各比化為「最簡整數比」，並求出「比值」：
   - (1) $48 : 32$
     **解答**：同除以 16 $\rightarrow \mathbf{3 : 2}$；比值 $= \mathbf{\frac{3}{2}}$（或 $1.5$）。
   - (2) $1.2 : 0.45$
     **解答**：同乘 100 $\rightarrow 120 : 45 \rightarrow$ 同除以 15 $\rightarrow \mathbf{8 : 3}$；比值 $= \mathbf{\frac{8}{3}}$。
   - (3) $\frac{5}{6} : \frac{3}{4}$
     **解答**：同乘 12 $\rightarrow 10 : 9 \rightarrow \mathbf{10 : 9}$；比值 $= \mathbf{\frac{10}{9}}$。

2. **(比例式計算)** 若 $4 : 7 = 20 : \Box$，求 $\Box$ 的值。
   **解答**：
   前項 $4 \times 5 = 20$，後項也要乘以 5，所以 $\Box = 7 \times 5 = 35$。

3. **(生活應用題)** 調製一杯香濃奶茶，奶精與紅茶的容量比是 $2 : 7$。如果要調製一杯總容量為 $450\text{ ml}$ 的奶茶，需要多少毫升的奶精和紅茶？
   **解答**：
   總份數 $= 2 + 7 = 9$ 份。
   每份 $= 450 \div 9 = 50\text{ ml}$。
   奶精 $= 50 \times 2 = 100\text{ ml}$；紅茶 $= 50 \times 7 = 350\text{ ml}$。

4. **(幾何應用題)** 一個長方形的周長是 $56$ 公分，長和寬的比是 $4 : 3$。請問這個長方形的面積是多少平方公分？
   **解答**：
   長 $+$ 寬 $= 56 \div 2 = 28$ 公分。
   總份數 $= 4 + 3 = 7$ 份，每份 $= 28 \div 7 = 4$ 公分。
   長 $= 4 \times 4 = 16$ 公分；寬 $= 4 \times 3 = 12$ 公分。
   面積 $= 16 \times 12 = 192$ 平方公分。
