# 單元 4：比與比值

> 🎯 學完這個單元，你會發現「比」無所不在——從調飲料到做實驗都用得到！

---

## 什麼是「比」？

「比」就是用來**比較兩個量的關係**。

我們用 **A : B** 來表示 A 和 B 的比，讀作「A 比 B」。

### 🏠 生活中的例子

- 果汁和水的比是 1 : 3 → 代表每 1 份果汁要加 3 份水
- 男生和女生的比是 5 : 7 → 代表每 5 個男生對應 7 個女生
- 水泥、沙、石的比是 1 : 2 : 3 → 這是混凝土的經典配方！

### 📌 注意事項

- **順序很重要！** A : B 和 B : A 是不一樣的
- 果汁 : 水 = 1 : 3 ≠ 水 : 果汁 = 3 : 1

---

## 比值是什麼？

### 🔑 核心觀念

**比值 = 前項 ÷ 後項**

比值就是把「比」變成一個數字（通常是分數或小數），方便我們比較和計算。

### 📝 範例 1：3 : 5 的比值

```
比值 = 3 ÷ 5 = 3/5 = 0.6
```

### 📝 範例 2：8 : 4 的比值

```
比值 = 8 ÷ 4 = 2
```

### 📝 範例 3：2.4 : 1.6 的比值

```
比值 = 2.4 ÷ 1.6 = 24/16 = 3/2 = 1.5
```

> 💡 比值等於 1，代表前項和後項一樣大。
> 比值大於 1，代表前項比後項大。
> 比值小於 1，代表前項比後項小。

---

## 最簡整數比

### 🔑 核心觀念

**最簡整數比**就是：
1. 前項和後項都是**整數**
2. 前項和後項的**最大公因數是 1**（也就是不能再約分）

### 📝 如何化成最簡整數比

**方法一：** 前項和後項同除以最大公因數

```
12 : 8
= (12 ÷ 4) : (8 ÷ 4)     ← 最大公因數是 4
= 3 : 2
```

**方法二：** 如果有分數，先通分再去掉分母

```
1/2 : 1/3
= (1/2 × 6) : (1/3 × 6)   ← 乘以分母的最小公倍數 6
= 3 : 2
```

**方法三：** 如果有小數，先同乘 10 或 100 變整數

```
0.6 : 0.9
= (0.6 × 10) : (0.9 × 10) ← 同乘 10
= 6 : 9
= 2 : 3                     ← 再約分
```

### 📝 綜合範例：1.5 : 2/3

```
  1.5 : 2/3
= 3/2 : 2/3               ← 先把小數變分數
= (3/2 × 6) : (2/3 × 6)   ← 乘以最小公倍數 6
= 9 : 4                    ← 已經是最簡整數比！
```

## 生活中的比

### 🥤 果汁調配

小明要調一杯好喝的柳橙汁，濃縮果汁和水的比是 **1 : 4**。

如果他要做 500 毫升的果汁飲料：

```
總共分成 1 + 4 = 5 份
每份 = 500 ÷ 5 = 100 毫升

濃縮果汁 = 1 × 100 = 100 毫升
水         = 4 × 100 = 400 毫升
```

### 🏗️ 混凝土配比

工地的混凝土配比是水泥 : 沙 : 石 = **1 : 2 : 4**。

如果需要 70 公斤的混凝土：

```
總共分成 1 + 2 + 4 = 7 份
每份 = 70 ÷ 7 = 10 公斤

水泥 = 1 × 10 = 10 公斤
沙   = 2 × 10 = 20 公斤
石   = 4 × 10 = 40 公斤
```

### 🎨 顏料調色

想調出橘色，紅色和黃色顏料的比是 **3 : 2**。

如果紅色用了 15 毫升，黃色要用多少？

```
3 : 2 = 15 : ?
15 ÷ 3 = 5（倍數）
黃色 = 2 × 5 = 10 毫升
```

## 迷思大破解

### ❌ 迷思 1：「比值和比是同一件事」

**錯！**
- **比**是兩個量的對應關係，寫成 A : B 的形式
- **比值**是一個數字，等於前項 ÷ 後項

例如 3 : 5 是「比」，3/5 = 0.6 是「比值」。

### ❌ 迷思 2：「比可以隨意交換順序」

**錯！** 順序不同，意義完全不同。

男 : 女 = 3 : 4 代表男生少、女生多。
女 : 男 = 4 : 3 雖然數字一樣，但寫法和對應關係不同。

### ❌ 迷思 3：「最簡整數比可以有小數」

**錯！** 最簡整數比的前項和後項都必須是**整數**，而且不能再約分。

0.5 : 1 不是最簡整數比！要先變成 1 : 2。

## 本單元重點整理

| 觀念 | 內容 |
|------|------|
| 比 | A : B，表示兩量的對應關係 |
| 比值 | 前項 ÷ 後項 |
| 最簡整數比 | 前後項為整數且最大公因數為 1 |
| 化簡技巧 | 有分數→通分、有小數→乘 10/100 |
