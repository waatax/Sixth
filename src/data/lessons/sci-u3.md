## 🔑 核心觀念 1：磁鐵的基本性質與磁力線

![電與磁：奧斯特實驗、電流磁效應與電磁鐵 (Electromagnetism)](./images/sci_u3_concept1.svg)


每塊磁鐵無論形狀為何（條形、蹄形、環形），都一定具有兩個磁性最強的端點，稱為$\textcolor{#e91e63}{\textbf{磁極}}$：**N 極 (North Pole，指北極)** 與 **S 極 (South Pole，指南極)**。

```text
       【同極相斥 💥】                           【異極相吸 🤝】
   [ N ── S ] ◄── 💥 ──► [ S ── N ]           [ S ── N ] ──► 🤝 ◄── [ S ── N ]
   (S 極對 S 極，互相推開排斥)                   (N 極對 S 極，互相吸引緊貼)
```

### 🧲 磁鐵的三大基本定律
1. $\textcolor{#e91e63}{\textbf{磁極交互作用}}$：$\textcolor{#e91e63}{\textbf{同極相斥}}$（N-N 或 S-S 互相排斥推開），$\textcolor{#2196f3}{\textbf{異極相吸}}$（N-S 互相強烈吸引）。
2. $\textcolor{#4caf50}{\textbf{不可分割性}}$：磁單極在自然界中不存在！如果將一根磁鐵折成兩半，折斷處會立刻感應出新的 N 極與 S 極，變成兩塊各自完整的磁鐵。
3. $\textcolor{#ff9800}{\textbf{磁性物質吸引性}}$：磁鐵只能吸引含有$\textcolor{#e91e63}{\textbf{鐵 (Fe)}}$、$\textcolor{#2196f3}{\textbf{鈷 (Co)}}$、$\textcolor{#9c27b0}{\textbf{鎳 (Ni)}}$ 等鐵磁性金屬。對於金、銀、銅、鋁、塑膠、木材則**完全沒有吸引力**。

### 🌐 磁力線 (Magnetic Field Lines) 的特徵
若在磁鐵上方覆蓋透明壓克力板並撒上細鐵粉，輕敲板子即可看見鐵粉排列成一條條平滑的弧線，稱為$\textcolor{#9c27b0}{\textbf{磁力線}}$：

```text
                     ┌───◄───◄─── 上方磁場 ───◄───◄───┐
                     │                                │
                     ▼                                ▲
               ┌───────────┐                    ┌───────────┐
               │    S 極   │ ══════════════════ │    N 極   │
               └───────────┘                    └───────────┘
                     ▲                                │
                     │                                ▼
                     └───◄───◄─── 下方磁場 ───◄───◄───┘
               (磁鐵外部：磁力線方向由 N 極出發，回到 S 極)
```

- **方向性**：在磁鐵外部，磁力線方向永遠由 $\textcolor{#e91e63}{\textbf{N 極出發}}$，彎曲回到 $\textcolor{#2196f3}{\textbf{S 極}}$；在磁鐵內部則由 S 極指向 N 極形成封閉曲線。
- **密集度與強度**：磁力線越密集的地方（如磁極兩端），代表$\textcolor{#ff9800}{\textbf{磁場強度越強}}$；磁力線稀疏處磁場較弱。
- **永不交叉**：任何兩條磁力線在空間中絕對不會互相交錯重疊。

## 🔑 核心觀念 2：地球大磁鐵與指北針

![電與磁的奇妙世界 (Electromagnetism) - 圖解 2](./images/sci_u3_concept2.svg)

我們的地球本體就是一顆巨大無比的球體磁鐵！因為地球外地核中含有高溫流動的液態鐵與鎳，透過發電機效應產生了覆蓋全地球的$\textcolor{#2196f3}{\textbf{地磁場}}$。

```text
                    【 地球地理北極 (北極熊 🐻‍❄️) 】
                    【 地磁場對應為：地磁 S 極 🧲 】
                                 ▲
                                 │ 指北針 N 極受吸引向上指向北方
                            ┌────┴────┐
                            │ 🧭 指北針 │
                            │   N 極  │
                            └────┬────┘
                                 │ 指北針 S 極受吸引向下指向南方
                                 ▼
                    【 地磁場對應為：地磁 N 極 🧲 】
                    【 地球地理南極 (企鵝 🐧) 】
```

### 🧭 指北針為什麼永遠指向北方？
- 指北針內部是一根裝置在極低摩擦支軸上的自由旋轉小磁針。
- 由於「異極相吸」的宇宙法則，指北針的 $\textcolor{#e91e63}{\textbf{N 極（紅色端）}}$ 會被地球北方的「$\textcolor{#2196f3}{\textbf{地磁 S 極}}$」所吸引，因此永遠堅定地指向**地理北極**！
- 相對地，指北針的 $\textcolor{#2196f3}{\textbf{S 極}}$ 則指向**地理南極**（地磁 N 極）。

| 地理位置名稱 | 地磁場對應磁極 | 指北針指向端點 | 備註說明 |
| :--- | :--- | :--- | :--- |
| $\textcolor{#2196f3}{\textbf{地理北極 (North Pole)}}$ | $\textcolor{#e91e63}{\textbf{地磁 S 極}}$ | 指北針的 $\textcolor{#e91e63}{\textbf{N 極}}$ 指向此處 | 異極相吸（N 極被地磁 S 極吸引） |
| $\textcolor{#e91e63}{\textbf{地理南極 (South Pole)}}$ | $\textcolor{#2196f3}{\textbf{地磁 N 極}}$ | 指北針的 $\textcolor{#2196f3}{\textbf{S 極}}$ 指向此處 | 異極相吸（S 極被地磁 N 極吸引） |

## 🔑 核心觀念 3：電流的磁效應——厄斯特的劃時代發現

![電與磁的奇妙世界 (Electromagnetism) - 圖解 3](./images/sci_u3_concept3.svg)

1820 年，丹麥物理學家**厄斯特 (Hans Christian Ørsted)** 在課堂實驗中偶然發現：當導線通上直流電時，放置在導線下方或上方的指北針磁針竟然發生了明顯的$\textcolor{#ff9800}{\textbf{偏轉}}$！

$$\textcolor{#e91e63}{\textbf{重大科學結論：}} \textcolor{#2196f3}{\textbf{電流 (流動的電荷)}} \text{ 會在其周圍空間激發出 } \textcolor{#e91e63}{\textbf{磁場 (Magnetic Field)}}$$

```text
       【直導線的安培右手定則】                 【通電螺線管 (線圈) 的磁場】
            大拇指 ＝ 電流方向                    四指彎曲 ＝ 電流環繞方向
                ▲                                  ┌─────────────┐
                │ 電流 I                           │  N 極   S 極│
           ┌────┼────┐                      ◄─── ├───► ◄───► ├───►
         ╭─┴────┼────┴─╮                     (磁場)│ 🌀🌀🌀🌀🌀 │(磁場)
         │  ⟲  │  ⟲   │ 磁場 B                    └─────────────┘
         ╰──────┼──────╯                      大拇指所指的方向 ＝ N 極方向
            四指彎曲 ＝ 磁場環繞方向
```

### ✋ 安培右手定則判定法
1. **長直導線**：右手大拇指指向電流方向，其餘四指自然彎曲握住導線，四指所指的同心圓環形方向即為磁場方向。
2. **通電螺旋線圈 (Solenoid)**：右手四指順著線圈上的電流流向彎曲環繞，此時伸直的大拇指所指的方向，即為線圈內部磁場方向，也就是線圈的 $\textcolor{#e91e63}{\textbf{N 極端}}$！

## 🔑 核心觀念 4：電磁鐵——威力強大的可控磁鐵

![電與磁的奇妙世界 (Electromagnetism) - 圖解 4](./images/sci_u3_concept4.svg)

將絕緣漆包線緊密纏繞在一根純鐵釘（鐵芯）上，通入直流電流，鐵釘便瞬間獲得強大磁性，這就是$\textcolor{#9c27b0}{\textbf{電磁鐵 (Electromagnet)}}$！

```text
                  【 簡易電磁鐵實驗電路裝置 】
             ┌───────────[ 開關 Switch ]───────────┐
             │                                     │
         ┌───┴───┐                             ┌───┴───┐
         │ 電池+ │                             │ 電池- │
         └───┬───┘                             └───┬───┘
             │                                     │
             └───────► 🌀🌀🌀🌀🌀🌀🌀🌀 ◄────────┘
                       │   鐵釘 (鐵芯)   │
                       └─────────────────┘
                         🧲 吸引大量迴紋針
```

### ⚖️ 電磁鐵 vs 永久磁鐵超級對比表

| 比較項目 | 電磁鐵 (Electromagnet) | 永久磁鐵 (Permanent Magnet) |
| :--- | :--- | :--- |
| $\textcolor{#e91e63}{\textbf{磁性開關}}$ | $\textcolor{#4caf50}{\textbf{可自由控制}}$（通電有磁性，斷電磁性立刻消失） | 永久具備磁性，無法隨意關閉 |
| $\textcolor{#2196f3}{\textbf{磁力強弱}}$ | $\textcolor{#4caf50}{\textbf{可自由調整}}$（增減電流、改變線圈圈數） | 固定不變（隨時間或高溫可能衰退） |
| $\textcolor{#ff9800}{\textbf{磁極方向}}$ | $\textcolor{#4caf50}{\textbf{可自由切換}}$（改變電池正負極接法，N/S 極對調） | 固定不變（N 極與 S 極位置固定） |

### 📈 增強電磁鐵磁力的三大黃金關鍵
1. $\textcolor{#e91e63}{\textbf{增加線圈纏繞圈數（匝數）}}$：在相同電流下，線圈繞 100 圈的磁力遠大於繞 20 圈。
2. $\textcolor{#2196f3}{\textbf{加大通過線圈的電流}}$：串聯更多顆電池提供更大電流，磁場強度倍增。
3. $\textcolor{#9c27b0}{\textbf{置入高導磁性鐵芯}}$：線圈內部插入鐵釘，鐵芯會被磁化與線圈磁場疊加，磁力可提升數百倍！

## 🔑 核心觀念 5：電磁鐵的日常生活科技應用

```text
   【電鈴運作循環 (Electric Bell)】             【馬達旋轉原理 (Electric Motor)】
    按下按鈕 ➔ 電路通電 ➔ 電磁鐵產生磁力           通電線圈置於永久磁鐵磁場中
          │                                              ┌──────────┐
          ▼                                              │ N 永久磁鐵 │
    吸引敲擊鐵片 ➔ 鈴響「叮！」                           │  ┌────┐   │
          │                                              │  │🌀圈│   │ ➔ 磁力推動旋轉
          ▼                                              │  └────┘   │
    接觸點分離 ➔ 電路斷開 ➔ 磁力消失                      │ S 永久磁鐵 │
          │                                              └──────────┘
          ▼                                            (電能 ──► 機械動能)
    鐵片彈簧彈回 ➔ 再次通電 ➔ 反覆「叮叮叮」
```

1. $\textcolor{#ff9800}{\textbf{傳統電鈴 (Electric Bell)}}$：利用「通電吸引 $\rightarrow$ 斷電彈回」的自斷電路機構，產生連續敲擊鈴鐺的高頻聲響。
2. $\textcolor{#2196f3}{\textbf{馬達 / 電動機 (Electric Motor)}}$：利用通電線圈在磁場中受磁力推動而持續旋轉的原理，將$\textcolor{#e91e63}{\textbf{電能}}$高效轉化為$\textcolor{#4caf50}{\textbf{動能}}$（如電風扇、吹風機、洗衣機、電動機車）。
3. $\textcolor{#9c27b0}{\textbf{電磁起重機 (Magnetic Crane)}}$：廢鐵回收場吊掛數噸鋼材，通電時強大磁力吸起廢鐵，移動到指定位置後「一鍵斷電」即可安全放下。
4. $\textcolor{#00bcd4}{\textbf{磁浮列車 (Maglev Train)}}$：利用車體與軌道間電磁鐵「同極相斥」的強大推力讓列車懸浮 $1\sim 2\text{ cm}$ 騰空前進，徹底消除機械摩擦力，時速可飆破 $600\text{ km/h}$！

### 📝 範例 1：【電磁鐵磁力增強條件探究】
- 📌 **題目情境**：在製作電磁鐵實驗中，如何讓電磁鐵吸引更多數量的迴紋針？請列出兩項最具體有效的方法。
- 💡 **思考關鍵**：電磁鐵磁力大小取決於「電流大小」、「線圈圈數」與「鐵芯」。
- 📐 **詳盡步驟**：
  1. 方法一：增加漆包線的纏繞圈數（如由 30 圈增加到 60 圈）。
  2. 方法二：增加電池串聯數量（增大電路中的電流強度）。
  3. 補充：在線圈中放入軟鐵芯可大幅聚集磁力線。

### 📝 範例 2：【生活中的電磁鐵應用判斷】
- 📌 **題目情境**：下列電器中，何者利用了「電流磁效應（電磁鐵/馬達）」？何者利用了「電流熱效應」？（電風扇、烤麵包機、電鈴、吹風機的發熱絲）
- 💡 **思考關鍵**：電轉動能/敲擊 ➔ 磁效應；電轉熱能 ➔ 熱效應。
- 📐 **詳盡步驟**：
  1. 電流磁效應：電風扇（馬達運轉）、傳統電鈴（電磁鐵吸引鐵槌敲擊鈴鐺）。
  2. 電流熱效應：烤麵包機（電熱絲發紅發熱）、吹風機發熱絲。

## 🧠 迷思大破解

❌ **迷思 1**：磁鐵可以吸引世上所有的金屬製品。
✅ **正確觀念**：磁鐵只能吸引含有「$\textcolor{#e91e63}{\textbf{鐵、鈷、鎳}}$」的鐵磁性金屬！我們日常的一元硬幣（主要含銅、鎳合金或純鋁製品）、鋁箔包、金項鍊、純銀戒指都無法被一般磁鐵吸引。

❌ **迷思 2**：拿鋸子把磁鐵從中間切斷，就可以得到一個單獨的 N 極和一個單獨的 S 極。
✅ **正確觀念**：絕對不可能！磁極永遠成雙成對存在。當你切斷磁鐵時，斷裂處的分子磁疇會重新排列，斷面處會立刻感應出相反的磁極，形成兩塊全新的微型雙極磁鐵。

❌ **迷思 3**：指北針的指針指向北方，所以地球的地理北極就是地磁的 N 極。
✅ **正確觀念**：剛好相反！根據「異極相吸」法則，指北針的「N 極」之所以指向地球北方，是因為地球地理北極附近實際上是地球磁場的「$\textcolor{#2196f3}{\textbf{地磁 S 極}}$」！

❌ **迷思 4**：電磁鐵纏繞漆包線時，線圈繞得越亂、越鬆散，磁力就越強。
✅ **正確觀念**：線圈必須沿著「同一方向」緊密且均勻地纏繞，磁力線才能完美同向疊加發揮最大威力；若正反方向胡亂交錯纏繞，相反方向的磁場會互相抵消削弱。

| $\textcolor{#2196f3}{\textbf{地磁與指北針原理}}$ | 地球本身是一顆大磁鐵：<br>地理北極附近為**地磁 S 極**；地理南極附近為**地磁 N 極** | **「指北針 N 極指向地理北極（因為那裡是地磁 S 極）」** | ⚠️ 指北針靜止時受地磁引導指向南北方向，周遭若有鐵器或通電導線會產生偏轉干擾 |
| $\textcolor{#ff9800}{\textbf{電流磁效應 (奧斯特)}}$ | 通電導線周圍會產生圓形磁場<br>右手安培定則：大拇指指向電流方向，四指彎曲為磁場方向 | **「電能生磁看右手，拇指電流四指磁」** | 💡 電流方向反轉時，磁場方向與指北針偏轉方向也會隨之反轉 |
| $\textcolor{#2e7d32}{\textbf{電磁鐵磁力增強三要素}}$ | 1. **增加線圈圈數**<br>2. **加大電流強度（多串聯電池）**<br>3. **放入鐵芯（如鐵釘）** | **「線圈多、電流大、塞鐵芯，磁力最強大」** | ⚠️ 電池並聯無法增強磁力（需串聯增加電壓）；電磁鐵可隨時開關磁性，優於永久磁鐵 |
| $\textcolor{#9c27b0}{\textbf{馬達 (電動機) 原理}}$ | 利用電磁鐵與永久磁鐵之間的排斥與吸引力帶動軸心旋轉 | **「通電轉動變動力，吹風機電風扇全靠它」** | 💡 馬達是將「電能轉為動能（機械能）」的核心裝置 |

   **解答**：$\textcolor{#4caf50}{\textbf{(B)}}$。利用安培右手定則：右手大拇指指向北方（電流方向），此時四指在導線下方指向西方，因此磁針 N 極向西偏轉。

### 3. 讓電磁鐵磁力變強的方法
