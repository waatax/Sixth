# 單元三：電與磁的世界

> 🧲 你知道嗎？電和磁其實是一家人！每次你按下開關、使用馬達玩具，都是電與磁在合作。讓我們一起進入這個看不見卻超強大的世界！

---

## 磁鐵的基本性質

### 磁極

每塊磁鐵都有兩個磁極：**N 極**（北極）和 **S 極**（南極）。

磁鐵最重要的規則：

- **同極相斥**：N 對 N、S 對 S → 會互相推開 💥
- **異極相吸**：N 對 S → 會互相吸引 🤝

你可以拿兩塊磁鐵試試看：同一端靠近時，會感覺到一股「推力」把手推開；反過來靠近，「啪」一聲就黏在一起了！

### 磁力線

如果你把一塊磁鐵放在紙下方，在紙上灑一些鐵粉，鐵粉就會排列出漂亮的弧線——這就是**磁力線**的形狀。

磁力線的特點：

- 從 **N 極出發**，回到 **S 極**
- 越靠近磁極，磁力線越密集，代表磁力越強
- 磁力線**不會交叉**

### 什麼東西會被磁鐵吸引？

磁鐵可以吸引含有**鐵、鈷、鎳**的物質。鋁罐、銅幣、塑膠、木頭等都不會被磁鐵吸引喔！

💡 **小測驗**：冰箱門用的磁鐵能吸住什麼？答案是鐵製的迴紋針、剪刀，但不能吸住鋁箔紙或一元硬幣。

## 地球磁場與指北針

### 地球是一塊超級大磁鐵

地球的內部有流動的液態鐵和鎳，產生了一個巨大的磁場。可以把地球想像成一塊超級大的磁鐵，它的磁場從南極附近出發，繞過地球表面，回到北極附近。

### 指北針為什麼指向北方？

指北針裡面有一根可以自由旋轉的小磁針。因為地球的**地理北極**附近其實是**磁場的 S 極**，而磁針的 N 極會被 S 極吸引，所以指北針的 N 極永遠指向北方。

等等……北極是 S 極？沒錯！這是很容易搞混的地方：

| | 地理位置 | 磁極 |
|---|---|---|
| 北方 | 地理北極 | 磁場的 S 極 |
| 南方 | 地理南極 | 磁場的 N 極 |

### 指北針的應用

古代的航海家和旅行者靠指北針（古稱「司南」）來辨別方向。即使在沒有 GPS 的時代，指北針也能幫助人們找到正確的路。中國是世界上最早發明指南針的國家，這可是我們的驕傲！

## 電流的磁效應

### 厄斯特的大發現

1820 年，丹麥科學家**厄斯特**（Ørsted）做了一個改變世界的實驗：

他把一條通電的導線放在指北針旁邊，結果指北針竟然**偏轉**了！這代表——**電流會產生磁場**！

這個發現叫做**電流磁效應**，它證明了電和磁之間有密切的關係。

### 通電導線周圍的磁場

當電流通過一條直導線時，導線的周圍會產生**圓形的磁場**，就像一圈一圈的甜甜圈圍繞著導線。

怎麼判斷磁場的方向？用**右手定則**：

1. 右手握住導線
2. 大拇指指向電流方向
3. 其他四指彎曲的方向就是磁場方向

### 線圈的磁場

如果把導線繞成一圈一圈的**線圈**（螺旋管），磁場會疊加在一起，變得更強！線圈的磁場形狀就像一塊棒狀磁鐵，有 N 極和 S 極。

## 電磁鐵——可以開關的磁鐵

### 什麼是電磁鐵？

把導線繞在一根**鐵芯**（鐵釘）上，通上電，鐵芯就變成磁鐵了！斷電後，磁性就消失。這就是**電磁鐵**。

跟一般的永久磁鐵比起來，電磁鐵的厲害之處在於：

- ✅ **可以控制開關**：通電有磁性，斷電就沒有
- ✅ **可以調整磁力大小**：改變電流大小或線圈匝數
- ✅ **可以改變磁極方向**：改變電流方向，N 極和 S 極就會對調

### 影響電磁鐵磁力的因素

| 因素 | 怎麼做會更強？ |
|------|----------------|
| 線圈匝數 | 繞越多圈，磁力越強 |
| 電流大小 | 電流越大（串聯更多電池），磁力越強 |
| 鐵芯 | 加入鐵芯比空心線圈磁力強很多 |

### 電磁鐵的應用

**🔔 電鈴**：按下按鈕 → 電路接通 → 電磁鐵產生磁力 → 吸引鐵片敲擊鈴 → 鐵片離開 → 電路斷開 → 磁力消失 → 鐵片彈回 → 電路再次接通……這個過程不斷重複，就會發出「叮叮叮」的聲音。

**🏎️ 馬達（電動機）**：馬達的核心就是電磁鐵！通電的線圈在永久磁鐵的磁場中會受力旋轉。電風扇、洗衣機、電動車都靠馬達運作。

**🏗️ 電磁起重機**：廢鐵回收場用巨大的電磁鐵來搬運沉重的鐵塊。通電吸起鐵塊，搬到目的地後斷電放下，超方便！

**🚄 磁浮列車**：利用電磁鐵的同極相斥原理，讓列車「浮」在軌道上方，減少摩擦力，所以可以跑得非常快！

## 迷思大破解

### ❌ 迷思一：「磁鐵可以吸住所有金屬」

**破解**：不對！磁鐵只能吸引含有**鐵、鈷、鎳**的物質。銅、鋁、金、銀等金屬都不會被磁鐵吸引。所以鋁箔紙、銅板和金戒指都吸不住喔！

### ❌ 迷思二：「把磁鐵切成兩半，就能得到一塊只有 N 極的磁鐵」

**破解**：不可能！不管你怎麼切，每一小塊磁鐵都還是有 N 極和 S 極。就算切成超級小的碎片，每一片都是完整的小磁鐵。磁鐵永遠都是 N 和 S 一起出現的。

### ❌ 迷思三：「指北針的 N 極指向地球的 N 極，所以地理北極是磁場的 N 極」

**破解**：剛好相反！因為異極相吸，指北針的 N 極之所以指向北方，是因為地理北極附近是地球磁場的 **S 極**。名稱確實很容易搞混，但只要記住「異極相吸」的原則就不會弄錯了。

## 動手做做看

**自製簡易電磁鐵**：

1. 準備一根大鐵釘、一段有絕緣層的銅線、一顆電池
2. 把銅線緊密地繞在鐵釘上（至少繞 30 圈）
3. 銅線的兩端分別接上電池的正極和負極
4. 試試看能吸起幾根迴紋針？
5. 改變繞線圈數或電池數量，比較看看磁力有什麼變化！

⚠️ **注意**：實驗中鐵釘和導線可能會發熱，不要持續通電太久。

## 本單元重點整理

1. 磁鐵有 N、S 兩極，**同極相斥、異極相吸**
2. 地球本身就是一個大磁鐵，指北針利用地球磁場來辨別方向
3. **電流磁效應**：通電導線周圍會產生磁場（厄斯特發現）
4. **電磁鐵** = 線圈 + 鐵芯 + 電流，可以控制開關和磁力大小
5. 電磁鐵被廣泛應用在電鈴、馬達、起重機、磁浮列車等
