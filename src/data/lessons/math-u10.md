# 單元 10：基準量與比較量

> 🎯 學完這個單元，你就能看懂打折、百分率，還能快速判斷誰是基準量！

---

## 什麼是基準量和比較量？

### 🔑 核心觀念

在比較兩個量的時候：

- **基準量**：被拿來「當標準」的那個量（分母的角色）
- **比較量**：拿來「跟標準比」的那個量（分子的角色）

公式：

> **比較量 ÷ 基準量 = 倍數（比值）**
>
> **比較量 = 基準量 × 倍數**
>
> **基準量 = 比較量 ÷ 倍數**

### 🏠 生活例子

「小明的身高是小華的 1.2 倍」

- 基準量：**小華**的身高（被拿來當標準的）
- 比較量：**小明**的身高（拿去跟標準比的）

---

## 如何判斷基準量？

### 🔑 關鍵技巧：找到「的」這個字

在「A 是 B **的**幾倍」這種句型中：

> **「的」前面那個就是基準量！**

### 📝 判斷練習

| 句子 | 基準量 | 比較量 |
|------|--------|--------|
| 小明的體重是小華**的** 1.5 倍 | 小華 | 小明 |
| 紅球數量是藍球**的** 3 倍 | 藍球 | 紅球 |
| 今年營收是去年**的** 1.2 倍 | 去年 | 今年 |
| A 是 B **的** 2/5 | B | A |

### 📝 範例 1

「哥哥有 300 元，弟弟的錢是哥哥的 2/3」，弟弟有多少錢？

```
基準量 = 哥哥 = 300 元
倍數 = 2/3

比較量（弟弟） = 300 × 2/3 = 200 元
```

### 📝 範例 2

「姊姊有 240 元，是妹妹的 4/3 倍」，妹妹有多少錢？

```
比較量 = 姊姊 = 240 元
倍數 = 4/3

基準量（妹妹） = 240 ÷ 4/3 = 240 × 3/4 = 180 元
```

### 📝 範例 3

「班上有男生 18 人、女生 24 人，男生是女生的幾倍？」

```
基準量 = 女生 = 24 人
比較量 = 男生 = 18 人

倍數 = 18 ÷ 24 = 3/4 = 0.75 倍
```

## 「是…的幾倍」常見題型

### 題型一：求比較量

> 已知基準量和倍數，求比較量 → **基準量 × 倍數**

果園有蘋果樹 80 棵，橘子樹是蘋果樹的 3/4。橘子樹有幾棵？

```
80 × 3/4 = 60 棵
```

### 題型二：求基準量

> 已知比較量和倍數，求基準量 → **比較量 ÷ 倍數**

書架上有故事書 45 本，是漫畫書的 5/3 倍。漫畫書有幾本？

```
45 ÷ 5/3 = 45 × 3/5 = 27 本
```

### 題型三：求倍數

> 已知基準量和比較量，求倍數 → **比較量 ÷ 基準量**

紅筆 12 枝、藍筆 8 枝，紅筆是藍筆的幾倍？

```
12 ÷ 8 = 3/2 = 1.5 倍
```

## 打折計算

### 🔑 核心觀念

打折就是「原價 × 折扣率」。

> **打 N 折 = 原價 × N/10**

| 打幾折 | 意思 | 乘以 |
|--------|------|------|
| 打 9 折 | 付原價的 90% | × 0.9 |
| 打 8 折 | 付原價的 80% | × 0.8 |
| 打 75 折 | 付原價的 75% | × 0.75 |
| 打 5 折 | 付原價的 50%（半價）| × 0.5 |
| 打 68 折 | 付原價的 68% | × 0.68 |

### 📝 範例 1：書店打 8 折

一本書定價 350 元，打 8 折要付多少？

```
350 × 0.8 = 280 元
省了 350 - 280 = 70 元
```

### 📝 範例 2：百貨公司打 75 折

一件外套定價 1200 元，打 75 折。

```
1200 × 0.75 = 900 元
```

### 📝 範例 3：已知折扣後價格，求原價

一雙鞋打 6 折後賣 480 元，原價多少？

```
原價 × 0.6 = 480
原價 = 480 ÷ 0.6 = 800 元
```

## 百分率

### 🔑 核心觀念

百分率就是「以 100 為基準」的比值。

> **百分率 = (比較量 ÷ 基準量) × 100%**

### 📝 範例 1：考試得分率

考試滿分 80 分，小明得 68 分。

```
得分率 = (68 ÷ 80) × 100% = 85%
```

### 📝 範例 2：出席率

全班 40 人，今天有 38 人出席。

```
出席率 = (38 ÷ 40) × 100% = 95%
```

### 📝 範例 3：成長率

去年營收 500 萬，今年 600 萬。

```
成長率 = (600 - 500) ÷ 500 × 100%
       = 100 ÷ 500 × 100%
       = 20%
```

### 📝 常見百分率與分數對照

| 百分率 | 分數 | 小數 |
|--------|------|------|
| 10% | 1/10 | 0.1 |
| 20% | 1/5 | 0.2 |
| 25% | 1/4 | 0.25 |
| 33.3% | 1/3 | 0.333 |
| 50% | 1/2 | 0.5 |
| 75% | 3/4 | 0.75 |
| 100% | 1 | 1.0 |
| 125% | 5/4 | 1.25 |

## 迷思大破解

### ❌ 迷思 1：「打 8 折就是減 8 元」

**大錯特錯！** 打 8 折是乘以 0.8，意思是付原價的 80%。

100 元的東西打 8 折 = 100 × 0.8 = 80 元（省了 20 元，不是省 8 元）。

### ❌ 迷思 2：「基準量一定是比較大的那個」

**錯！** 基準量跟大小無關，要看題目的敘述。

「小明的錢是小華的 3 倍」→ 基準量是小華（比較小的那個）。
「小明的錢是小華的 1/2」→ 基準量還是小華（但這次小華比較大）。

關鍵是看**「的」前面是誰**。

### ❌ 迷思 3：「百分率不可能超過 100%」

**錯！** 百分率可以超過 100%。

例如：今年營收是去年的 150%，代表成長了 50%。

業績成長為原來的 2 倍 = 200%。

### ❌ 迷思 4：「打折越多越便宜」

**要看怎麼說！** 
- 「打 3 折」= 付原價的 30%（很便宜，只付三成）
- 「打 9 折」= 付原價的 90%（只便宜一點）

數字越小代表折扣越多，越便宜！

## 本單元重點整理

| 觀念 | 重點 |
|------|------|
| 基準量判斷 | 找「的」前面的量 |
| 求比較量 | 基準量 × 倍數 |
| 求基準量 | 比較量 ÷ 倍數 |
| 打折 | 原價 × N/10 |
| 百分率 | (比較量 ÷ 基準量) × 100% |

> 🌟 記住口訣：**「的」前是基準，打折乘零點，百分除基準！**
