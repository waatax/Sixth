## 👥 均一專家顧問委員會陣容 (Expert Advisory Council - 9 位跨領域專家)

本專案由 **均一教育平台核心決策團隊** 聯合 **5 位外聘頂尖教育專家** 共同組成 9 人專家顧問委員會，經歷 **7 輪深度會議迭代 (Iterations 1 ~ 7)**，將教育學、認知神經科學、教科書實務、知識圖譜與自適應測評理論，全面轉化為高實用性、有實際操作方法論的英數理先修工程：

1. 💻 **林技術長 (CTO)**（均一平台技術長兼首席架構師）：主導知識圖譜 (Knowledge Graph) 引擎、Bayesian Knowledge Tracing (BKT) 演算法與零延遲互動探究工具架構。
2. 🧭 **張知識長 (CKO)**（均一平台知識長兼內容總監）：主導微概念粒度 (Micro-concepts) 切割與跨學段先備知識相依性拓撲圖。
3. 📱 **黃平台規劃長 (CPO)**（均一產品與平台規劃長）：設計學習者體驗路徑 (Learner Journey)、三階鷹架式引導提示與自主學習動線。
4. 🎓 **陳資深教育專家**（均一教育研發顧問兼師資培訓總監）：主導 108 課綱三面九項素養落地、鷹架學習理論 (Scaffolding) 與自律學習循環 (SRL)。
5. 📚 **周特級名師**（教育部國中數理輔導團首席諮詢教師 & 教科書編審委員）：精準對齊康軒、南一、翰林三大版本教科書單元進度與國中會考核心考點。
6. 🗣️ **李特聘講座教授**（國立師範大學英語教學研究所教授 & 雙語中心顧問）：研發「五大句型鷹架」、「be動詞/助動詞雙軌制」與「1200 常用字彙自然拼讀銜接包」。
7. 🧠 **蘇認知心理學家**（中研院/大學認知神經科學研究員 & 學習心理學教授）：專攻工作記憶限制 (Working Memory)、認知負荷理論 (Sweller's CLT) 與微步切割 (Micro-chunking)。
8. 🎮 **何遊戲化設計總監**（EdTech 遊戲化架構師兼產品體驗總監）：專精 Octalysis 八角行為架構、微任務回饋與動態心流通道調節。
9. 📊 **郭自適應測評科學家**（學習成效分析科學家兼資深演算法工程師）：研發三階動態提示鷹架 (Three-tiered Scaffolding) 與智能學習弱點診斷處方箋 (Smart Prescription)。

## 🔄 7 次會議深度迭代紀要白皮書 (7-Iteration Conference Summary)

- **Round 1【課綱診斷與三版本對齊】**：全面體檢小六下到國一上康軒、南一、翰林三大版本教科書落差，建立完整單元跨冊對照矩陣。
- **Round 2【均一知識圖譜微概念拓撲】**：打破章節壁壘，將國中先修拆解為「小六先備 ➔ 國一核心 ➔ 國二/會考延伸」五階能力階梯 (L1~L5)。
- **Round 3【數學科 4 階思維轉換方法論】**：確立「生活具象 ➔ 數線幾何 ➔ 代數符號 ➔ 會考素養」4 階階梯，並實作動態「數線正負走步機」。
- **Round 4【英語科文法句構無痛跨越】**：確立「be 動詞與一般動詞互斥原則」，打造動態「動詞時態時光機」與 1200 單詞性速記表。
- **Round 5【自然理化生物微觀具象化】**：落實 108 課綱探究與實作變因分析，打造「光學顯微鏡虛擬實驗台（倒立放大虛像與玻片反向移動規律）」。
- **Round 6【動機工程與三階提示自律閉環】**：設計「Level 1 觀念提點 ➔ Level 2 步驟引導 ➔ Level 3 完整詳解」三階測驗提示鷹架與智能弱點處方箋。
- **Round 7【全系統整合與終極驗收】**：三大版本切換過濾器、先修互動探究工具箱、專家白皮書專區全面上線，Oxlint 零警告與 Vite 極速構建通過！

## 🌟 核心功能矩陣

### 1. 📖 108 課綱三大版本教科書銜接矩陣 (康軒/南一/翰林)
- **版本快速切換過濾器**：可一鍵切換康軒、南一、翰林版，精確查看各版本國一對應章節名稱與銜接警訊等級。
- **小六先備知識回溯標籤**：明確告知國一每個新概念在國小六年級的先備知識點。
- **均一微概念階梯 (L1~L5)**：螺旋遞進拆解學習步幅，杜絕跳躍式學習挫折。
- **名師迷思防雷專區 (Misconception Buster)**：點擊展開各章節三大常犯錯誤陷阱與正解心法。

### 2. 🔬 國中先修動態探究工具箱 (Interactive Simulators)
- 🧮 **數線正負運算與絕對值走步機 (Number Line Simulator)**：
  - 相反數鏡像對稱視覺化（$(+a) + (-a) = 0$）。
  - 絕對值幾何距離公式驗證（$|A - B|$ 與中點坐標）。
  - 正負走步動態向量推演（加正向右、加負向左）。
- ⏳ **英語動詞時態時光機 (English Tense Time Machine)**：
  - 切換主詞 (I / You / He / They) 與動詞 (play / watch / study / go)。
  - 即時切換過去式、現在簡單式、現在進行式、未來式，動態演示三單 -s/-es 規則與時間副詞搭配。
- 🔬 **光學顯微鏡虛擬操作台 (Virtual Microscope Lab)**：
  - 低倍鏡 (100X) 與高倍鏡 (400X) 切換：親身體驗「暗、小、少、大」光學四特徵。
  - 粗細調節輪調焦清晰度與光圈亮度模擬。
  - 載玻片實體移動控制盤：親手驗證「物在哪裡，載玻片就往哪裡移」的倒立成像法則！

### 3. ✍️ 均一自適應闖關體檢與智能弱點處方箋 (Smart Adaptive Quiz)
- **35 題全科核心題庫**：精確涵蓋數學、英語、自然科學、國語文、社會科（每科 7 題），全面對齊康軒、南一、翰林三大版本。
- **三階提示鷹架**：
  - `💡 觀念提點 (Level 1)`：喚醒核心概念，不直接劇透答案。
  - `📝 步驟引導 (Level 2)`：提供解題算式或文法步驟。
  - `交卷後 Level 3 完整詳解`：詳細名師步驟推導與陷阱剖析。
- **智能弱點診斷處方箋 (Smart Prescription)**：測驗完畢後自動列出錯題知識點，精準引導回溯教材補強！

### 4. 📊 7×7 完整度查驗矩陣 (49 節點全維度驗證)
- **7 大學科範疇**：國小高年級自然 (`ns-ele-high`)、國中理化生物地科、國小高年級數學、國中數學先修、國小/國中英語文、國小/國中語文、國小/國中社會領域。
- **7 大教研維度**：官方課綱指標對齊、三版本教科書落差、微概念階梯 (L1~L5)、迷思概念防雷、交互探究實驗、三階自適應測評、均一官方 Hub 直通。
- 專屬獨立互動儀表板與專家白皮書查驗頁，100% 完整無遺漏！

## 🚀 本地開發與部署 (Getting Started)

```bash
# 安裝依賴
npm install

# 啟動本機開發伺服器 (預設連接埠: 5173)
npm run dev

# 語法與代碼規範檢查 (Oxlint)
npm run lint

# 生產環境打包 (輸出至 /dist 目錄)
npm run build

# 本機預覽生產環境打包
npm run preview
```
