1. 🧠 **兒童認知神經科學家**：主導「15~30秒微步切割 (Micro-chunking)」與多巴胺正向獎勵迴路。
2. 🎮 **頂級手遊化架構師**：打造魔王城堡挑戰 (Boss Castle)、連擊倍率、神獸盲盒轉蛋 (Gacha) 與即時打擊感。
3. 📱 **短影音沉浸互動導演**：研發 TikTok 直式全螢幕「知識短影音 Reels」模式與雙擊 ❤️ 點讚粒子特效。
4. 🔬 **PhET 互動實驗與數理模擬專家**：設計 6 大動態探究模擬器（圓面積切片、槓桿天平、酸鹼變色、電磁鐵、大氣鋒面、追趕跑道）。
5. 📚 **108 課綱特級名師委員會**：涵蓋國小六年級 8 大學科 + 國中七年級會考銜接考點。

## 🌟 7x7 (49 專項) 核心升級矩陣

### 1. 📱 短影音微學習 (Shorts/Reels)
- **直式滑動學習流**：支援手機滑動、鍵盤 `↑` / `↓` 上下切換。
- **15~30秒精準切割**：把複雜算理濃縮成 3 條超有感精華卡。
- **雙語 AI 實時發音伴讀**：可隨時暫停/切換語速。
- **5秒突擊快問**：影片中隨機觸發快問，答對立即噴發金幣。
- **雙擊飄心 ❤️ 粒子連擊**：即時多巴胺反饋。

### 2. 🔬 PhET 風格互動探究實驗室 (Interactive Labs)
- 🧮 **圓面積極限切片幾何模擬器**：4~64 等份切片，實時動態化身為長方形 ($r \times r \times 3.14$)。
- ⚖️ **槓桿平衡與力矩天平**：即時計算 $\text{施力} \times \text{施力臂} = \text{抗力} \times \text{抗力臂}$，達成平衡時觸發勝利煙火。
- 🧪 **酸鹼中和與石蕊試紙變色儀**：動態滴定酸鹼試劑，即時呈現 pH 數值與紅藍試紙變色。
- ⚡ **電磁鐵線圈與磁力強度實驗**：調整電池數量與線圈匝數，測試吸起迴紋針極限。
- 🌍 **大氣高低氣壓與冷暖鋒面動態圖解**：觀察高低氣壓氣流旋轉與梅雨滯留鋒成因。
- 🏃 **速率與相遇追趕跑道模擬器**：設定跑者速率，動態模擬計算精確相遇時間。

### 3. 🎁 神獸轉蛋盲盒與星光商城 (Gacha & Pet System)
- **黃金寶箱轉蛋機**：支援單抽與五連抽，SSR 皇家披風、極光頭像框神聖光柱特效。
- **5 大屬性守護神獸**：智多狐 (數學)、博學鷹 (自然)、雷霆龍 (魔王戰)、晴波豚 (英語)、星靈貓 (暴擊)。
- **三段形態進化**：幼年 $\to$ 成長 $\to$ 究極形態，裝備飾品提升戰力與經驗加成。

### 4. ⚔️ 魔王城堡挑戰與錯題粉碎擂台 (Battle Arena)
- **四大守護魔王**：遺忘幽靈、迷茫石巨人、粗心小惡魔、深淵混沌魔龍。
- **錯題粉碎擂台 (Mistake Smasher)**：將錯題轉化為粗心怪獸，揮動重錘一鍵粉碎弱點！

### 5. 🔊 Web Audio API 聲光體感反饋
- 純代碼即時合成多頻音效（開箱音、暴擊音、滑動音、連擊音、升級和弦）。
- 支援一鍵靜音與無障礙聲效調節。

## 🚀 本地開發與部署 (Getting Started)

```bash
# 安裝依賴
npm install

# 啟動本機開發伺服器 (預設連接埠: 5173)
npm run dev

# 語法與代碼規範檢查 (Oxlint)
npm run lint

# 生產環境打包 (輸出至 /dist 目錄)
npm run build

# 本機預覽生產環境打包
npm run preview
```
