單元 4：社會服務學習四部曲、視障人導法與公民實踐

📖【課綱核心觀念突破】
【服務學習 (Service-Learning) 標準四部曲歷程】： 1. 「準備 (Preparation)」：調研社區服務對象的真實需求、接受志工技能培訓與安全講習。 2. 「服務 (Action)」：帶著愛心與同理心實地投入利他公共服務。 3. 「反思 (Reflection)」：【最核心環節】！透過討論、寫作或分享，反思服務中的心靈觸動、自我成長與問題改善（What ➔ So What ➔ Now What）。 4. 「慶賀與分享 (Celebration)」：分享成果、彼此肯定感恩，激勵持續投身公共事務。
【視障朋友「人導法」四步驟口訣（必考實務題！）】： • 「問」：主動詢問「您需要協助嗎？」。 • 「拍」：以手背輕輕觸碰對方的指背，讓對方確認你的手臂位置。 • 「引」：讓視障者輕握自己的「手肘上方」，導引者走在「半步之前」平穩前進。 • 「報」：遇上下階梯或轉彎時，以口頭清晰預先告知路況（如：前有上階梯三階）。
【執勤中導盲犬的「四不一問」原則】：不餵食、不撫摸、不呼叫、不拒絕（導盲犬出入公共場所），並主動詢問視障朋友是否需要協助。

單元 6：戶外冒險探索、無痕山林 (LNT) 與野外危機求生應變

📖【課綱核心觀念突破】
【國際無痕山林運動 (Leave No Trace, LNT) 七大準則】： 1. 事前充分的規劃與準備（了解天候路線裝備）。 2. 在堅實的既有步道與營地上行走露營（不踩踏脆弱植被）。 3. 妥善處理廢棄物（所有垃圾、廚餘、果皮全數打包帶下山）。 4. 保持環境原有風貌（不採摘野花、不刻字破壞）。 5. 減低用火對環境的衝擊（使用爐具，不隨意野外生火）。 6. 尊重野生動植物（遠距離觀察，絕不餵食接觸）。 7. 考量其他使用者（降低噪音，禮讓上山山友）。
【果皮廚餘在山林的迷思】：高海拔低溫乾燥，果皮（如香蕉皮、橘子皮）需要數月甚至數年才能分解，且會吸引野生動物食用破壞習性，因此「廚餘果皮一律帶下山」！
【野外迷路求生「STOP 原則」】： • 「S (Stop)」：立即停下原地待援，絕對不要盲目亂走！ • 「T (Think)」：冷靜思考回憶最後確定位置。 • 「O (Observe)」：觀察周圍環境、尋找避風遮雨處、檢視背包糧水。 • 「P (Plan)」：擬定保暖防失溫與求救計畫。
【野外求生「333 原則」人體耐受極限】： • 失溫耐受約「3 小時」➔ 防風保暖防水為野外求生第一優先！ • 缺水耐受約「3 天」。 • 缺糧耐受約「3 週」。
【迷路致命大忌】：迷路時「絕對不可順溪谷往下走」！臺灣溪谷多垂直峭壁瀑布與深潭，容易受困失溫身亡；正確做法是「往高處稜線走或原地避風待援」。

【真題 1】在山林野外健行時若不慎脫離隊伍而迷失方向，下列哪一項求生做法是國際公認「最安全正確」的應變原則？
A. 順著陡峭溪谷一路往下游衝，尋找有沒有住家
B. 立即原地停下腳步 (Stop) 保持冷靜，做好防風保暖避難，留在明顯路徑原地等待搜救隊支援
C. 把背包所有裝備與外套丟掉輕裝狂奔
D. 點燃整片森林引發大火以吸引注意
