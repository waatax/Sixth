單元 7：夢想職業、生涯探索與志向表述句型

📖【課綱核心觀念突破】
【詢問與表達夢想職業的核心句型】： • "What do you want to be when you grow up?"（你長大後想成為什麼？） • "I want to be a / an [職業]."（我想成為一名...）。 • 第三單稱問答："What does he / she want to be?" ➔ "He / She wants to be a / an [職業]."
【冠詞 a 與 an 的正確搭配】： • 字首發音為「母音音標」的職業用 an：an astronaut（太空人）, an artist（藝術家）, an engineer（工程師）, an actor（演員）。 • 字首發音為「子音音標」的職業用 a：a doctor, a teacher, a veterinarian (vet, 獸醫), a pilot（飛行員）, a chef（主廚）, a police officer, a scientist.
【表達職業原因的 because 子句】： • "I want to be a vet because I love animals and want to care for them." • "He wants to be a software engineer because he likes coding and technology."
⚡【名師公式・解題大招・速記口訣】
🌟 職業句構三單注意公式
He/Shewantstobea/an[職業](三單主詞want加s！)He / She wants to be a/an [職業] (三單主詞 want 加 s！)He/Shewantstobea/an[職業](三單主詞want加s！)
💡 大招解析：因為問句用 does，回答時動詞 want 必須恢復加上三單 s ➔ wants。

單元 8：形容詞比較級與最高級 (Comparatives & Superlatives)

📖【課綱核心觀念突破】
【形容詞比較級（兩者相比）】： • 句型：A+be 動詞+比較級形容詞+than+B\text{A} + \text{be 動詞} + \text{比較級形容詞} + \text{than} + \text{B}A+be 動詞+比較級形容詞+than+B。 • 例句：A giraffe is taller than an elephant.
【形容詞最高級（三者或三者以上相比）】： • 句型：A+be 動詞+the+最高級形容詞+(in / of 範圍)\text{A} + \text{be 動詞} + \text{the} + \text{最高級形容詞} + (\text{in / of 範圍})A+be 動詞+the+最高級形容詞+(in / of 範圍)。 • 例句：Mount Everest is the highest mountain in the world.
【形容詞變化規則】： 1. 單音節直接加 -er / -est：tall ➔ taller ➔ tallest; fast ➔ faster ➔ fastest. 2. 字尾有 e 加 -r / -st：large ➔ larger ➔ largest; nice ➔ nicer ➔ nicest. 3. 子音 + y 結尾，去 y 改 -ier / -iest：happy ➔ happier ➔ happiest; heavy ➔ heavier ➔ heaviest. 4. 短母音 + 單子音結尾，重複字尾：big ➔ bigger ➔ biggest; hot ➔ hotter ➔ hottest. 5. 三音節以上（長單字），前面加 more / most：beautiful ➔ more beautiful ➔ the most beautiful.
【段考必考高頻不規則變化】： • good / well ➔ better ➔ the best • bad / badly ➔ worse ➔ the worst • many / much ➔ more ➔ the most
⚡【名師公式・解題大招・速記口訣】
🌟 比較級與最高級黃金搭配詞
看見than用【比較級(−er/more)】；看見the用【最高級(−est/most)】！看見 than 用【比較級 (-er / more)】；看見 the 用【最高級 (-est / most)】！看見than用【比較級(−er/more)】；看見the用【最高級(−est/most)】！

⚠️【歷屆名校高頻常考易錯陷阱】
❌ 最高級漏掉 the：學生常寫 "He is tallest boy"，正確必須有 the ➔ "He is the tallest boy in our class"。
❌ 不規則變化寫成 regular："gooder" 或 "goodest" 完全不存在！正確是 good ➔ better ➔ best；bad ➔ worse ➔ worst。
📝【各校歷年段考／畢業考真題實戰】
🏛️ 臺北市某國小六年級下學期畢業考精選題
【真題 1】The blue whale is _____ animal that has ever lived on the Earth.
A. large
B. larger than
C. the largest
D. most large
✅ 正確解答：選項 C
【解題步驟】：
範圍是全世界地球上所有動物相比（三者以上），使用最高級句型「the + 最高級形容詞」；large 字尾已有 e，直接加 st 變成 "the largest"。故選 C。
🏛️ 高雄市某國小六年級下學期畢業考精選題
【真題 2】Peter's math score is _____ than Kevin's, but Kevin is _____ runner in the class.
A. good ; the fast
B. better ; the fastest
C. more good ; fastest
D. best ; faster
✅ 正確解答：選項 B
【解題步驟】：
1. 第一個空格後面有 "than"，需使用比較級；good 的不規則比較級是 "better"。
2. 第二個空格後面有範圍 "in the class"，需使用最高級「the + fastest」。
故選 B。
