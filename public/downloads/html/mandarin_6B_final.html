【傳統書信格式五大核心要素】： 1. 「稱謂與提稱語」：對父母長輩用「膝下、膝前、尊鑒」；對師長用「函丈、道鑒」；對平輩用「大鑒、台鑒」；對晚輩用「青鑒、如晤」。 2. 「啟事敬詞（開場白）」：對尊長用「敬稟者、叩稟者」；對平輩用「敬啟者」；對晚輩用「逕啟者」。 3. 「祝頌問候語」：對父母用「敬請 叩安 / 福安」；對師長用「敬請 鐸安」；對商界用「順祝 商祺」。 4. 「署名與具名敬詞」：對父母自稱「兒/女 叩上」；對師長自稱「學生 敬上」；對平輩自稱「友 拜啟」。
【信封封面啟封詞（超級陷阱題！）】： • 信封中央是「郵差看給誰拆」的！因此寫給收信人的動詞「啟」是請對方「拆開信件」之意！ • 對長輩用「安啟、鈞啟」；對師長用「道啟」；對平輩用「大啟、台啟」。 • 【絕不可在信封寫「敬啟」！】「敬啟」意思是「請恭敬地打開」，等同命令尊長恭敬拆信，極為失禮！
【生活常見實用題辭分類（段考必背！）】： • 「賀新居落成（喬遷）」：華廈鼎新、喬遷之喜、美輪美奐、肯堂肯構。 • 「賀生男」：弄璋之喜；「賀生女」：弄瓦之喜。 • 「賀教師/教育界」：杏壇之光、桃李芬芳、立德樹人、春風化雨。 • 「賀醫界診所」：杏林春暖、妙手回春、懸壺濟世、扁鵲復生。 • 「賀壽誕」：松柏長青、福如東海、壽比南山。

【真題 1】小明寫了一封感謝信寄給班導師林老師。在直式信封的中央收件人欄位，下列哪一種寫法「最為禮貌且完全合乎傳統書信禮儀」？
A. 林老師 大啟
B. 林老師 敬啟
C. 林老師 學生小明敬上
D. 林老師 收到
✅ 正確解答：選項 A
【解題步驟】：
• 信封中央是請收信人拆信，「大啟」或「道啟」表示請對方拆開。
• B 項「敬啟」意為請老師恭敬打開，是大不敬。
• C 項把寄信人的「敬上」寫在收信人位置，格式錯誤。
故合乎禮儀的是 A（林老師 大啟/道啟）。

📖【課綱核心觀念突破】
【東漢許慎《說文解字》六書造字法則】： • 「四個造字之法（能創造出新字）」： 1. 「象形」：畫成其物，隨體詰詘。描摹物體具體形狀（如：日、月、山、水、木、魚、鳥）。 2. 「指事」：視而可識，察而見意。用純抽象符號或在象形字上加上符號標明位置（如：上、下、一、二、刃（刀上加一點標明刀鋒）、本（木下加一橫標明樹根）、末（木上加一長橫標明樹梢））。 3. 「會意」：比類合誼。將兩個或以上的字根組合起來產生新字義（如：休（人依於木為休息）、武（止戈為武）、信（人言為信）、明（日月同輝為明）、鳴（鳥口為鳴））。 4. 「形聲」：以事為名，取譬相成。由「形符（表意）」與「聲符（表音）」組合而成，佔現代漢字 80% 以上！（如：江（氵表水，工表音）、湖、晴、騎、茱）。 • 「兩個用字之法（只用字不造新字）」：「轉注」與「假借」。
【漢字字體演變歷史順序】：甲骨文（殷商卜辭，最古老成熟文字） ➔ 金文（鐘鼎文） ➔ 小篆（秦始皇李斯統一天下文字，線條圓勻對稱） ➔ 隸書（漢代打破象形古文字，由圓變方建立現代漢字結構，漢隸） ➔ 楷書（三國魏晉成熟，標準規範正楷）與行書、草書。
【古典文學名家封號與代表作】： • 「詩仙」：李白（字太白，號青蓮居士，盛唐浪漫主義詩人）。 • 「詩聖」：杜甫（字子美，號少陵野老，其詩反映社會疾苦被譽為「詩史」）。 • 「詩佛」：王維（詩中有畫，畫中有詩，精擅山水田園詩）。 • 「明代四大奇書」：《三國演義》、《水滸傳》、《西遊記》、《金瓶梅》（清代《紅樓夢》則與前三者合稱四大名著）。

🏛️ 臺北市某國小六年級下學期畢業考精選題
【真題 1】漢字造字法則中，「休」字由「人」倚靠在「木」旁表示休息；「明」字由「日」與「月」共同發光表示光明。請問這兩個字均屬於六書中的哪一種造字法則？
A. 象形
B. 指事
C. 會意
D. 形聲
✅ 正確解答：選項 C
【解題步驟】：
會意字是將兩個或兩個以上的字組合在一起，將各自的含義融合成一個全新的概念。人+木=休，日+月=明，均屬於「會意字」。故選 C。
🏛️ 高雄市某國小六年級下學期畢業考精選題
【真題 2】秦始皇統一六國後，推行「書同文」政策，廢除各國異體字，統一推行的官方文字字體是下列何者？
A. 甲骨文
B. 金文
C. 小篆
D. 楷書
✅ 正確解答：選項 C
【解題步驟】：
秦始皇命丞相李斯簡化六國文字，創制「小篆」作為全國統一的標準官方法定文字。隸書在漢代大興，楷書魏晉成形。故選 C。
